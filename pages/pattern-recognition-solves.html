A2. LDA, 2D to 1D S25, F24 (dataset 1) · S24 (dataset 2) · S23 (dataset 3)
Read: B §4.1.4 "Fisher's linear discriminant"; D Ch. 3 §3.8.2 "Fisher Linear Discriminant".
m_i = class mean; S_i = Σ(x−m_i)(x−m_i)ᵀ; S_W = S1+S2; S_B = (m1−m2)(m1−m2)ᵀ w ∝ S_W⁻¹(m1−m2) (largest eigenvector of S_W⁻¹S_B); y = wᵀx

Dataset 1 — class 0: (1,2),(3,1); class 1: (6,5),(8,7).

  • m1 = (2, 1.5), m2 = (7, 6); S1 = [[2,−1],[−1,0.5]], S2 = [[2,2],[2,2]]; S_W = [[4,1],[1,2.5]], |S_W| = 9.
  • S_B = [[25,22.5],[22.5,20.25]]. S_W⁻¹ = (1/9)[[2.5,−1],[−1,4]].
  • w = S_W⁻¹(m1−m2) = (1/9)(−8, −13) → direction (8,13); unit vector w = (0.524, 0.852). Largest eigenvalue of S_W⁻¹S_B = 10.94 (the other is 0).
  • Projections y = 0.524x1+0.852x2: class 0 → 2.23, 2.42; class 1 → 7.40, 10.15. Classes are clearly separated.

Dataset 2 — class 0: (2,3),(3,5); class 1: (5,8),(6,10).

  • m1 = (2.5,4), m2 = (5.5,9); S1 = S2 = [[0.5,1],[1,2]]; S_W = [[1,2],[2,4]] is singular (|S_W| = 0): all points in each class lie on a line of slope 2.
  • So S_W⁻¹ does not exist. Choose w to make within-class scatter zero: w ⟂ (1,2), i.e. w = (2,−1)/√5 = (0.894, −0.447).
  • Projections: class 0 → 0.447, 0.447; class 1 → 0.894, 0.894. Within-class scatter is 0, so J(w) → ∞ (perfect separation). (Equivalent: use S_W + εI and let ε→0.)

Dataset 3 — ω1: (4,2),(2,4),(2,3),(3,6),(4,4); ω2: (9,10),(6,8),(9,5),(8,7),(10,8).

  • m1 = (3, 3.8), m2 = (8.4, 7.6); S1 = [[4,−1],[−1,8.8]], S2 = [[9.2,−0.2],[−0.2,13.2]]; S_W = [[13.2,−1.2],[−1.2,22]].
  • S_B = [[29.16,20.52],[20.52,14.44]]. w ∝ S_W⁻¹(m1−m2) = (−0.427,−0.196) → unit w = (0.909, 0.417).

A5a. Batch perceptron F24 · (1,2)+, (4,3)+, (3,−1)−, (−2,−2)−, w=[0,0], η=1
Read: B §4.1.7 "The perceptron algorithm"; D Ch. 5 §5.5 "Perceptron criterion".

Rule: with t = ±1, a sample is misclassified if t·wᵀx ≤ 0. Batch update: w ← w + η Σ_{misclassified} t·x.

  • Iter 1: w = (0,0), all scores 0, all misclassified. w = (1,2)+(4,3)−(3,−1)−(−2,−2) = (4, 8).
  • Iter 2: scores: (1,2) → 20 ✓, (4,3) → 40 ✓, (3,−1) → 4 but t = −1 ✗, (−2,−2) → −24 ✓. Update w = (4,8) − (3,−1) = (1, 9).
  • Iter 3: (1,2) → 19 ✓, (4,3) → 31 ✓, (3,−1) → −6 ✓, (−2,−2) → −20 ✓. No errors, stop.
w = (1, 9); boundary x1 + 9x2 = 0.

A6. Classify with Gaussian classes (equal priors) F24 · μ1=(0,0), μ2=(2,0), σ²=1 → x=(1,0) · S24 · Σ=[[2,.5],[.5,1]], μ1=(1,1), μ2=(3,−1) → x=(2.5,.5)

A14. Edit distance and Bellman's principle F23, S23i: google → doodle · F22: pattern → petern
Read: Dynamic programming / Bellman's optimality principle; the edit-distance table is the standard DP of Jurafsky & Martin, "Minimum Edit Distance" (Speech and Language Processing, Ch. 2).

Bellman's principle: an optimal solution is built from optimal solutions of its sub-problems. For edit distance, D(i,j) = min{ D(i−1,j)+1 (delete), D(i,j−1)+1 (insert), D(i−1,j−1) + (0 if s_i = t_j else substitution cost) }. Fill the table, then trace back.

  • google → doodle: g-o-o-g-l-e vs d-o-o-d-l-e. Only positions 1 and 4 differ. Operations: substitute g→d (position 1), substitute g→d (position 4). Distance = 2 (unit cost); if substitution costs 2 (insert + delete), distance = 4.
  • pattern → petern: p-a-t-t-e-r-n → p-e-t-e-r-n. Operations: substitute a→e, delete one t. Distance = 2 (unit cost; 3 with substitution cost 2).

S23's handwritten target word is hard to read; use the same table method on that word.

A16. Extreme values with constraints F23, S23i · f = x²+y², x+1 = 0, y+1 = 0

B. Derivations and proofs

B1. Bayes rule minimises average error · zero-one loss rule · minimum-risk rule S25, S24, S23, F24
Read: D Ch. 2 §2.1–2.3; B §1.5 "Decision Theory".

Bayes minimises error. P(error) = ∫P(error|x)p(x)dx. Choosing the class with the larger posterior gives P(error|x) = min[P(ω1|x), P(ω2|x)], the smallest possible value at every x. Any other rule picks the smaller posterior somewhere and adds error there. Since p(x) ≥ 0, minimising pointwise minimises the integral.

Zero-one loss. λ(α_i|ω_j) = 0 if i = j, else 1. Then R(α_i|x) = Σ_{j≠i}P(ω_j|x) = 1 − P(ω_i|x). Minimum risk = maximum posterior: decide ω_i if P(ω_i|x) > P(ω_j|x) for all j≠i. Risk equals error probability.

Minimum-risk rule, two classes. R(α1|x) = λ11P(ω1|x)+λ12P(ω2|x); R(α2|x) = λ21P(ω1|x)+λ22P(ω2|x). Decide ω1 if R(α1|x) < R(α2|x):

(λ21−λ11)P(ω1|x) > (λ12−λ22)P(ω2|x) ⇔ (λ21−λ11)p(x|ω1)P(ω1) > (λ12−λ22)p(x|ω2)P(ω2) (p(x) cancels) ⇔ p(x|ω1)/p(x|ω2) > [(λ12−λ22)/(λ21−λ11)]·P(ω2)/P(ω1) (if λ21 > λ11)

Role of the loss function in generalised decision theory: it sets the cost of each action/state pair, so unequal costs move the threshold (the fish-packing example).

B2. Gaussian discriminants: linear form, shared covariance, effect of priors S23, S23i, S24
Read: D Ch. 2 §2.6.2 "Case 2: Σ_i = Σ".

g_i(x) = ln p(x|ω_i) + ln P(ω_i) = −½(x−μ_i)ᵀΣ⁻¹(x−μ_i) − (d/2)ln2π − ½ln|Σ| + ln P(ω_i). Drop terms equal for all classes and expand; xᵀΣ⁻¹x is also common:

g_i(x) = w_iᵀx + w_i0, w_i = Σ⁻¹μ_i, w_i0 = −½μ_iᵀΣ⁻¹μ_i + ln P(ω_i) boundary: wᵀ(x − x0) = 0, w = Σ⁻¹(μ1−μ2) x0 = ½(μ1+μ2) − [ln(P(ω1)/P(ω2)) / ((μ1−μ2)ᵀΣ⁻¹(μ1−μ2))]·(μ1−μ2)

The boundary is a hyperplane, orthogonal to Σ⁻¹(μ1−μ2) (not to μ1−μ2 unless Σ ∝ I). Equal priors: x0 is the midpoint. If P(ω1) > P(ω2), x0 moves away from μ1 towards μ2, enlarging the region of the more probable class.

B3. Geometry of a linear discriminant and distance to the hyperplane F24, F23
Read: B §4.1.1 "Two classes"; D Ch. 5 §5.2.

g(x) = wᵀx + w0; boundary g(x) = 0. The weight vector w is normal to the hyperplane (for x_a, x_b on it, wᵀ(x_a−x_b) = 0) and points into the positive region; the bias w0 shifts the plane (distance from the origin is |w0|/‖w‖).

Distance by constrained minimisation (F23): minimise ‖x−x_a‖² subject to g(x) = 0. L = ‖x−x_a‖² + λ(wᵀx+w0). ∂L/∂x = 2(x−x_a)+λw = 0 → x = x_a − λw/2. Put into g(x) = 0: g(x_a) − λ‖w‖²/2 = 0 → λ = 2g(x_a)/‖w‖². Then ‖x−x_a‖ = |λ|‖w‖/2 = |g(x_a)|/‖w‖.

B4. SVM theory: margin, ½‖w‖², Lagrange multipliers, dual, KKT, kernel every paper
Read: B §7.1 "Maximum Margin Classifiers" with Appendix E; D Ch. 5 §5.11; B Ch. 6 §6.1–6.2 for kernels.

Margin = 2/‖w‖. Rescale (w,b) so the closest points obey y_i(wᵀx_i+b) = 1; this is allowed because (w,b) and (cw,cb) define the same plane. The distance from a point to the plane is |wᵀx+b|/‖w‖ = 1/‖w‖, so the total margin is 2/‖w‖.

Why minimise ½‖w‖² instead of maximising 2/‖w‖: maximising 2/‖w‖ is the same as minimising ‖w‖, which is the same as minimising ‖w‖² (monotonic). The squared form is smooth and convex (quadratic programme with a unique optimum), no square root, and the ½ cancels the 2 when differentiating (∂/∂w = w). Maximising 1/‖w‖ directly is awkward near w → 0.

Lagrange multipliers. Constraint y_i(wᵀx_i+b) − 1 ≥ 0 is attached with λ_i ≥ 0: L_P = ½‖w‖² − Σλ_i[y_i(wᵀx_i+b) − 1]. ∂L/∂w = 0 → w = Σλ_i y_i x_i; ∂L/∂b = 0 → Σλ_i y_i = 0. Substituting:

L_D = Σλ_i − ½ΣΣ λ_iλ_j y_i y_j (x_i·x_j), λ_i ≥ 0, Σλ_i y_i = 0 decision: f(x) = sgn(Σ λ_i y_i (x_i·x) + b)

KKT: λ_i[y_i(wᵀx_i+b) − 1] = 0. So λ_i > 0 only if y_i(wᵀx_i+b) = 1, i.e. the point lies on the margin (support vector) (S24 Q1b). Points with λ_i = 0 do not affect w. The boundary in terms of multipliers is f(x) = Σ_{SV}λ_i y_i x_i·x + b, which satisfies KKT as above (F23 Q2a).

Why solve the dual: (1) it depends on the data only through dot products x_i·x_j, so a kernel K(x_i,x_j) can replace them (kernel trick); (2) the number of variables equals the number of samples, not the number of features, so it is better when features are very many; (3) simple constraints; only support vectors matter. Strong duality holds (convex problem), so the optima agree.

Kernel trick, K(x,z) = (1+xᵀz)², 2-D: (1+x1z1+x2z2)² = 1 + 2x1z1 + 2x2z2 + x1²z1² + 2x1x2z1z2 + x2²z2² = φ(x)·φ(z) with φ(x) = (1, √2x1, √2x2, x1², √2x1x2, x2²). The kernel gives the 6-D dot product from a 2-D computation, with no explicit φ.

Why w is not computed in kernel SVM (S24): w = Σλ_i y_i φ(x_i) lives in feature space, which can be infinite-dimensional (RBF). Classify with f(x) = sgn(Σλ_i y_i K(x_i,x) + b) instead.

Soft margin (S24 Q3c, S23i): add slack ξ_i ≥ 0 with penalty C: minimise ½‖w‖² + CΣξ_i. The dual is the same as hard margin except 0 ≤ λ_i ≤ C. Points with λ_i = C are inside the margin or misclassified; C → ∞ recovers the hard margin.

B5. Perceptron convergence theorem S24, S23, F22
Read: B §4.1.7; D Ch. 5 §5.5.2 "Convergence proof for single-sample correction".

Replace class-2 samples by −x so a solution satisfies ŵᵀx_n > 0 for all n (‖ŵ‖ = 1, γ = min ŵᵀx_n > 0 exists when separable); R = max‖x_n‖. Each update is w_{k+1} = w_k + x (x misclassified, w_kᵀx ≤ 0), starting at w_0 = 0.

  • Lower bound: ŵᵀw_{k+1} = ŵᵀw_k + ŵᵀx ≥ ŵᵀw_k + γ, so ŵᵀw_k ≥ kγ and hence ‖w_k‖ ≥ kγ.
  • Upper bound: ‖w_{k+1}‖² = ‖w_k‖² + 2w_kᵀx + ‖x‖² ≤ ‖w_k‖² + R², so ‖w_k‖² ≤ kR².
  • Combine: k²γ² ≤ ‖w_k‖² ≤ kR² → k ≤ R²/γ². The number of updates is finite, so the algorithm terminates at a solution vector.
B6. MLE derivations F24 Gaussian mean · S23 multivariate Bernoulli
Read: D Ch. 3 §3.2.1–3.2.4 "The Gaussian case: unknown μ"; B §2.3.4 "Maximum likelihood for the Gaussian".

Gaussian mean, Σ known. ln p(D|μ) = −½Σ_k(x_k−μ)ᵀΣ⁻¹(x_k−μ) + const. ∇_μ = Σ_k Σ⁻¹(x_k−μ) = 0 → Σ_k x_k − nμ = 0 (Σ⁻¹ is invertible):

μ̂ = (1/n) Σ_k x_k

Multivariate Bernoulli. ln P(D|θ) = Σ_k Σ_i [x_ki ln θ_i + (1−x_ki) ln(1−θ_i)]. ∂/∂θ_i = Σ_k [x_ki/θ_i − (1−x_ki)/(1−θ_i)] = 0 → Σ_k x_ki(1−θ_i) = θ_iΣ_k(1−x_ki) → Σ_k x_ki = nθ_i:

θ̂_i = (1/n) Σ_k x_ki i.e. θ̂ = (1/n) Σ_k x_k
B7. MLE vs MAP vs Bayes · large-n limit S23i, F22
Read: D Ch. 3 §3.3–3.4 "Bayesian estimation: Gaussian case"; B §2.3.6 and §1.2.5.

MLE: θ is fixed but unknown, θ̂ = argmax p(D|θ). MAP: θ is random with prior p(θ), θ̂ = argmax p(D|θ)p(θ), a point estimate. Full Bayes: keep p(θ|D) and average over it. MLE has no prior, so unseen events get probability 0.

μ_n = [nσ0²/(nσ0²+σ²)]·x̄_n + [σ²/(nσ0²+σ²)]·μ0

Divide numerator and denominator by nσ0²: μ_n = x̄_n/(1 + σ²/(nσ0²)) + (σ²/(nσ0²))·μ0/(1 + σ²/(nσ0²)). As n → ∞, σ²/(nσ0²) → 0, so μ_n → x̄_n, the MLE (also σ_n² = σ0²σ²/(nσ0²+σ²) → σ²/n → 0). With enough data the prior is overridden. Same if σ0 → ∞ (vague prior).

B8. Uncorrelated 2-D Gaussian factorises F24, S24, S23
Read: D Ch. 2 §2.5 "The normal density"; B §2.3.

Uncorrelated means Σ = diag(σ1², σ2²), so |Σ| = σ1²σ2² and Σ⁻¹ = diag(1/σ1², 1/σ2²):

p(x) = 1/(2π√(σ1²σ2²)) · exp{ −½[(x1−μ1)²/σ1² + (x2−μ2)²/σ2²] } = [1/(√(2π)σ1) e^{−(x1−μ1)²/2σ1²}] · [1/(√(2π)σ2) e^{−(x2−μ2)²/2σ2²}] = N(x1; μ1, σ1²) · N(x2; μ2, σ2²)

The joint is the product of the marginals, so for Gaussians uncorrelated ⇔ independent. (This is also why Σ = σ²I gives circular contours.)

B9. d-bit parity is not linearly separable F22
Read: B §4.1.7 (limits of the perceptron); D Ch. 5 §5.1.

Take d = 2 (XOR): (0,0) and (1,1) → ω2 (even), (1,0) and (0,1) → ω1 (odd). A linear g = w1x1 + w2x2 + w0 would need g(0,0) < 0 → w0 < 0; g(1,0) > 0 → w1 + w0 > 0; g(0,1) > 0 → w2 + w0 > 0; g(1,1) < 0 → w1 + w2 + w0 < 0. Adding the middle two: w1 + w2 + 2w0 > 0, so w1 + w2 + w0 > −w0 > 0, contradicting the last. For d > 1 fix all other inputs at 0: any x that varies only in two coordinates reproduces this XOR sub-problem, so no single hyperplane works.

B10. PCA: role of eigenvalues and eigenvectors F24, S23, F23
Read: B §12.1.1 "Maximum variance formulation".

For centred data with covariance matrix S, the variance of the projection onto a unit vector u is uᵀSu. Maximise subject to uᵀu = 1: L = uᵀSu − λ(uᵀu − 1) → Su = λu and the variance equals λ. So eigenvectors of S are the principal directions and eigenvalues are the variances along them. The eigenvector with the largest eigenvalue is PC1; others are orthogonal because S is symmetric. Keep the top p eigenvectors; the fraction of variance retained is Σ_{top p}λ / Σλ. An eigenvector is a vector with Av = λv (A only rescales it).

B11. Backpropagation (error propagation layer by layer) F23, S23, S23i
Read: D Ch. 6 "Multilayer Neural Networks" §6.3 "Backpropagation algorithm". Not covered by the class slides I summarised, so check your lecture notes.

Three-layer net, input x_i → hidden y_j = f(net_j), net_j = Σ w_ji x_i → output z_k = f(net_k), net_k = Σ w_kj y_j. Error J = ½Σ_k(t_k − z_k)².

  • Output layer: ∂J/∂w_kj = (∂J/∂net_k)(∂net_k/∂w_kj) = −δ_k y_j with sensitivity δ_k = (t_k − z_k) f′(net_k). So Δw_kj = η δ_k y_j.
  • Hidden layer: ∂J/∂y_j = −Σ_k (t_k − z_k) f′(net_k) w_kj = −Σ_k w_kj δ_k, so δ_j = f′(net_j) Σ_k w_kj δ_k and Δw_ji = η δ_j x_i.
  • The error is propagated back: each hidden sensitivity is the weighted sum of the output sensitivities.

C. Short answers and reinforcement learning

C1. Q-learning pseudo-code, MDP, discounted reward S23, S23i, F22, S25 (DRL)
Read: SB Ch. 3 "Finite Markov Decision Processes", Ch. 6 §6.5 "Q-learning: off-policy TD control"; Mnih et al. (2015) for DQN.
initialise Q(s,a) = 0 for all s,a for each episode: s ← start state repeat until s is terminal: choose a from s using ε-greedy on Q take a; observe reward r and next state s' Q(s,a) ← Q(s,a) + α [ r + γ·max_a' Q(s',a') − Q(s,a) ] s ← s'
  • α: learning rate (how far to move towards the new estimate). r + γ·max Q(s',a'): the TD target (immediate reward plus discounted best future value). Bracket = TD error. γ: discount. ε: exploration probability.
  • MDP: states, actions, transition probabilities, rewards, discount. RL: the agent learns a policy that maximises expected return by interacting with the environment. Additive discounted reward G_t = Σ γ^k R_{t+k+1}, 0 ≤ γ < 1. Justification: the infinite sum stays finite, near rewards count more than uncertain distant ones, and it makes the Bellman recursion V = r + γV′ work.
  • DRL vs Q-learning (S25): tabular Q-learning stores one number per (s,a), which fails for large or continuous spaces. Deep RL (e.g. DQN) approximates Q(s,a;θ) with a neural network trained on loss (r + γ max Q_target(s',a') − Q(s,a;θ))², using experience replay and a target network for stability.
  • Recycling robot (S23 Q1b): states = (battery: high/low) × (can in front: yes/no) × (holding can: yes/no) [plus location: near charger/trash]. Actions: search/navigate, pick up, throw in trash, go to charger, charge, wait. Rewards: +1 for each can thrown into the trash, large negative (e.g. −10) if the battery dies, a small cost per step (e.g. −0.1) and 0 otherwise, with γ < 1. This pushes it to collect many cans while recharging before it is empty.
C2. Short definitions and comparisons S25, S24, F24, S23
  • Curse of dimensionality: the data needed to cover the feature space grows exponentially with dimension; data become sparse, distances less meaningful, and classifiers overfit (see chapter 1 notes; B §1.4).
  • Unsupervised learning: no labels; find structure such as clusters (k-means) or low-dimensional projections (PCA).
  • K-fold cross-validation: split into k folds; train on k−1, test on the remaining one; rotate k times; average the scores (chapter 10).
  • Random subsampling vs k-fold (S24): random subsampling repeats random train/test splits, so some points may never be tested and others several times; k-fold tests every sample exactly once, so its estimate has lower variance and is generally more robust.
  • MSE vs MAE: MSE squares errors, so outliers dominate; it is smooth, has a closed form, and is optimal for Gaussian noise (predicts the mean). MAE grows linearly, is robust to outliers, predicts the median, suits Laplace-like noise, but is not differentiable at 0. Choose MSE for clean data and MAE when outliers are present.
  • Mutually exclusive: cannot happen together, P(A∩B) = 0, P(A∪B) = P(A)+P(B); e.g. a coin showing head or tail. Non-exclusive: can happen together, P(A∪B) = P(A)+P(B)−P(A∩B); e.g. a card that is a heart or a king.
  • PCA vs LDA (S24): both project linearly (y = Wᵀx). PCA is unsupervised and keeps maximum variance; LDA is supervised and maximises between-class over within-class scatter (at most C−1 dimensions).
  • Regularisation in logistic regression: add λ‖w‖² (L2) or λ‖w‖₁ to the loss. Large weights are penalised, which reduces overfitting; λ too large underfits; L1 gives sparse weights.
  • Generative vs discriminative (F23, S23): generative models learn p(x|y)p(y) (Gaussian discriminant analysis, Naive Bayes) and classify by Bayes' rule; discriminative models learn p(y|x) or the boundary directly (logistic regression, SVM). Use Gaussian discriminant analysis for continuous, roughly Gaussian features; Naive Bayes for high-dimensional discrete data (text) with little data. Naive Bayes' strong assumption: features are conditionally independent given the class. Laplace smoothing stops a zero count from making the whole product zero.
  • Boosting vs bagging (F23, F22): bagging trains classifiers on bootstrap samples in parallel and averages them, which reduces variance. Boosting trains weak classifiers (a bit better than chance) sequentially, each focusing on earlier mistakes, which reduces bias and gives a strong classifier (low training error). AdaBoost: classifier weight α_t = ½ ln((1−ε_t)/ε_t); sample weights multiply by e^{α_t} if misclassified and e^{−α_t} if correct, then renormalise; final H(x) = sgn(Σα_t h_t(x)).
  • Model complexity, bias and variance (S23): low complexity: high bias, low variance (underfit); high complexity: low bias, high variance (overfit); test error is U-shaped (chapter 1, B §3.2).
