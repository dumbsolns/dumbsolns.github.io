Exam overview: everything taught in class

Ten topics in lecture order, with key formulas and book references. Chapter numbers refer to the editions most commonly used (Bishop 2006, Duda, Hart & Stork 2nd ed., Sutton & Barto 2nd ed.); check them against your own copy.

Course books: (B) Bishop, Pattern Recognition and Machine Learning; (D) Duda, Hart & Stork, Pattern Classification; (S) Schalkoff, Pattern Recognition: Statistical, Structural and Neural Approaches. Extra sources used in slides: (SB) Sutton & Barto, Reinforcement Learning; (M) Mitchell, Machine Learning; (T) Tan, Steinbach & Kumar, Introduction to Data Mining.

1. Introduction, features and the design cycle

Read: D Ch. 1 "Introduction" (fish example, design cycle); B Ch. 1 "Introduction" (curve fitting, model selection, curse of dimensionality); B §3.2 "The Bias-Variance Decomposition".
  • Pattern recognition: assigning an unknown object to a class from measured data. Two modes: classification (known categories) and clustering (learning categories). Applications: OCR, biometrics (fingerprint, iris, face), speech, medical diagnosis, bioinformatics, remote sensing, license plates.
  • Pattern class: a collection of similar objects. Difficulty comes from intra-class variability (many ways to write a "3") and inter-class similarity (identical twins, 0/D, 8/B).
  • Features are measurable quantities; together they form a feature vector x = (x1,...,xl)T in Rl, treated as a random vector.
  • Fish example (sea bass vs salmon): preprocessing, feature extraction, classification. Length alone overlaps heavily; lightness is better; length + lightness/width gives a 2-D feature space with a decision boundary. Unequal costs of errors shift the threshold. Adding features does not always help: avoid unreliable, correlated (redundant) or costly features. Too many features means the curse of dimensionality.
  • Design cycle: collect data → select features → select model → train classifier → evaluate. System pipeline: sensing → pre-processing → feature extraction → classification → post-processing. Good features are discriminative and invariant to translation, rotation and scale, and robust to occlusion, deformation and illumination.
  • Learning types: supervised (labels or costs given), unsupervised (find natural groupings), reinforcement (only right/wrong feedback).
  • Overfitting: perfect on training data, poor on unseen data. Causes: little data, too many features, overly complex model. Fixes: tune hyperparameters, reduce features, ensembles (e.g. random forest), regularization.
  • Bias-variance: high bias = too simple (underfits); high variance = too flexible (fits noise). Training error keeps falling with complexity while test error is U-shaped; pick the complexity at the minimum of test error.

2. Linear discriminants, least squares, perceptron

Read: B Ch. 4 "Linear Models for Classification": §4.1.1 Two classes, §4.1.2 Multiple classes, §4.1.3 Least squares for classification, §4.1.7 The perceptron algorithm. D Ch. 5 "Linear Discriminant Functions".
y(x) = wTx + w0 class C1 if y(x) ≥ 0, else C2 boundary: y(x) = 0 (w is normal to the hyperplane) signed distance of x: r = y(x) / ||w|| origin to hyperplane: -w0 / ||w||
  • w tilts the hyperplane; bias w0 shifts it from the origin.
  • K > 2 classes: one-versus-rest (K-1 classifiers), one-versus-one (K(K-1)/2 classifiers), or a single K-class discriminant (assign to class k if y_k(x) > y_j(x) for all j≠k). Both one-vs-rest and one-vs-one leave ambiguous regions; the K-class form does not. Its decision regions are singly connected and convex.
  • Least squares: minimise sum-of-squares error E = ½ Tr{(XW-T)T(XW-T)} with augmented inputs. Set the derivative to zero:
    W = (XTX)-1 XT T = X† T (X† = pseudo-inverse)
    Closed form, but sensitive to outliers and needs all data in memory.
  • Perceptron (Rosenblatt 1957; XOR limit shown by Minsky 1969; backprop revival 1986): feature map φ(x), targets t = ±1. A point is correct if wTφ(x)t > 0.
    E_P(w) = - ∑_{n in M} wTφ(x_n) t_n (M = misclassified points) update: w ← w + η φ(x_n) t_n
    Each update lowers the error of that point. Converges only if the data are linearly separable. Batch updates suit small data and stable tracking; single-sample (stochastic) updates suit big or streaming data. Class example: start w=(-2.5,1,0) on points (2,3)+, (3,2)+, (1,1)-; after updates w=(-3.5,1,1).

3. Support vector machines

Read: B Ch. 7 "Sparse Kernel Machines", §7.1 "Maximum Margin Classifiers" (with Appendix E "Lagrange Multipliers"); D Ch. 5 §5.11 "Support Vector Machines"; B Ch. 6 "Kernel Methods" for kernels.
  • Many hyperplanes separate the data; choose the one with the maximum margin (Vapnik & Chervonenkis, 1960s; popular after 1992).
  • Margin lines: w·x+b = +1 and -1, margin = 2/||w||. Maximising margin = minimising ½||w||²:
    minimise ½||w||² subject to y_i (w·x_i + b) ≥ 1
  • Lagrangian (primal): L_P = ½||w||² - ∑ λ_i [y_i(w·x_i+b) - 1]. Setting derivatives to zero gives w = ∑ λ_i y_i x_i and ∑ λ_i y_i = 0. Substituting gives the dual, a quadratic programme (solved by SMO / LIBSVM):
    L_D = ∑ λ_i - ½ ∑∑ λ_i λ_j y_i y_j (x_i · x_j) classify: f(z) = sign(w·z + b)
  • KKT conditions: λ_i ≥ 0 and λ_i[y_i(w·x_i+b) - 1] = 0. So either λ_i = 0 (point irrelevant) or the point lies exactly on the margin: a support vector. Only support vectors define w. Strong duality lets us swap min and max.
  • Soft margin: a single noisy point can shrink the margin, or make the problem infeasible. Add slack ξ_i ≥ 0 and penalty C: minimise ½||w||² + C∑ξ_i.
  • Non-separable data: map x to φ(x). The kernel trick computes φ(x)·φ(z) as K(x,z) without going to the high-dimensional space. This works because the dual depends only on dot products, which is why the dual is preferred over the primal.
  • Kernels: linear (already separable, many features); polynomial (γx·z + c)d (known feature interactions); RBF exp(-γ||x-z||²) (no prior knowledge, non-separable). Large γ = narrow bumps, tight boundary, overfitting; small γ = smooth boundary, underfitting.

4. Bayesian decision theory

Read: D Ch. 2 "Bayesian Decision Theory" (§2.1–2.10: minimum-error-rate classification, discriminant functions, normal density, error bounds, ROC, discrete and missing features, compound decisions); B §1.5 "Decision Theory".
  • Terms: prior P(ω_j), likelihood p(x|ω_j), evidence p(x), posterior P(ω_j|x).
    P(ω_j|x) = p(x|ω_j) P(ω_j) / p(x) posterior = likelihood × prior / evidence
  • Rules: priors only: pick the larger prior (same decision always). With x: decide ω1 if P(ω1|x) > P(ω2|x), equivalently p(x|ω1)P(ω1) > p(x|ω2)P(ω2), or the likelihood ratio p(x|ω1)/p(x|ω2) > P(ω2)/P(ω1). P(error|x) = min[P(ω1|x), P(ω2|x)]; Bayes rule minimises average error.
  • Where probabilities come from: objective (from experiments/histograms; car-price example: priors 0.183 / 0.817 gave posterior 0.438), subjective (assumed Gaussian, equal priors), or a mix (model plus data-fitted μ, Σ).
  • General theory: d-dim features, c classes, actions α_i (including reject), loss λ(α_i|ω_j).
    conditional risk: R(α_i|x) = ∑_j λ(α_i|ω_j) P(ω_j|x) Bayes rule: choose the α_i with minimum R(α_i|x); minimum overall risk = Bayes risk
    Two classes: decide ω1 if (λ21-λ11) p(x|ω1)P(ω1) > (λ12-λ22) p(x|ω2)P(ω2). With zero-one loss this reduces to maximum posterior and risk = error probability.
  • Discriminants: assign to ω_i if g_i(x) > g_j(x). Use g_i = P(ω_i|x), or g_i = ln p(x|ω_i) + ln P(ω_i). Any monotonically increasing f(g_i) gives the same decisions. Two classes: a single dichotomizer g = g1 - g2 (log-likelihood ratio).

  • Error bounds: Chernoff bound = minimise e-k(β) over β (1-D problem); Bhattacharyya sets β = 0.5 (easier, looser). Only good for Gaussians. Class example: k(0.5) = 4.06 gives P(error) ≤ 0.0087.
  • ROC: classifier threshold a = P(ω2)/P(ω1) (or b with losses); changing it trades false accepts (FAR) vs false rejects (FRR), e.g. biometric authentication of authentic vs impostor.
  • Discrete features: replace integrals with sums. Missing features: marginalise over the missing ones: P(ω_i|x_g) = ∫ P(ω_i|x_g,x_b) p(x_g,x_b) dx_b / p(x_g). Compound decisions: decide n patterns jointly when successive states are dependent.

5. Parameter estimation: MLE, Bayesian estimation, MAP

Read: D Ch. 3 "Maximum-Likelihood and Bayesian Parameter Estimation" (§3.2 Maximum Likelihood, §3.3–3.4 Bayesian Estimation: Gaussian case, §3.5 Problems of dimensionality); B §2.3.4 "Maximum likelihood for the Gaussian", §2.3.6 "Bayesian inference for the Gaussian", §1.2.5 "Curve fitting re-visited" (MAP).
  • Problem: priors and class-conditional densities are rarely known. Assume a parametric form (e.g. Gaussian) and estimate θ from training data. Priors are easy; densities, especially in high dimensions, are hard.
  • MLE: θ is fixed but unknown. Samples are i.i.d.; classes are treated separately.
    p(D|θ) = ∏_k p(x_k|θ) θ^ = argmax p(D|θ) = argmax ∑ ln p(x_k|θ) (set ∇_θ = 0)
  • Gaussian MLE: μ^ = (1/n)∑x_k, Σ^ = (1/n)∑(x_k-μ^)(x_k-μ^)T. Derivation uses ∇_μ ln p = Σ-1(x-μ).
  • Bias: estimator is unbiased if E[θ^] = θ. μ^ is unbiased with variance σ²/n (→ 0, so it converges). The ML variance is biased: E[σ^²] = ((n-1)/n)σ², an underestimate. The unbiased estimator divides by n-1 (Bessel's correction). Bias vs variance trade-off: usually reduce one at the expense of the other.
  • MLE limitation: unseen events get probability 0 (bag-of-words sentence with an unseen word has probability 0). A prior fixes this: Bayesian learning.
  • Bayesian estimation: θ is a random variable with prior p(θ); data revise it to the posterior.
    p(θ|D) = p(D|θ) p(θ) / ∫ p(D|θ)p(θ)dθ p(x|D) = ∫ p(x|θ) p(θ|D) dθ
  • Univariate Gaussian, unknown mean (prior N(μ0,σ0²)): posterior is Gaussian N(μ_n, σ_n²), a conjugate prior / reproducing density.
    μ_n = [nσ0²/(nσ0²+σ²)] x̄_n + [σ²/(nσ0²+σ²)] μ0 σ_n² = σ0²σ² / (nσ0²+σ²) → σ²/n for large n
    μ_n is the best guess, σ_n² the remaining uncertainty; the posterior sharpens as n grows.
  • MAP: θ^ = argmax p(x|θ)p(θ). For N = 1 Gaussian: θ = (σ0²x + σ²θ0)/(σ0²+σ²). If σ0 = 0, trust the prior fully (θ0); if σ0 → ∞, trust the data (MAP = MLE).

6. Principal component analysis (PCA)

Read: B §12.1 "Principal Component Analysis" (Ch. 12 "Continuous Latent Variables"); D Ch. 3 §3.8.1 "Principal Component Analysis (PCA)".
  • Goal: data compression / dimensionality reduction (2D→1D, 3D→2D) by keeping directions of maximum variance, because variation carries information. PC1 is the direction of largest spread; PC2 is orthogonal to it (zero redundancy). Components are blends of original features, not simply dropped features.
  • Background: mean, variance, covariance (positive: increase together; negative: opposite; zero: independent), covariance matrix S. Eigenvector: Av = λv; eigenvalues measure variation.
  • Derivation: for centred data X and unit vector u (uTu = 1), variance of projection = uTSu. Maximise with a Lagrange multiplier:
    L = uTSu - λ(uTu - 1) ⇒ Su = λu, variance = λ eigenvalues from det(S - λI) = 0
    Largest eigenvalue's eigenvector = PC1. S uses 1/(n-1).
  • Steps: (1) get data; (2) subtract mean; (3) covariance matrix; (4) eigenvectors and eigenvalues; (5) sort eigenvalues descending, keep top p (n→p dimensions) to form the feature vector; (6) new data = (feature vector)T × (centred data). Exact original data is recovered only if all eigenvectors are kept; otherwise information is lost.
  • PCA is unsupervised and ignores class labels.

7. Linear discriminant analysis (Fisher LDA)

Read: B §4.1.4 "Fisher's linear discriminant" and §4.1.6 "Fisher's discriminant for multiple classes"; D Ch. 3 §3.8.2 "Fisher Linear Discriminant" and §3.8.3 "Multiple Discriminant Analysis".
  • Objective: reduce dimension while preserving class discriminatory information (PCA ignores classes). Project onto a hyperplane of dimension C-1.
  • Fisher criterion (two classes): distance between projected means alone is not enough (it ignores spread). Maximise separation of means relative to within-class scatter:
    J(w) = (m~1 - m~2)² / (s~1² + s~2²) = (wT S_B w) / (wT S_W w) S_W = S1 + S2 (within-class), S_B = (μ1-μ2)(μ1-μ2)T (between-class, rank 1) solution: eigenvectors of S_W-1 S_B ; two classes: w* ∝ S_W-1(μ1 - μ2)
  • Worked example: ω1 = {(4,2),(2,4),(2,3),(3,6),(4,4)}, ω2 = {(9,10),(6,8),(9,5),(8,7),(10,8)}. Compute means, class covariances, S_W, S_B, then eigenvalues. The eigenvector with the largest eigenvalue (12.2) separates well; the one with eigenvalue ≈ 0 does not.
  • PCA vs LDA: PCA = maximum variance, unsupervised; LDA = maximum class separability, supervised.
  • Limitations: at most C-1 projections; parametric (assumes unimodal Gaussian classes); fails when the class information is in the variance rather than the mean.

8. Clustering: k-means and hierarchical

Read: D Ch. 10 "Unsupervised Learning and Clustering" (§10.6 Criterion Functions, §10.7 Iterative Optimization / k-means, §10.9 Hierarchical Clustering); B §9.1 "K-means Clustering"; T Ch. 8 "Cluster Analysis: Basic Concepts and Algorithms" (linkage methods).
  • Clustering: group objects so that intra-cluster distances are small and inter-cluster distances large. Needs a proximity measure, a criterion function, and an algorithm. Questions: how many clusters? Applications: gene expression, face and news clustering, marketing, land use, climate.
  • Distances: Euclidean (L2), Manhattan (L1), Chebyshev / supremum (L∞), Minkowski (∑|x_i-y_i|h)1/h. Similarity: cosine x·y/(||x|| ||y||) (scale invariant, text), correlation coefficient. Feature scaling can hurt if variance comes from cluster structure. Example: x1=(1,2), x2=(3,5): Euclidean 3.61, Manhattan 5, supremum 3.
  • SSE criterion: J = ∑_i ∑_{x in D_i} ||x - μ_i||², with μ_i the cluster mean; number of clusters fixed.
  • k-means (MacQueen 1967, partitional): (1) choose k seeds as centroids; (2) assign each point to the closest centroid; (3) recompute centroids; (4) repeat until no reassignments, no centroid change, or small SSE decrease. Results depend on seeds (can reach sub-optimal clusterings). Heuristics: random points, furthest-centre heuristic, multiple restarts, initialise from another method (e.g. Ward). Class example (k=2, m1=(1,1), m2=(5,7)) converged to {1,2} and {3..7} with centroids (1.25,1.5) and (3.9,5.1).
  • Hierarchical: agglomerative (bottom-up, merge two closest clusters, update distance matrix) or divisive (top-down split). A dendrogram records merges; cut it at a level to get clusters.
Inter-cluster distance Definition Strength / weakness
MIN (single link) closest pair Handles non-elliptical shapes; sensitive to noise and outliers
MAX (complete link) farthest pair Robust to noise; breaks large clusters; biased to globular
Group average mean of all pair distances Compromise; robust; biased to globular
Centroid distance between centroids Uses cluster centres only
Ward's increase in squared error on merge Robust; globular; hierarchical analogue of k-means
  • Cost: O(N²) space, O(N³) time (O(N² log N) for some methods). Pros: no fixed k; meaningful taxonomies. Cons: merges cannot be undone; no objective function directly minimised; trouble with sizes, shapes and outliers.

9. Reinforcement learning

Read: SB Ch. 3 "Finite Markov Decision Processes" (returns, value functions, Bellman equations, optimal policies); SB Ch. 6 "Temporal-Difference Learning" (§6.5 Q-learning); Mnih et al. (2015) "Human-level control through deep reinforcement learning" for DQN. Not covered by the three course textbooks.
  • Idea: when labelled examples are unavailable, an agent takes actions in an environment and receives a new state and a reward (chess, robots, driving).
  • MDP: states S, actions A, transition probability T(s,a,s'), reward R(s,a,s'), discount γ. A policy π(a|s) is the strategy; goal = optimal policy.
  • Return: G_t = R_{t+1} + γR_{t+2} + γ²R_{t+3} + .... The future is stochastic, so use expectations:
    V_π(s) = E_π[G_t | S_t = s] Q_π(s,a) = E_π[G_t | S_t=s, A_t=a] Bellman: V_π(s) = E[R_{t+1} + γ V_π(S_{t+1})] Q*(s,a) = E[R_{t+1} + γ max_a' Q*(S_{t+1}, a')] π* has V(s) = max_π V_π(s)
  • TD learning (transition probabilities unknown): use sampled target r + γV(s') and update incrementally: V(s) ← V(s) + α[r + γV(s') - V(s)].
  • Q-learning: Q(s,a) ← Q(s,a) + α[r + γ max_a' Q(s',a') - Q(s,a)]. With ε-greedy exploration: random action with probability ε, else best-known action.
  • Tabular Q-learning fails for huge state spaces (chess, driving). Fix: function approximation with a neural network. The TD error becomes an MSE loss ⇒ DQN.
  • Modern families: value-based (DQN); policy-based / actor-critic (PPO, SAC); RLHF (policy gradient guided by a reward model learned from human preferences, used in LLMs).
  • Class example (grid "combini"): 7×8 = 56 states; reward +1 at the combini, -1 at the lecture hall, -0.1 per step; the optimal policy gives the best direction at every state.

10. Evaluating learning methods

Read: M Ch. 5 "Evaluating Hypotheses" (confidence intervals, t-tests); B §1.3 "Model Selection" (cross-validation); D Ch. 9 §9.6 "Resampling for Estimating Statistics and Classifier Accuracy"; Fawcett (2006) "An introduction to ROC analysis".
  • Splitting: never let test labels influence learning. Training / validation (tuning) / test sets. A single split wastes data and can be unrepresentative. Learning curves plot accuracy against training size. Random resampling repeats splits; stratified sampling keeps class proportions.
  • Cross-validation: n folds, each fold tested once (e.g. 5 folds with 11+17+16+13+16 correct of 100 gives 73%). 10-fold is common; leave-one-out sets n = #instances. Internal CV inside each training set selects hyperparameters (e.g. k in k-NN). CV evaluates a learning method, not a single model.
  • Confusion matrix (TP, FP, FN, TN) and metrics:
    accuracy = (TP+TN)/(TP+FP+FN+TN) recall = TPR = sensitivity = TP/(TP+FN) FPR = FP/(FP+TN) = 1 - specificity precision = TP/(TP+FP) F1 = 2PR/(P+R) (harmonic mean)
    Accuracy misleads with class skew (99.9% by predicting all-negative on 9990:10) or unequal costs.
  • ROC curve: TPR vs FPR as the threshold varies. Build it by sorting scores high to low and updating TP/FP. Lowering the threshold raises both TPR and FPR (sensitivity up, specificity down). Points: (0,0) never positive; (1,1) always positive; (0,1) perfect; diagonal = random; northwest is better; left side = "conservative", upper right = "liberal". AUC: 0.9–1 excellent, 0.8–0.9 good, 0.7–0.8 fair, 0.6–0.7 poor, 0.5–0.6 fail. ROC is insensitive to class distribution and finds the best threshold for given costs.
  • Precision-recall curves: suit tasks with many negatives; default precision = fraction of positives. For CV, pool predictions, or average per-fold ROC curves.
  • Special classifiers: perfect (TPR 1, FPR 0, acc 1); worst (TPR 0, FPR 1); ultra-liberal (always +: TPR 1, FPR 1); ultra-conservative (always -: TPR 0, FPR 0, precision undefined).
  • Confidence interval on error (n ≥ 30, r errors): error = r/n, true error in error ± z_N √(error(1-error)/n), z = 1.96 for 95% (normal approximation of the binomial). Bootstrap: resample with replacement ~1000 times and take the 2.5% / 97.5% points.
  • Comparing systems: paired t-test on per-fold differences δ_i. Null: equal accuracy. t = δ̄ / √[ ∑(δ_i-δ̄)² / (n(n-1)) ], n-1 degrees of freedom; reject if p < 0.05. Use a two-tailed test (we do not know which is better). Sign test for small data. Also scatter plots and lesion studies (remove components to see their contribution).
  • Pitfalls: test data not representative; preprocessing (feature selection, tuning, thresholds) using labels outside the training fold; repeatedly tweaking on the same data (human overfitting).
