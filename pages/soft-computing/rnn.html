RNN, LSTM & GRU – Deep Dive

CSE 4237 · PDF pp. 343–378 (RNN, LSTM, GRU after Hung-yi Lee), 647–676 (vanilla RNN and GRU equations, handwritten notes), 813–843 (RNN/LSTM deck, after colah and cs231n). Tags: S25 F24 S24 F23 S23 S22 F22. Some RNN/LSTM question appeared in every exam.

1. Why recurrent networks?

PDF pp. 344–346, 366, 814–823

  • A fully connected network needs a fixed number of inputs x₁…xn. For text or speech n is large and growing, so the network would become too large. Humans also do not restart thinking every second: we understand each word from the previous words.
  • RNN idea: feed the inputs one at a time and re-use the same weights at each step, passing a hidden state (memory) forward: h′, y = f(h, x) (h and h′ have the same dimension). However long the sequence, there is only one function f. It is “another compression of the fully connected network”.
  • Feed-forward vs recurrent (p. 366): a feed-forward network has input only at the first layer and different parameters in each layer (at = σ(Wtat−1 + bt), t = layer); a recurrent network has an input at every time step and shares parameters across time (at = σ(What−1 + Wixt + b), t = time step).

2. The vanilla (naive) RNN

PDF pp. 350–351, 651–662, 817–830

st = φ( W·st−1 + U·xt + b )  ·  yt = softmax( V·st )
The slides’ “naive RNN” (p. 350): h′ = σ(Whh + Wix), y = softmax(Woh′) (bias ignored). Equivalent forms: st = φ(W[st−1, xt]) with the weight matrices concatenated (p. 659). φ is usually tanh.
  • The state is a single “hidden” vector; the same W, U, V are used at every step (p. 823). Shapes (p. 651): s is n×1, W is n×n, U is n×m, x is m×1.
  • Training (p. 825): unfold the network over time and treat it as one big feed-forward network; compute gradients by ordinary backpropagation (backpropagation through time, BPTT) and update the shared weights with the sum of the gradients from every step.
  • Input/output configurations (pp. 817–821): one-to-one (plain network); one-to-many (image → sequence of words, captioning); many-to-one (sequence of words → sentiment); many-to-many (sequence → sequence, machine translation; also frame-level video classification).
  • Sentiment classification (pp. 826–828): convert words to embeddings, feed them one by one; only the last output matters: a sigmoid there gives positive/negative, and the cost is computed from the last step and the label.
  • Language modelling (p. 830): the output at each step is a softmax over the vocabulary predicting the next word.

4. Problems of the naive RNN: forgetting and vanishing/exploding gradients

PDF pp. 352, 831–835 · F22 S25 S24

  • Short memory: on a time series the naive RNN tends to forget old information (p. 352). “The clouds are in the sky”: little context needed. “I grew up in France… I speak fluent French”: the clue is far away. In theory an RNN can learn such long-term dependencies, in practice it cannot (pp. 831–833).
  • Why: backpropagation through time multiplies the gradient by the same matrix (and the activation derivative) at every step: ∂L/∂sk = ∂L/∂sT · Πt=k+1..T (Wᵀ·diag φ′(·)). “In the same way a product of k real numbers can shrink to zero or explode to infinity, so can a product of matrices” (p. 834).
  • Vanishing: if the effective factor per step is below 1 (small W, tanh′ ≤ 1) the gradient shrinks exponentially: 0.5²⁰ ≈ 10⁻⁶, so early inputs hardly affect learning. Exploding: factor above 1: 1.5²⁰ ≈ 3,300, unstable updates.
  • Other flaws: sequential computation (cannot parallelise over time), one state vector bottleneck.
Remedies (F22 “flaws of RNN and a solution”, 4 marks): flaws: forgetting of distant information and vanishing/exploding gradients. Solutions: LSTM or GRU (gated memory path, slides p. 835 “LSTMs do not have this problem”), gradient clipping for exploding gradients, truncated BPTT, careful initialisation; later, attention/Transformers.

5. LSTM: structure and gates

PDF pp. 353–363, 836–842 · F24 S22: structure and roles of the gates

The LSTM (Hochreiter & Schmidhuber, 1997) is a special RNN. A plain RNN repeating module has a single tanh layer; the LSTM module has four interacting layers and a separate cell state Ct that runs along the top “conveyor belt”: it is changed only slowly, by minor linear interactions, so information can flow along it unchanged (p. 354, 839). Gates are sigmoid layers (output 0 to 1) multiplied point-wise: 0 = let nothing through, 1 = let everything through.

Gate / stepEquation (colah form, pp. 840–842)Role
Forget gate ft (green, “controls forget”)ft = σ(Wf·[ht−1, xt] + bf)decides what part of the old cell state Ct−1 to keep (1) or erase (0)
Input gate it and candidate C̃tit = σ(Wi·[ht−1, xt] + bi), C̃t = tanh(WC·[ht−1, xt] + bC)input gate decides which components to update; the tanh layer proposes the new content

Lecture notation (Hung-yi Lee, pp. 360–362): four matrix computations from the same input [xt, ht−1]: z = tanh(W[x,h]) (update information), zi = σ(Wi[x,h]) (input gate), zf = σ(Wf[x,h]) (forget gate), zo = σ(Wo[x,h]) (output gate). Then ct = zf ⊙ ct−1 + zi ⊙ z, ht = zo ⊙ tanh(ct), yt = σ(W′ht). These four computations are done concurrently as one big matrix product.

  • Naive RNN vs LSTM (p. 359): in the RNN h changes fast (ht and ht−1 can be very different), whereas in the LSTM the memory c changes slowly (ct = ct−1 plus something) while h changes fast.
  • Why sigmoid and tanh (pp. 354–355): sigmoid gives a 0–1 “switch” for the three gates; tanh (bounded, differentiable, monotonic, with a second derivative that persists over a long range) keeps the vanishing-gradient problem under control; ReLU can replace tanh as an alternative, but know the trade-offs.
One LSTM step with numbers (scalar): x = 1, ht−1 = 0.5, Ct−1 = 2; f: weights (1, 1, 0) → f = σ(1.5) = 0.8176; i: (0.5, 0.5, 0) → σ(0.75) = 0.6792; candidate (1, 1, 0) → tanh(1.5) = 0.9051; o: (1, 1, 0) → σ(1.5) = 0.8176. Ct = 0.8176·2 + 0.6792·0.9051 = 2.2499; ht = 0.8176·tanh(2.2499) = 0.7996.

6. How the LSTM solves the vanishing-gradient problem

PDF pp. 354–355, 835 · S24 Q4c (7 marks): “using appropriate equations”

  1. RNN: st = φ(Wst−1 + Uxt + b) so ∂st/∂st−1 = diag(φ′)·W and over k steps the gradient is a product of k such matrices, which vanishes (norm < 1) or explodes (norm > 1).
  2. LSTM cell state is updated additively: Ct = ft ∗ Ct−1 + it ∗ C̃t. Hence along the cell path ∂Ct/∂Ct−1 = ft (element-wise, plus gate-dependence terms that are small), and over k steps ∂Ct/∂Ct−k ≈ Πj ft−j+1.
  3. If the forget gate is close to 1 the product stays near 1: the gradient flows back almost unchanged (a “highway”, like a residual connection), and the network can learn to keep f≈1 where long memory is needed and f≈0 where it should reset. There is no repeated multiplication by the same W along this path.
  4. Gates are learned from data, so the network chooses what to remember; the input gate protects the cell from irrelevant inputs and the output gate protects the rest of the network from irrelevant memory.
Numbers: after 20 steps a plain RNN factor 0.5 gives 0.5²⁰ ≈ 9.5×10⁻⁷, an LSTM forget gate 0.95 gives 0.95²⁰ ≈ 0.36; after 50 steps 0.99⁵⁰ ≈ 0.61 vs 0.9⁵⁰ ≈ 0.005. (Use the calculator below.)

7. Peephole LSTM

PDF pp. 358, 361 · F23: differences between LSTM and peephole LSTM (4 marks)

In the standard LSTM the gates see only [ht−1, xt], so the gates cannot look at the cell state they control. The peephole variant (Gers & Schmidhuber) lets the gates “peep into the memory” by also feeding the cell state:

ft = σ(Wf·[Ct−1, ht−1, xt] + bf) · it = σ(Wi·[Ct−1, ht−1, xt] + bi) · ot = σ(Wo·[Ct, ht−1, xt] + bo)
The forget and input gates use the old cell state Ct−1; the output gate uses the new cell state Ct. The peephole connections are diagonal (each gate unit sees only its own cell component), p. 361.

8. GRU: gated recurrent unit

PDF pp. 364–365, 663–673 (equations) · S22 F22: RNN/LSTM comparisons

The GRU (Cho et al., 2014) is “more compression” of the LSTM: it combines the forget and input gates into a single update gate and merges the cell state and hidden state (no separate cell layer), so it is simpler than the LSTM (p. 364). The ht values passed along either retain much old information or are jump-started with new information (p. 365).

Equations (p. 673): zt = σ(Wz·[ht−1, xt]) (update gate) · rt = σ(Wr·[ht−1, xt]) (reset gate) · h̃t = tanh(W·[rt ∗ ht−1, xt]) (candidate) · ht = (1 − zt) ∗ ht−1 + zt ∗ h̃t
  • Reset gate rt: how much of the previous state is read when forming the candidate (r = 0 ignores the past).
  • Update gate zt: how much of the state is replaced by the candidate; it is both forget and write gate: (1 − z) keeps the old state, z writes the new one.
  • Other convention (pp. 663–671): rt = σ(Wrst−1 + Urxt + br), zt = σ(Wzst−1 + Uzxt + bz), s̃t = φ(W(rt∘st−1) + Uxt + b), st = zt∘st−1 + (1 − zt)∘s̃t (z is the “forget” gate here, so z = 0 replaces all memory with the candidate, p. 671). The roles of z and 1−z are swapped between the two slide sets; write the convention you use.

10. Applications and attention

PDF pp. 367–378 · S25 mentions: sentiment analysis

  • Neural machine translation (p. 368): an encoder LSTM reads the source sentence; a decoder LSTM produces the target (sequence-to-sequence).
  • Chat model (pp. 369–370): seq2seq conversation, with context kept over turns (hierarchical encoder-decoder, Serban et al. 2015).
  • Speech recognition (p. 371): Baidu’s Deep Speech uses RNNs. Others: sentiment classification, language modelling, video classification, image captioning (pp. 817–830).
  • Attention (pp. 372–377): for image captioning a CNN gives a vector per image region; the LSTM state z₀ is matched with each region to produce weights (e.g. 0.7, 0.1, 0.1, 0.1, 0, 0), the weighted sum is fed to the LSTM to emit word 1, the new state z₁ gives new weights (0, 0.8, 0.2, …) for word 2, and so on (“Show, Attend and Tell”, Xu et al. 2015). Attention removes the single-vector bottleneck; Transformers (see the Transformer page) build on it.

Why: the same weights are multiplied at every step in BPTT, gradients vanish over long gaps (§4). LSTM: forget gate ft keeps old memory (Ct = ft∗Ct−1 + it∗C̃t), input gate decides what new information is written (§5–6). Traps

  • The cell state C and hidden state h are different; GRU merges them.
  • Gates use sigmoid (0–1); candidate and output squashing use tanh.
  • LSTM has 3 gates, GRU 2; peephole adds the cell state to the gate inputs, it does not add a gate.
  • The update is element-wise (∗ or ⊙), not a matrix product.
  • State which GRU convention you use (z versus 1 − z).
  • LSTM mitigates vanishing gradients; exploding gradients still need clipping.

Likely short questions

  • Why RNN over a feed-forward network; what is shared across time; BPTT.
  • Many-to-one vs many-to-many examples; sentiment classification set-up.
  • Why sigmoid in gates and tanh for the cell candidate; GRU vs LSTM.
