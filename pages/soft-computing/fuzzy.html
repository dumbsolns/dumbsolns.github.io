Fuzzy Logic & Neuro-Fuzzy (ANFIS) – Deep Dive

CSE 4137/4237 · Part A – Fuzzy logic (sections 1–12): PDF pp. 22–34, 474–522, 677–701, 747–785. Part B – Neuro-fuzzy (sections 13–20): PDF pp. 110–127 (ANFIS) and 786–812 (neuro-fuzzy system, worked example). Tags: S25 Spring 2025 … F22 Fall 2022 show where a topic was asked.

1. Why fuzzy logic?

PDF pp. 22–34, 677–690

Classical (Boolean) logic answers only true/false. Human concepts such as hot, tall, slow, heavy have no sharp edge: is 5′9″ tall? Fuzzy logic (L. A. Zadeh, 1965) replaces the two truth values with a degree of truth in [0,1], which is why it models human reasoning and is the “uncertainty / vagueness” part of soft computing.

Crisp (Boolean)Fuzzy
Membership0 or 1any value in [0,1]
Boundarysharp thresholdgradual transition
Question“Is the room hot?” → Yes/No“How hot?” → Very (0.85), Little (0.3)…
ExampleIsa is 5′10″: TRUEIsa is tall: possibly true (0.7)

Fuzzy vs probability p. 689

Probability measures the chance that a crisp event occurs (70% chance it is hot). Fuzzy membership measures how much a thing belongs to a vague class (it is hot to degree 0.7, no randomness involved). Probabilities over all outcomes sum to 1; memberships need not.

Doctor analogy p. 33

A doctor asks about symptoms, correlates them with diseases with some uncertainty and prescribes medicine fuzzily. Fuzzy systems do the same: vague inputs → rules → graded output.

Model answer (3 marks): “Fuzzy logic is a multi-valued logic that handles vagueness using degrees of truth between 0 and 1. Example: temperature 30 °C belongs to warm with 0.6 and hot with 0.2. The membership function maps every crisp input to its degree of membership in a fuzzy set and so converts a crisp value into linguistic terms (fuzzification).” S24 F23 S23 F24 S22

2. Fuzzy sets and their vocabulary

PDF pp. 683–688

A fuzzy set A on universe X is A = {(x, μA(x)) | x∈X}, with μA: X→[0,1]. Two ways to write it:

  • Discrete: A = 0.1/1 + 0.3/2 + 0.7/3 + 1/4 + …. Read “μ/x”; the + and / are notation, not arithmetic.
  • Continuous: A = ∫ μA(x)/x, or a formula for μA(x).
TermMeaning
Support{x : μ(x) > 0}
Core{x : μ(x) = 1}
Heightmax μ(x); the set is normal if height = 1
Crossover pointx where μ(x) = 0.5
Fuzzy numbernormal, convex fuzzy set on ℝ with one peak (e.g. “about 4”)

A crisp set is the special case where every μ is 0 or 1, so every fuzzy-set rule reduces to classical set theory.

3. Membership functions (MFs)

PDF pp. 692–701 · Jang Ch. 2 · Ross Ch. 4

The MF is the fuzzy set: it fixes how gradual the boundary is. Standard shapes (a, b, c, d are parameters):

TypeFormula
Triangularmax(min((x−a)/(b−a), (c−x)/(c−b)), 0)
Trapezoidalmax(min((x−a)/(b−a), 1, (d−x)/(d−c)), 0)
Gaussianexp(−(x−c)²/(2σ²))
Generalized bell1 / (1 + |(x−c)/a|2b)
Sigmoidal1 / (1 + e−a(x−c)) (open-ended, “large”/“small”)

How to write the equation from a graph S25 F22 S24 F23

  1. List the corner points where the slope changes (and the value there).
  2. For each straight piece use the two-point line: rising (x−a)/(b−a), falling (c−x)/(c−b); flat parts are constant 1 or 0.
  3. Write each piece with its x-interval, then check continuity: at every break point the two neighbouring pieces must give the same value.

4. Operations on fuzzy sets

Ross Ch. 2 · Jang Ch. 2

  • Union: μA∪B(x) = max(μA, μB) · Intersection: min(μA, μB) · Complement: 1 − μA
  • Other t-norms/s-norms: algebraic product μAμB (AND), algebraic sum a+b−ab (OR). Mamdani rule inference uses min or product.
  • Laws that still hold: commutative, associative, distributive, De Morgan, idempotent.
Fuzzy ≠ crisp: the law of excluded middle and non-contradiction fail. A ∪ A′ ≠ X and A ∩ A′ ≠ ∅: for μ=0.3, max(0.3,0.7)=0.7 < 1 and min(0.3,0.7)=0.3 > 0.
A = {0.2/a, 0.6/b, 1/c}, B = {0.5/a, 0.4/b, 0.9/c}: A∪B = {0.5/a, 0.6/b, 1/c}; A∩B = {0.2/a, 0.4/b, 0.9/c}; A′ = {0.8/a, 0.4/b, 0/c}.

5. α-cut (alpha-cut) principle

PDF pp. 491–504

Aα = {x : μA(x) ≥ α} is a crisp set (an interval for a fuzzy number): Aα = [a₁(α), a₂(α)]. Higher α → narrower interval. Resolution theorem: a fuzzy set is rebuilt from its cuts, μA(x) = maxα min(α, 1A_α(x)).

Fuzzy arithmetic by α-cuts (interval arithmetic at every level): A + B = [a₁(α)+b₁(α), a₂(α)+b₂(α)]. It gives the same answer as the extension principle with less work.

6. Extension principle and fuzzy addition

PDF pp. 474–490 · F24 F22 S23 F23

Extends a crisp function z = f(x,y) to fuzzy inputs: μC(z) = maxx+y=z min(μA(x), μB(y)) for addition (sup–min composition). For multiplication use x·y=z in the same formula.

Slide method (3 steps)

  1. Step 1: draw a grid with the support of A on one side and of B on the other; fill each cell with min(μA(x), μB(y)).
  2. Step 2: group cells on the same anti-diagonal (equal x+y) — they all give the same z.
  3. Step 3: take the max of each diagonal as μC(z).

7. Fuzzy relations and composition

PDF pp. 505–522 · S24 F23 S23 F22 · Ross Ch. 3

A fuzzy relation R on X×Y is a fuzzy set of pairs, written as a matrix of μR(x,y). The Cartesian product of two fuzzy sets is μA×B(x,y) = min(μA(x), μB(y)). Composition chains R₁ (X×Y) and R₂ (Y×Z) into T (X×Z): like matrix multiplication where “sum of products” becomes “max over y of (some operation)”.

TypeμR₁∘R₂(x,z)
Max-minmaxy min(μR₁(x,y), μR₂(y,z))
Max-productmaxy μR₁(x,y)·μR₂(y,z)
Max-averagemaxy ½(μR₁(x,y)+μR₂(y,z)) (slide writes it as ½·max of the sums)
Worked example. R₁ = [[0.6, 0.3],[0.2, 0.9]] (rows x₁,x₂; columns y₁,y₂), R₂ = [[1.0, 0.5],[0.3, 0.8]] (rows y₁,y₂; columns z₁,z₂). Take row of R₁ and column of R₂ and combine element-by-element, then max.

Dimensions must match (columns of R₁ = rows of R₂). Show one full row-column calculation for each entry or the marker cannot award method marks. Composition is generally not commutative.

8. Fuzzy inference systems

PDF pp. 32, 682, 747–785 · Ross Ch. 5 · Jang Ch. 3–4

Pipeline: crisp input → fuzzifier (MFs give degrees) → rule base + inference engine (IF x₁ is A and x₂ is B THEN y is C) → aggregation → defuzzifier → crisp output. In a rule, AND = min (or product), OR = max.

Mamdani system (fuzzy consequent)

  1. Fuzzify each input with its MFs.
  2. Firing strength of rule k: αk = min(μA(x₁), μB(x₂)) (OR → max).
  3. Max-min method: clip each consequent set at αk (min(αk, μC_k(y))). Max-product method: scale it (αk·μC_k(y)) — keeps the shape.
  4. Aggregate all rules with max, then defuzzify (centroid etc.).

Sugeno / TSK system (function consequent)

Rule: IF x₁ is A and x₂ is B THEN z = px₁ + qx₂ + r (zero-order: z = constant). Output is a weighted average: y = Σ wk zk / Σ wk with wk = min(μA(x₁), μB(x₂)) (or product). No separate defuzzification step, so it is faster and is the model ANFIS learns.

MamdaniSugeno
Consequentfuzzy setlinear function / constant
Defuzzificationneeded (centroid …)weighted average
Interpretabilityhigherlower, more efficient
Typical useexpert-built controllersadaptive / neuro-fuzzy (ANFIS)

9. Defuzzification

Ross Ch. 4 · PDF p. 784 (trapezoid centroid)

  • Centroid (centre of gravity): y* = ∫ μ(y)·y dy / ∫ μ(y) dy, discrete Σ μ(yi)yi / Σ μ(yi). Most common, uses the whole aggregated shape.
  • Weighted average (height) method: y* = Σ μk ȳk / Σ μk, where ȳk is the centroid of the k-th clipped set. Used in the slides’ example below.
  • Mean of maxima, first/last of maxima: use only the points where μ is maximal; fast but ignores the rest of the shape.
  • Trapezoid centroid (slide formula, clipped triangle with top length a, base b, offsets c, d): x̄ = b/2 + (2a+b)(c²−d²) / (6(b²−a²)).

12. Exam kit – fuzzy logic

Mini-answers

  • Crisp vs fuzzy set F22: crisp 0/1, sharp boundary, Boolean; fuzzy [0,1], gradual, handles vagueness (table in §1).
  • Advantages of a fuzzy system F22: human-like linguistic rules, tolerates imprecise inputs, no exact mathematical model, easy to modify, robust, good for non-linear control. Limitation: no learning, rules/MFs need an expert. Neuro-fuzzy fixes this: an NN tunes MFs and rules (Part B below: NFS and ANFIS).
  • Role of the MF S24: converts crisp input into a degree of membership; defines the fuzzy set; its shape controls sensitivity; used in fuzzification and (output MFs) defuzzification.

Traps checklist

  • Extension principle: min inside, max across a diagonal; peak must land on the sum of peaks.
  • Max-average = max of the average, not average of the max.
  • Always check continuity of piecewise MFs; mention typos if the printed formula is inconsistent.
  • Mamdani: clip (max-min) vs scale (max-product). Sugeno: weighted average, not sum.
  • Show intermediate tables; marks go to method.

13. Why combine neural networks and fuzzy logic?

PDF pp. 110, 113–114, 786 · S25 F23 F22

Neural networkFuzzy system
Strengthlearns from data and feedback; adaptseasy to comprehend: linguistic terms and if-then rules
Weakness“black box”: hard to see what each neuron or weight meansno learning algorithm; MFs and rules must come from an expert or be identified by other techniques

The two are complementary technologies, so it is natural to marry them: the network supplies learning, the fuzzy part supplies interpretability and the use of prior knowledge (p. 113).

Three categories of neuro-fuzzy system (p. 114)

  1. A fuzzy rule-based model constructed with a supervised NN learning technique (e.g. backprop);
  2. one constructed with reinforcement-based learning;
  3. one that uses an NN to construct the fuzzy partition of the input space (find the MFs/rules).

Two common ways of combining (p. 786): (1) the Neuro-Fuzzy System (NFS): a fuzzy logic controller represented by the structure of an NN and trained by backprop or a GA; (2) ANFIS, a class of adaptive networks functionally equivalent to a fuzzy inference system (p. 115), covering both Sugeno and Tsukamoto models.

14. Online (pattern) vs batch backpropagation

PDF pp. 111–112

  • Online / pattern mode: weights are adjusted after each input-output pair. Slide example: 500 training pairs → each weight is adjusted 500 times per sweep; after 1000 sweeps, 500 × 1000 = 500,000 adjustments (the slide prints 50,000; the arithmetic gives 500,000).
  • Batch mode (off-line): weights are adjusted once per sweep, after the whole training set has been processed, using the error of the entire set → each weight adjusted 1000 times after 1000 sweeps.
  • Online is faster per update and noisier; batch gives a smoother, exact-gradient update.

15. Neuro-fuzzy system (NFS) based on the Mamdani approach

PDF pp. 786–812 · F22: how a neuro-fuzzy system can be built

A fuzzy logic controller (FLC) is drawn as a 5-layer feed-forward network. The weights are not arbitrary: they encode the membership-function parameters, and training by backpropagation (or a GA) tunes them.

LayerFunctionOperation
1 · Inputlinear transfer functionoutputs equal the inputs
2 · FuzzificationMF of each linguistic termμterm(input)
3 · ANDlogical AND of antecedentsmin of the input memberships (rule firing strength)
4 · Fuzzy inferenceconsequent (clipped output set) of each fired rulemin(strength, output MF)
5 · Defuzzificationcenter of sumsO = Σ Aifi / Σ Ai (Ai = area, fi = centroid of the i-th clipped set)

Worked example from the slides (pp. 796–812)

Setup: two inputs I₁ (terms Near NR, Far FR, Very Far VFR) and I₂ (Small SM, Medium M, Large LR), one output O (Low LW, High H, Very High VH). All MFs are triangles; the base-width parameters of the triangles are the weights (v for inputs, w for the output). Starting values: I₁ = 1.6, I₂ = 18.0, target O = 9.0. Rule base (rows I₁, columns I₂): NR → LW, LW, LW · FR → H, H, VH · VFR → VH, VH, VH.

Weights: normalised weights [v₁₁ v₂₄ w₁₁] = [0.3, 0.6, 0.4] are mapped into the allowed ranges 0.5 ≤ b₁ ≤ 1.5, 5 ≤ b₂ ≤ 15, 2 ≤ b₃ ≤ 8 by b = n·(max − min) + min: b₁ = 0.3·1 + 0.5 = 0.8, b₂ = 0.6·10 + 5 = 11.0, b₃ = 0.4·6 + 2 = 4.4. This places the triangle peaks at NR 1.0, FR 1.8, VFR 2.6 (I₁); SM 10, M 21, LR 32 (I₂); LW 5.0, H 9.4, VH 13.8 (O).

  1. Layer 1: outputs 1.6 and 18.0.
  2. Layer 2 (fuzzification): I₁ = 1.6 lies between NR and FR: μNR = (1.8−1.6)/0.8 = 0.25, μFR = (1.6−1.0)/0.8 = 0.75. I₂ = 18: μSM = (21−18)/11 = 0.272727, μM = (18−10)/11 = 0.727272.
  3. Layer 3 (AND = min): of the 3×3 = 9 combinations only four are non-zero: NR∧SM = min(0.25, 0.2727) = 0.25; NR∧M = 0.25; FR∧SM = min(0.75, 0.2727) = 0.272727; FR∧M = min(0.75, 0.7273) = 0.727272.
  4. Layer 4 (inference): rules fired: (NR, SM) → LW at 0.25; (NR, M) → LW at 0.25; (FR, SM) → H at 0.272727; (FR, M) → H at 0.727272. Each output triangle is clipped at its strength.
  5. Layer 5 (center of sums): areas and centroids of the clipped sets: A₁ = 0.9625, f₁ = 6.466667 (LW @0.25); A₂ = 0.9625, f₂ = 6.466667; A₃ = 2.072724, f₃ = 9.4 (H @0.2727); A₄ = 4.072722, f₄ = 9.4.
    O = (0.9625·6.4667 + 0.9625·6.4667 + 2.0727·9.4 + 4.0727·9.4) / (0.9625 + 0.9625 + 2.0727 + 4.0727) = 70.215/8.0704 = 8.7003. Target 9.0, deviation d = 9.0 − 8.700328 = 0.299672. Backpropagation uses this error to change the base-width weights, re-shaping the MFs until the output matches.
Do not confuse with ANFIS: this NFS is Mamdani-type (fuzzy consequents, defuzzification by center of sums, MF widths as weights), whereas ANFIS is Sugeno-type (linear consequents, weighted average).

16. ANFIS: adaptive neuro-fuzzy inference system

PDF pp. 115–127 · S25 F24: five layers, which layers learn

ANFIS (Jang, 1993) is an adaptive network that is functionally equivalent to a fuzzy inference system; the slides show the Sugeno and the Tsukamoto versions. Take two inputs x, y, one output f and a two-rule first-order Sugeno model (p. 118):

  • Rule 1: IF x is A₁ AND y is B₁ THEN f₁ = p₁x + q₁y + r₁
  • Rule 2: IF x is A₂ AND y is B₂ THEN f₂ = p₂x + q₂y + r₂

Overall output: f = (w₁f₁ + w₂f₂)/(w₁ + w₂) = w̄₁f₁ + w̄₂f₂ (p. 116).

2 Rule / firing strength (p. 121)fixed (Π)O2,i = wi = μAi(x) · μBi(y) (the slide writes min; both are AND operators)each node is one rule; output = firing strength
3 Normalisation (p. 122)fixed (N)O3,i = w̄i = wi / (w₁ + w₂)ratio of the i-th rule’s strength to the sum of all strengths
4 Consequent (p. 123)adaptive (square)O4,i = w̄i fi = w̄i(pix + qiy + ri)consequent parameters {pi, qi, ri}

  • Alternate form (p. 125): normalisation done at the very last layer: f = Σ wifi / Σ wi.
  • Tsukamoto model (p. 126): consequent MFs are monotonic; each rule’s crisp output zi comes from its firing strength through the inverse MF; the output is Σ wizi / Σ wi.
  • 2 inputs, 9 rules (p. 127): three MFs on each input with grid partition → 3×3 = 9 rules, each region of the input square has its own consequent. With n inputs and m MFs each there are mⁿ rules (rule explosion for many inputs).

17. ANFIS worked example and explorer

By hand (membership grades given). x = 2, y = 3: μA₁ = 0.6, μA₂ = 0.4, μB₁ = 0.5, μB₂ = 0.8; f₁ = x + y + 1, f₂ = 2x − y + 2. Then f₁ = 6, f₂ = 3.
Product AND: w₁ = 0.6·0.5 = 0.30, w₂ = 0.4·0.8 = 0.32; w̄₁ = 0.30/0.62 = 0.4839, w̄₂ = 0.5161; f = 0.4839·6 + 0.5161·3 = 4.4516.
Min AND (slide): w₁ = min(0.6, 0.5) = 0.5, w₂ = min(0.4, 0.8) = 0.4; w̄₁ = 0.5556, w̄₂ = 0.4444; f = 0.5556·6 + 0.4444·3 = 4.6667.

Explorer: Gaussian MFs μ(x) = exp(−(x−c)²/(2σ²)) (parameters c, σ per MF), two rules as above. Change anything and watch every layer.

18. Learning in ANFIS: parameters and hybrid learning

Extension from Jang et al. Ch. 12 (the slides stop at the architecture)

  • Two parameter sets: premise parameters (layer 1: MF shape such as c, σ or a, b, c) and consequent parameters (layer 4: pi, qi, ri).
  • Hybrid learning rule: with premise parameters fixed, the output is linear in the consequent parameters: f = Σ (w̄ix)pi + (w̄iy)qi + w̄iri. Forward pass: propagate the data up to layer 4 and solve for the consequent parameters by least-squares estimation. Backward pass: propagate the error back and update the premise parameters by gradient descent (backpropagation). This converges faster than pure gradient descent because the search space is reduced.
  • Parameter count (bell MFs, 3 parameters each): 2 inputs × 2 MFs × 3 + 2 rules × 3 = 18; for the 9-rule grid: 2 × 3 × 3 + 9 × 3 = 18 + 27 = 45 (Gaussian MFs: 2 parameters each).

20. Exam kit – neuro-fuzzy

“Why is ANFIS more effective than a pure ANN or a pure FIS? Which layers learn and which reason?” (6 marks) S25
A pure ANN needs a lot of data, cannot use prior knowledge and is a black box; a pure FIS cannot learn, its membership functions and rules must be tuned by an expert. ANFIS gives the network structure of a Sugeno FIS, so parameters are tuned from data while the rules stay interpretable, with faster convergence by hybrid learning. Learning: layer 1 (premise MF parameters, adaptive) and layer 4 (consequent parameters p, q, r, adaptive). Rule-based reasoning: layer 1 fuzzifies the inputs, layer 2 applies the AND operator (firing strength), layer 3 normalises, layer 5 aggregates; layers 2, 3 and 5 are fixed nodes with no parameters.
“With a diagram explain the five layers and indicate what each computes” (6 marks) F24

“Advantages of neuro-fuzzy systems” (3 marks) F23
Combine learning ability of NNs with the transparency and linguistic rules of fuzzy logic; handle imprecise/uncertain data; allow prior expert knowledge as initial rules; reduce manual tuning of MFs; faster training with hybrid learning; good for non-linear modelling and control.
“Advantages of a fuzzy system; how can a neuro-fuzzy system be built?” (6 marks) F22
Advantages as in §12. Building: (1) define inputs/outputs and linguistic terms with initial MFs/rule base (expert or grid partition); (2) map the fuzzy system onto a layered network (five layers: input, fuzzification, AND, inference, defuzzification, or ANFIS); (3) let the weights represent MF parameters/consequents; (4) train by backpropagation or a GA (hybrid learning for ANFIS) using input-output data; (5) check the deviation (e.g. 9.0 − 8.70 = 0.30 in the slide example) and tune. Three categories: supervised-NN, reinforcement-based, NN-built fuzzy partition (p. 114).

Traps

  • ANFIS adaptive layers: 1 and 4 (square nodes); fixed: 2, 3, 5 (circle nodes).
  • Premise = antecedent (layer 1); consequent = layer 4.
  • Layer 3 divides by the sum of all firing strengths.
  • Distinguish NFS (Mamdani, center of sums) from ANFIS (Sugeno, weighted sum).
