Hidden Markov Models & Viterbi – Deep Dive

CSE 4137/4237 · PDF pp. 448–473 (HMM slides), 464–470 (Viterbi, Rainy/Sunny example). Tags: S25 Spring 2025 · F24 · S24 · F23 · S23 · S22 · F22. Viterbi appeared in every exam.

1. Markov models

PDF pp. 450–453

  • A Markov model is a finite state machine with N states. It starts in an initial state at t=1 and moves to the next state using the transition probabilities of the current state.
  • Markov property (memoryless): the next state depends only on the current one: P(qt+1|q1..t) = P(qt+1|qt).
  • It is fully defined by transition probabilities aij (state i → j; each row sums to 1) and initial probabilities πi = P(q₁=Si) (they sum to 1).
Weather chain (R, S): π = (0.6, 0.4), R→R 0.7, R→S 0.3, S→R 0.4, S→S 0.6. P(R, S, S) = 0.6 × 0.3 × 0.6 = 0.108.

In a plain Markov model you see the state. Many problems do not allow that, which is why we need the hidden version.

2. Hidden Markov model (HMM)

PDF pp. 454–459 F23 S24 F22: components/issues

An HMM is a Markov process whose states are hidden; each state emits a visible observation according to a probability distribution. We only see the outputs (e.g. we see what she does, not the weather).

ComponentMeaningConstraint
States S = {S₁…SN}hidden (Noun/Verb/Adj; Rainy/Sunny)
Observations V = {v₁…vM}visible symbols (words; Walk/Shop/Clean)
Transition matrix A, aij=P(qt+1=Sj|qt=Si)how states changeeach row sums to 1
Emission matrix B, bi(vm)=P(vm|Si)what each state outputseach row sums to 1 (slide p. 458)
Initial vector πwhere the chain startssums to 1

The model is written M = λ = (A, B, π). Graphically: a chain of hidden variables H₁…HL with one observed Xi hanging off each (slide p. 459). Two assumptions: (1) first-order Markov chain, (2) each observation depends only on the current state.

The slides write aij = P(si|sj) (p. 453/456), which reads backwards. In every exam diagram arrows go from state i to state j, and row i of A holds the probabilities leaving state i. Use that.

3. The three problems of an HMM

PDF pp. 460–464 S24 F22: “explain the issues of HMM”

ProblemGivenFindAlgorithm
1. Evaluationλ=(A,B,π), O=o₁…oTP(O|λ)Forward (or backward)
2. Decodingλ, Omost likely hidden state sequenceViterbi
3. Learningtraining sequences, structurebest A, B, πBaum-Welch (EM)

Evaluation: forward algorithm (p. 462)

Forward variable αt(i) = P(o₁…ot, qt=Si). Three stages: initialisation α₁(i)=πibi(o₁); recursion αt+1(j) = [Σi αt(i)aij]·bj(ot+1); termination P(O|λ)=Σi αT(i). Cost O(N²T) instead of NT for summing over all paths. Same table as Viterbi but with sum instead of max.

Learning: Baum-Welch (p. 463)

Iterative EM: the E-step computes expected state occupancy γt(i) and expected transitions ξt(i,j) with forward-backward; the M-step re-estimates âij = Σξt(i,j)/Σγt(i), b̂j(k) = Σt:o_t=kγt(j)/Σγt(j), π̂i=γ₁(i). Repeats until likelihood stops increasing; converges to a local optimum only.

Model answer “Explain the issues of HMM” (3 marks): “Given an HMM, there are three basic problems: evaluation (probability that the model generated an observation sequence, solved by the forward algorithm), decoding (most likely hidden state sequence, solved by Viterbi) and learning (estimating transition and emission probabilities from data, solved by Baum-Welch).”

4. Viterbi algorithm (decoding)

PDF pp. 464–470

Idea: dynamic programming. Because of the Markov property, the best path to state j at time t only needs the best path to each state at time t−1. The slides call the pieces overall probability (multiply each new probability by the old one), Viterbi probability (best next-step probability × previous Viterbi probability) and Viterbi path (list of chosen states).

  1. Initialise (t=1): δ₁(i) = πi·bi(o₁).
  2. Recurse (t=2…T): δt(j) = maxi[ δt−1(i)·aij ]·bj(ot) and store the back-pointer ψt(j) = argmaxi δt−1(i)·aij.
  3. Terminate: best final state q*T = argmaxj δT(j), probability maxj δT(j).
  4. Back-track: q*t = ψt+1(q*t+1) back to t=1.

Cost O(N²T). For long sequences use log-probabilities (sum instead of product) to avoid underflow. On real data the accuracy of the decoded path is typically 80–90% (slide p. 470).

8. Exam kit

Answer template (7 marks)

  1. List the model: states, observations, π, A, B (draw the tables from the figure).
  2. Write the recursion δt(j)=maxi δt−1(i)aij·bj(ot).
  3. Compute δ₁ for all states.
  4. For each later step and each state: write all candidate products, circle the max, multiply by the emission, note the predecessor.
  5. Pick the largest final δ, back-track the pointers, write the state sequence and its probability.

Traps

  • π is used only at t=1; later steps use A.
  • Candidate uses the previous state’s δ × afrom→to; emission uses the current state and the current symbol.
  • Multiply, never add (adding gives the forward probability, not Viterbi).
  • Check each row of A and B sums to 1 when a label is hard to read.
  • Keep back-pointers at every step; ties: write both paths or pick one and say so.
  • Order of the answer is the sequence of states (one per observation), not the observations.

Likely short questions

  • Components of an HMM; difference between Markov chain and HMM.
  • Three problems and their algorithms.
  • Viterbi vs forward (max vs sum); why dynamic programming (O(N²T) vs NT).
  • Applications: speech recognition, POS tagging, cryptanalysis, activity recognition, machine translation, DNA/gene regions (slide p. 471).
