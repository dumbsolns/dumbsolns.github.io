Neural Networks & Logistic Regression – Deep Dive

CSE 4237 · PDF pp. 41–56 (intro), 58–107 (NN basics), 128–158 (cross-entropy), 159–202 (shallow NN, activations); content credit Andrew Ng. Tags: S25 F24 S24 F23 S23 S22 F22 mark where a topic was asked. The “dw₁…db” question appeared in every exam.

1. From one neuron to deep learning

PDF pp. 41–56 · F24 Q1a

  • AI ⊃ ML ⊃ Deep learning. A neural network learns a function from inputs x to output y given many labelled examples (supervised learning, “gold labels”).
  • Single neuron (house price): size x → price y. The fitted function is a ReLU, max(0, ax+b), because a price cannot be negative. Stacking neurons gives a network: hidden units (family size, walkability, school quality) are learned automatically; you only supply x and y.
  • Types: standard NN (structured data), CNN (images), RNN (speech, text). Structured data = tables with well-defined features; unstructured = images, audio, text.
  • Why deep learning took off: huge labelled data (digitisation, mobile, IoT), fast computation (GPUs, distributed), and better algorithms (e.g. sigmoid → ReLU speeds gradient descent). Training is iterative, so faster computation means faster experiments.

2. Binary classification and logistic regression

PDF pp. 59–67

Setup: an input x ∈ ℝnx and a label y ∈ {0, 1} (cat/non-cat). A 64×64 RGB image is unrolled into nx = 64·64·3 = 12,288. Training set of m examples: X is nx×m (one example per column), Y is 1×m.

Model: given x, find ŷ = P(y=1|x):

z = wᵀx + b  ·  ŷ = a = σ(z) = 1/(1+e−z)
  • wᵀx+b is linear and unbounded, so the sigmoid squashes it into (0,1) so it can be read as a probability. σ(0)=0.5, σ(z)→1 for large z, →0 for very negative z. Predict 1 if a > 0.5 (i.e. z > 0).
  • Weights w change the steepness of the sigmoid; the bias b shifts it left or right (decision boundary wᵀx+b=0 moves away from the origin). Without b the boundary must pass through x=0 and the model underfits. S22 F22
  • Parameters: w (nx×1) and b (scalar).

3. Loss and cost: why cross-entropy

PDF pp. 68–71, 129–146 · S23 F23

  • Squared error ½(ŷ−y)² (the ½ cancels when differentiating) is fine for linear regression but not for logistic regression: with the sigmoid it makes a non-convex cost with many local minima, so gradient descent can get stuck (p. 70).
  • Cross-entropy (log) loss: L(ŷ,y) = −[ y·log ŷ + (1−y)·log(1−ŷ) ]. If y=1 the loss is −log ŷ (small when ŷ→1, huge when ŷ→0); if y=0 it is −log(1−ŷ). It is convex in (w, b) and penalises confident wrong answers very heavily.
  • Loss vs cost (p. 146): the loss is for one example; the cost is the average over the training set: J(w,b) = (1/m) Σi=1..m L(ŷ(i), y(i)).
Numbers: y=1, ŷ=0.9 → L = −ln 0.9 = 0.105; y=1, ŷ=0.1 → L = −ln 0.1 = 2.303; y=0, ŷ=0.1 → L = −ln 0.9 = 0.105.

4. Gradient descent

PDF pp. 72–79

Find w, b that minimise J(w,b). Start at a random (or zero) point on the convex surface and repeatedly step downhill:

w := w − α · ∂J/∂w    b := b − α · ∂J/∂b   (α = learning rate)
  • Derivative = slope: if f(a)=3a, shifting a by 0.001 shifts f by 0.003, so the slope is 3 (p. 77). A positive slope means decrease w; a negative slope means increase w.
  • Too large α overshoots or diverges; too small α is slow.
  • Why not brute-force search? With 1 weight and 1000 trial values it is fine; with 2 weights it needs 10⁶ evaluations (~40 s in the slide example) and grows exponentially with every added weight, whereas one gradient step costs about one pass. (pp. 78–79)
  • Because J is convex for logistic regression, any initialisation (usually 0) reaches the global minimum.

5. Computation graph and backpropagation for logistic regression

PDF pp. 81–94 · S23: why a computation graph?

A computation graph splits a function into elementary steps. Example J = 3(a + bc): u = bc, v = a + u, J = 3v. The forward pass computes the output/cost left to right; the backward pass applies the chain rule right to left to get all derivatives exactly and cheaply. That is why every framework builds a graph for training.

Graph for one example (two features): z = w₁x₁ + w₂x₂ + b → a = σ(z) → L(a,y). Walk backwards:

  1. da = ∂L/∂a = −y/a + (1−y)/(1−a)
  2. dz = ∂L/∂z = da · σ′(z) = da · a(1−a). Simplify: [−y/a + (1−y)/(1−a)]·a(1−a) = −y(1−a) + (1−y)a = a − y ⇒ dz = a − y.
  3. dw₁ = x₁·dz, dw₂ = x₂·dz, db = dz (since ∂z/∂wi = xi, ∂z/∂b = 1).
  4. Update: w₁ := w₁ − α·dw₁, w₂ := w₂ − α·dw₂, b := b − α·db.

Over m examples (pp. 95–101): J, dw, db are accumulated over a loop of m examples and divided by m, then one update is applied. Repeating this is gradient descent. The naive version has two loops (over examples and over features); vectorization removes both.

6. The exam question: dw₁…dw₄ and db with ReLU, tanh, LeakyReLU

S25 F24 F23 S23 F22

The exam network is z = w₁x₁ + … + b → a = g(z) → L(a,y) with L the cross-entropy and g not the sigmoid. Keep the chain rule general:

dz = da · g′(z) with da = −y/a + (1−y)/(1−a) = (a−y)/(a(1−a)), then dwi = xi·dz, db = dz.

Worked ReLU example. x = (1, 2, 0, 3), w = (0.1, 0.05, 0.2, 0.1), b = 0.05, y = 1. z = 0.1 + 0.1 + 0 + 0.3 + 0.05 = 0.55 > 0 ⇒ a = ReLU(z) = 0.55. Loss = −ln 0.55 = 0.598. da = (0.55−1)/(0.55·0.45) = −1.818; g′ = 1 so dz = −1.818. dw = x·dz = (−1.818, −3.636, 0, −5.455), db = −1.818. With α=0.1: w₁ = 0.1 + 0.182 = 0.282, b = 0.05 + 0.182 = 0.232.
Say these in the answer: (1) the formula is general, plug in the given x, w, b, y if numbers are given; (2) ReLU’s derivative at 0 is undefined, convention 0; (3) cross-entropy assumes a ∈ (0,1), so with ReLU/tanh outputs the formula is used formally (the question defines L as cross-entropy); (4) a dead ReLU (z ≤ 0) gives all-zero gradients; (5) the sigmoid shortcut dz = a − y does not apply to other activations.

8. Vectorized logistic regression

PDF pp. 98–106 · F24 S23 F22

  • Forward: Z = wᵀX + b (1×m; b is a scalar, broadcast to every column), A = σ(Z).
  • Cost: J = −(1/m) Σ [ Y log A + (1−Y) log(1−A) ].
  • Backward: dZ = A − Y (1×m), dw = (1/m)·X·dZᵀ (nx×1), db = (1/m)·Σ dZ.
  • Update: w := w − α·dw, b := b − α·db. One iteration, no explicit loop.

Why vectorize: removes the two for-loops (over m examples and over features); NumPy/GPU matrix operations use parallel hardware and are orders of magnitude faster; code is shorter and less error-prone. The justification: the columns of X are independent examples, so one matrix product computes all z(i) at once.

9. Shallow (two-layer) neural network

PDF pp. 160–171 · F24 S23 F23 F22: vectorized 3-4-1 network

A neural network is logistic regression repeated many times: the hidden layer is several LRs on the same input, and the output layer is another LR on their outputs. Superscript [l] = layer, (i) = example, subscript = node. Hidden units are “hidden” because their true values are not observed in the training set.

QuantityShape (nx=3 inputs, 4 hidden, 1 output)
X3 × m
W[1], b[1]4 × 3, 4 × 1
Z[1], A[1]4 × m
W[2], b[2]1 × 4, 1 × 1
Z[2], A[2] = ŷ1 × m
Forward (all m examples): Z[1] = W[1]X + b[1], A[1] = g[1](Z[1]), Z[2] = W[2]A[1] + b[2], A[2] = σ(Z[2]).
Single example: the same with x (3×1) instead of X.

Justification: stacking the m example vectors as columns of X, and the hidden-unit weights as rows of W[1], makes each entry of Z[1] exactly the per-example, per-unit z, so a single matrix product replaces the loop over examples (and the loop over hidden units).

Backward (for completeness): dZ[2] = A[2] − Y; dW[2] = (1/m)dZ[2]A[1]ᵀ; db[2] = (1/m)ΣdZ[2]; dZ[1] = W[2]ᵀdZ[2] ∗ g[1]′(Z[1]); dW[1] = (1/m)dZ[1]Xᵀ; db[1] = (1/m)ΣdZ[1]. Initialise W randomly (small values), not zero, otherwise all hidden units stay identical. Parameters of the 3-4-1 net: 4·3+4 + 1·4+1 = 21.

10. Activation functions

PDF pp. 172–200 · S24 F23 F22 S22 S23 F24

Why non-linear? S24 F23 S23 F22

With a linear (identity) activation: a[1]=W[1]x+b[1], a[2]=W[2]a[1]+b[2] = (W[2]W[1])x + (W[2]b[1]+b[2]) = W′x + b′. Any number of layers collapses into one linear function; the network is just linear regression (or, with a sigmoid output, a plain logistic regression), and cannot learn non-linear boundaries. Non-linear g also allows stacking layers and has a derivative for backprop. (Linear g is acceptable only in the output layer of a regression problem.)

Sigmoid1/(1+e⁻ᶻ)(0,1)a(1−a), max 0.25output of binary classifiers; vanishing gradient, not zero-centred, exp is costly
tanh(eᶻ−e⁻ᶻ)/(eᶻ+e⁻ᶻ)(−1,1)1−a², max 1zero-centred, steeper; still saturates
ReLUmax(0,z)[0,∞)0 / 1 (undefined at 0)fast, sparse, default for hidden layers; dying ReLU
Leaky ReLUmax(0.01z,z)(−∞,∞)0.01 / 1fixes dying ReLU
Softmaxeᶻⁱ/Σeᶻʲ(0,1), sums to 1—multi-class output layer
  • Sigmoid problem (p. 181): for large |z| the output saturates and the gradient ≈ 0 (maximum slope only 0.25), so deep layers learn extremely slowly (vanishing gradient); outputs are all positive, so updates zig-zag. Does tanh solve it? It is zero-centred and its gradient reaches 1, so it is better, but it also saturates at both ends; the vanishing-gradient problem remains. ReLU/Leaky ReLU, careful initialisation or residual/LSTM structures help.
  • Derivation of the sigmoid slope: σ(z)=(1+e⁻ᶻ)⁻¹ ⇒ σ′ = e⁻ᶻ/(1+e⁻ᶻ)² = σ(1−σ). tanh′ = 1−tanh². “tanh is steeper than sigmoid” S23: at z=0 tanh′=1 vs σ′=0.25, and tanh(z) = 2σ(2z) − 1 (a stretched, shifted sigmoid), so its slope is 4× larger near 0.
  • ReLU benefits (pp. 183–184): cheap (a comparison), converges quickly, non-saturating for z>0, sparse activation (many hidden units are exactly 0). Dying ReLU: when z<0 for every input, output and gradient are 0, the unit never updates. Fixes: Leaky ReLU (slope 0.01 for z<0, so a gradient always flows), parametric/exponential ReLU, smaller learning rate, good initialisation.
  • Derivative of ReLU at 0: not differentiable (left slope 0, right slope 1) but z is practically never exactly 0, so use 0 or 1 by convention.
  • ReLU vs softmax in a CNN F23: ReLU adds non-linearity in hidden/conv layers cheaply; softmax in the output turns scores into class probabilities.

11. Softmax, entropy and cross-entropy

PDF pp. 129–158 · F23 S23 S24 S22: CE, softmax problems

  • Logits are the raw, un-normalised scores; softmax pi = ezi/Σjezj makes them positive and sum to 1, and it exaggerates the largest: softmax([1,2]) = [0.269, 0.731] (blurry image, “maybe a cat”) vs softmax([10,20]) = [0.00005, 0.99995] (crisp).
  • Information of an event: surprise in bits, I(x) = −log₂ p(x). Entropy is the average information: H(p) = −Σ p(x) log p(x). The minus sign makes it positive because log p ≤ 0 for p∈(0,1) (p. 137).
  • Cross-entropy between true p and predicted q: H(p,q) = −Σ p(x) log q(x). With a one-hot target it reduces to −log of the predicted probability of the correct class. Example: true [0,1,0], predicted [0.2,0.7,0.1] ⇒ L = −ln 0.7 = 0.357; the loss is large if the correct class gets small probability.
  • Variants (p. 144–145): binary CE (one sigmoid output), categorical CE (one-hot labels), sparse categorical CE (integer labels; same loss, only label format differs).
  • Problems of softmax classification S24 S22: the denominator sums over all classes, so with a huge vocabulary (e.g. 10,000+ words) every step is expensive; large logits can overflow (subtract the max for numerical stability); outputs are over-confident and force exactly one class. Fixes: hierarchical softmax, negative sampling (see Word2vec), sampled softmax, numerically stable implementation.
  • Wordle example (pp. 148–157): 5,757 words ⇒ log₂ 5757 = 12.49 bits of uncertainty; each guess should maximise expected information. “fuzzy” gives 2.28 bits, “tares” 6.21 bits on average.

12. Exam kit

“A neural network is a combination of several logistic regressions” (4–8 marks) S24 F23 S22 F24
Agree. Each neuron computes σ(wᵀx+b), exactly a logistic regression. A hidden layer runs several of them in parallel on the same input; the output layer is another LR on their outputs (the 3-4-1 network is four LRs feeding a fifth). The difference is that hidden units learn useful features, which a single LR cannot, because of the non-linearity.
“A non-activated network acts as linear regression” (4 marks) S23 / “linear activation turns a deep network into one layer” F22
Show the collapse proof from §10: W[2]W[1] is just one matrix.
Handwritten digits: LR vs shallow vs deep ANN (10 marks) F24
LR: simple, fast, convex, but linear boundary, poor on pixels. Shallow ANN: learns non-linear features, a good fit for digit images (MNIST), few parameters. Deep ANN/CNN: best accuracy on large, complex data, but needs more data and compute, overfits, harder to tune and less interpretable. Recommend a shallow/moderate ANN (a CNN for bigger images) with ReLU hidden units and softmax output.

Traps

  • Loss (one example) vs cost (average of m).
  • dz = a − y is only for sigmoid + cross-entropy; otherwise multiply da by g′(z).
  • Never initialise a hidden layer to all zeros.
  • Shapes: W[1] is (hidden × inputs); b is broadcast across columns.
  • Always state which activation derivative you use and at which z.
