Section 01 • Theoretical Foundations

Core RL Paradigm & Markov Decision Processes (MDPs)

Sutton & Barto Ch. 1 & Ch. 3
Supervised Learning (x_i, y_i)

Learns from an external teacher providing instant ground-truth labels $y_i$ for every input $x_i$ (e.g., Bayesian Classification, SVM, Linear Regression).

Unsupervised Learning {x_i}

Finds hidden statistical structure or low-dimensional subspaces in unlabeled data with no reward signal (e.g., PCA, K-Means Clustering).

Reinforcement Learning (s_t, a_t, r_{t+1}, s_{t+1})

Learns via trial-and-error interaction. Feedback is evaluative (scalar rewards $r_{t+1}$) rather than instructive, and rewards are often delayed across many steps.

The Markov Decision Process (MDP) 5-Tuple: $\langle \mathcal{S}, \mathcal{A}, P, R, \gamma \rangle$

An MDP formally defines the environment for sequential decision-making under uncertainty:

1. $\mathcal{S}$ (States) The set of all valid states the environment can occupy ($s_t \in \mathcal{S}$).
2. $\mathcal{A}$ (Actions) The set of all possible actions executable by the agent ($a_t \in \mathcal{A}(s_t)$).
3. $P$ (Dynamics) State Transition Probability: $P(s' \mid s, a) = \Pr(S_{t+1} = s' \mid S_t = s, A_t = a)$, where $\sum_{s' \in \mathcal{S}} P(s' \mid s, a) = 1$.
4. $R$ (Reward) Reward Function: $R(s, a, s') = \mathbb{E}[R_{t+1} \mid S_t = s, A_t = a, S_{t+1} = s']$ (scalar feedback signal).
5. $\gamma$ (Discount) Discount Factor: $\gamma \in [0, 1]$, determining the present value of future rewards.

The Markov Property (Memorylessness)

A state $S_t$ has the Markov Property if the future state and reward depend purely on the current state and action, independent of all prior history:

$$P(S_{t+1} = s' \mid S_t, A_t, S_{t-1}, \dots, S_0) = P(S_{t+1} = s' \mid S_t, A_t)$$

"The present state captures all relevant information from history."

Cumulative Discounted Return ($G_t$)

The agent seeks to maximize expected return $G_t$ from step $t$:

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$ $$\text{Recursive form: } G_t = R_{t+1} + \gamma G_{t+1}$$
  • • Why $\gamma \in [0, 1)$? Guarantees convergence of the infinite sum to a finite value ($\le \frac{R_{\max}}{1-\gamma}$) in continuing/cyclic tasks and models future uncertainty.
  • • $\gamma = 0$ (Myopic): Agent only maximizes immediate reward $R_{t+1}$.
  • • $\gamma \to 1$ (Far-sighted): Agent weighs distant future rewards heavily.
Section 02 • Value Functions & Control

Bellman Equations, Q-Learning & SARSA

Sutton & Barto Ch. 3, Ch. 4 & Ch. 6

1. Bellman Expectation Equations (For Policy $\pi$)

Policy Evaluation

A policy $\pi(a \mid s)$ defines the probability of selecting action $a$ in state $s$.

State-Value Function $V^\pi(s)$

Expected return starting from state $s$ and following policy $\pi$ thereafter:

$$V^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s] = \sum_{a \in \mathcal{A}} \pi(a \mid s) \sum_{s' \in \mathcal{S}} P(s' \mid s, a) \left[ R(s, a, s') + \gamma V^\pi(s') \right]$$

Action-Value Function (Q-Function) $Q^\pi(s, a)$

Expected return starting from state $s$, taking action $a$, and following policy $\pi$ thereafter:

$$Q^\pi(s, a) = \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a] = \sum_{s' \in \mathcal{S}} P(s' \mid s, a) \left[ R(s, a, s') + \gamma \sum_{a' \in \mathcal{A}} \pi(a' \mid s') Q^\pi(s', a') \right]$$

2. Bellman Optimality Equations (Optimal Policy $\pi^*$)

Optimal Control

The optimal policy $\pi^*$ achieves the maximum possible expected return from every state:

Optimal State-Value $V^*(s) = \max_\pi V^\pi(s)$

$$V^*(s) = \max_{a \in \mathcal{A}} Q^*(s, a) = \max_{a \in \mathcal{A}} \sum_{s' \in \mathcal{S}} P(s' \mid s, a) \left[ R(s, a, s') + \gamma V^*(s') \right]$$

Optimal Action-Value $Q^*(s, a) = \max_\pi Q^\pi(s, a)$

$$Q^*(s, a) = \sum_{s' \in \mathcal{S}} P(s' \mid s, a) \left[ R(s, a, s') + \gamma \max_{a' \in \mathcal{A}} Q^*(s', a') \right]$$
Optimal Policy Extraction: Pick action with highest $Q^*(s,a)$: $$\pi^*(s) = \arg\max_{a \in \mathcal{A}} Q^*(s, a)$$

Model-Based vs. Model-Free RL

Model-Based (Dynamic Programming)

Assumes $P(s'\mid s,a)$ and $R(s,a,s')$ are fully known. Computes values iteratively over all states without sampling:

Value Iteration: $V_{k+1}(s) \leftarrow \max_a \sum_{s'} P(s'\mid s,a)[R + \gamma V_k(s')]$

Model-Free (Temporal Difference / TD Learning)

Environment dynamics $P$ and $R$ are unknown. The agent learns directly from sampled transitions $(s_t, a_t, r_{t+1}, s_{t+1})$ by bootstrapping (updating an estimate using another estimate).

Exploration vs. Exploitation ($\epsilon$-Greedy Policy)

With probability $\epsilon \in [0, 1]$, choose a random action (explore); with probability $1 - \epsilon$, choose the greedy action $\arg\max_a Q(s_t, a)$ (exploit).

Q-Learning (Off-Policy) vs. SARSA (On-Policy)

High-Yield Exam Topic
Q-Learning (Off-Policy TD Control — Watkins, 1989) Uses max_a' Q(s', a')
$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \Big[ \underbrace{r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a')}_{\text{TD Target}} - \underbrace{Q(s_t, a_t)}_{\text{Old Estimate}} \Big]$$

• TD Error ($\delta_t$): $\delta_t = r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t)$.
• Why Off-Policy? Even if the agent explores randomly using an $\epsilon$-greedy behavior policy, the update rule evaluates the greedy maximum $\max_{a'} Q(s_{t+1}, a')$ at the next state, directly approximating $Q^*(s,a)$.

SARSA (On-Policy TD Control — State-Action-Reward-State-Action) Uses actual Q(s', a')
$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \Big[ r_{t+1} + \gamma Q(s_{t+1}, a_{t+1}) - Q(s_t, a_t) \Big]$$

• Why On-Policy? Updates $Q(s_t, a_t)$ using the actual action $a_{t+1}$ chosen by the current policy in state $s_{t+1}$ rather than the $\max$ operator.

Exam Problem: 3-Step Tabular Q-Learning & Backward Value Propagation

Given: 1D Linear Grid-World $\mathcal{S} = \{S_1, S_2, S_3, S_4\text{ (Goal)}\}$, Actions $\mathcal{A} = \{\text{Left } (L), \text{Right } (R)\}$, Initial $Q_0(s,a) = 0$.

Hyperparameters: Learning Rate $\alpha = 0.5$, Discount Factor $\gamma = 0.9$, Step Reward $r_{\text{step}} = -1$, Goal Entry Reward $r_{\text{goal}} = +10$.

Master Q-Learning Update Rule:

$$Q(s,a) \leftarrow Q(s,a) + \alpha \big[ r + \gamma \max_{a'} Q(s',a') - Q(s,a) \big]$$

1. State-Space Diagram & Reward Structure (1D Corridor)

2. Q-Table Evolution ($Q_0 \to Q_3$)

State Left ($L$) Right ($R$) Initial Right ($R$) Final
$S_1$ 0.00 0.00 -0.50*
$S_2$ 0.00 0.00 → -0.50 +1.50
$S_3$ 0.00 0.00 +5.00
$S_4$ (Goal) 0.00 0.00 0.00

*Note: In Episode 2, stepping $S_1 \xrightarrow{R} S_2$ first yields $Q(S_1,R) = -0.50$, and then stepping $S_2 \xrightarrow{R} S_3$ updates $Q(S_2,R)$ to $\mathbf{+1.50}$.

Step 1 (Episode 1, $t=0$) S₂ —(Right)→ S₃

1. Observed Transition:

  • Current State-Action: $(s_t, a_t) = (S_2, \text{Right})$
  • Next State: $s_{t+1} = S_3$, Immediate Reward: $r = -1$
  • Current Estimate: $Q_{\text{old}}(S_2, R) = 0.0$

2. Max Future Value at $S_3$:

$$\max_{a'} Q(S_3, a') = \max\big(Q(S_3, L), Q(S_3, R)\big)$$ $$= \max(0.0, 0.0) = 0.0$$

3. Compute TD Target & TD Error:

$$\text{TD Target} = r + \gamma \max_{a'} Q(S_3, a')$$ $$= -1 + (0.9)(0.0) = -1.0$$ $$\delta_1 = \text{TD Target} - Q_{\text{old}}(S_2, R) = -1.0 - 0.0 = -1.0$$

4. Plug into Update Rule:

$$Q_{\text{new}}(S_2, R) = 0.0 + 0.5 \big[ -1 + 0.9(0.0) - 0.0 \big]$$ $$Q_{\text{new}}(S_2, R) = 0.0 + 0.5(-1.0) = \mathbf{-0.50}$$

Insight: Because $S_3$ hasn't discovered the goal yet, $Q(S_2, R)$ drops to $-0.50$ due to the step penalty $r = -1$.

Step 2 (Episode 1, $t=1$) S₃ —(Right)→ S₄ (Goal)

1. Observed Transition:

  • Current State-Action: $(s_t, a_t) = (S_3, \text{Right})$
  • Next State: $s_{t+1} = S_4 \text{ (Terminal)}$, Reward: $r = +10$
  • Current Estimate: $Q_{\text{old}}(S_3, R) = 0.0$

2. Max Future Value at Terminal $S_4$:

$$\max_{a'} Q(S_4, a') = 0.0 \quad \text{(Terminal State Rule)}$$

3. Compute TD Target & TD Error:

$$\text{TD Target} = r + \gamma \max_{a'} Q(S_4, a')$$ $$= +10 + (0.9)(0.0) = +10.0$$ $$\delta_2 = 10.0 - 0.0 = +10.0$$

4. Plug into Update Rule:

$$Q_{\text{new}}(S_3, R) = 0.0 + 0.5 \big[ 10 + 0.9(0.0) - 0.0 \big]$$ $$Q_{\text{new}}(S_3, R) = 0.0 + 0.5(10.0) = \mathbf{+5.00}$$

Insight: Episode 1 terminates at $S_4$! State $S_3$ now stores a positive value ($+5.00$) reflecting proximity to the goal.

Step 3 (Episode 2 Propagation) S₁→S₂ & Revisit S₂→S₃

Part 3A ($S_1 \xrightarrow{R} S_2, r=-1$): Since $\max_{a'} Q(S_2, a') = \max(0, -0.5) = 0$, $Q(S_1, R)$ updates to: $$Q(S_1, R) = 0 + 0.5[-1 + 0.9(0) - 0] = \mathbf{-0.50}$$

Part 3B (Revisiting $S_2 \xrightarrow{R} S_3, r=-1$):

  • Previous Stored Value: $Q_{\text{old}}(S_2, R) = -0.50$
  • Lookahead at $S_3$ Now Sees $+5.00$:
$$\max_{a'} Q(S_3, a') = \max(0.0, \mathbf{5.00}) = \mathbf{5.00}$$

Compute New TD Target & TD Error:

$$\text{TD Target} = -1 + (0.9)(5.00) = -1 + 4.50 = \mathbf{+3.50}$$ $$\delta_3 = 3.50 - (-0.50) = \mathbf{+4.00}$$

Plug into Update Rule:

$$Q_{\text{new}}(S_2, R) = -0.50 + 0.5 \big[ -1 + 0.9(5.0) - (-0.50) \big]$$ $$Q_{\text{new}}(S_2, R) = -0.50 + 0.5(4.00) = \mathbf{+1.50}$$

Key Takeaway: The $+10$ reward at $S_4$ has now propagated backward two steps into $Q(S_2, R) = +1.50$!

Section 05 • Quick Exam Revision

Exam Cheat-Sheet, Common Pitfalls & Textbook References

4 Classic Exam Traps to Avoid

  • 1. Forgetting $\max_{a'} Q(S_{\text{terminal}}, a') = 0$: When an agent transitions into a terminal goal or hazard state, there are no subsequent actions. Always set the future value term of a terminal state to $0$.
  • 2. Mixing up $s_t$ and $s_{t+1}$ in the $\max$ operator: When updating $Q(s_t, a_t)$, the lookahead term $\gamma \max_{a'} Q(s_{t+1}, a')$ inspects the row of the next state $s_{t+1}$, never the current state $s_t$.
  • 3. Confusing Reward $r_{t+1}$ with Value $V(s)$: $r_{t+1}$ is the immediate short-term scalar feedback from a single step; $V(s)$ and $Q(s,a)$ measure the long-term cumulative discounted return from that point onward.
  • 4. Why Q-Learning needs multiple episodes: Because TD learning bootstraps one step at a time ($s_t \to s_{t+1}$), a terminal reward at $S_4$ only updates $S_3$ on the first visit, $S_2$ on the second visit, and $S_1$ on the third visit.
