Principal component analysis (PCA): deep dive

Dimensionality reduction by keeping the directions of maximum variance: the intuition, the complete Lagrange derivation, the step-by-step algorithm, the lecture's 10-point example and the past-paper example in full, reconstruction error, and the practical traps.

Read: Bishop, PRML, §12.1 "Principal Component Analysis": §12.1.1 "Maximum variance formulation", §12.1.2 "Minimum-error formulation", §12.1.3 "Applications of PCA", §12.1.4 "PCA for high-dimensional data". Duda, Hart & Stork, Ch. 3 §3.8.1 "Principal Component Analysis (PCA)". The 10-point worked example matches L. Smith (2002), "A tutorial on principal components analysis". For the Lagrange-multiplier step see Bishop Appendix E. Section numbers follow the usual editions; check your copies.

1. Why reduce dimensions?

Data compression (slides, credited to Andrew Ng): two features that measure the same thing, such as a length in inches and the same length in centimetres, are redundant. All the points lie almost on a line, so the 2-D data can be reduced to 1-D with little loss. Likewise 3-D points that almost lie in a plane can be reduced to 2-D coordinates on that plane.

Definition (slide): PCA is a method of dimensionality reduction / feature extraction that transforms the data from a d-dimensional space into a new coordinate system of dimension p, where p ≤ d (the worst case is p = d).

Uses: visualisation (3 genes or 100 genes → a 2-D plot of which samples cluster), less storage and faster learning, removing noise and redundancy, and a defence against overfitting and the curse of dimensionality.

2. The intuition: a line that fits the spread

The slides build PCA with a table of gene measurements for six mice.

  • One gene gives one number per mouse: a number line. Mice with similar values (1, 2, 3 high; 4, 5, 6 low) cluster together.
  • Two genes make a 2-D scatter plot; three genes need a 3-D plot; four or more genes can no longer be plotted. PCA lets us squeeze them onto a plot with the few axes that matter (slide: PC1 holds 91% of the variation and PC2 4%, so the mice cluster visibly on a PC1–PC2 plot).

How PC1 is found (two-gene picture)

  1. Compute the average of each gene: the centre of the data.
  2. Shift the data so the centre sits on the origin (0,0). This changes no relative positions.
  3. Draw a line through the origin and project every point onto it. Rotate the line until it fits as well as possible.
  4. "Fits well" can be measured two ways, and they always agree: minimise the squared distances from the points to the line, or maximise the squared distances d₁², d₂², … from the projected points to the origin, SS(distances) = d₁² + … + dn². PCA picks the line with the largest SS(distances). That line is PC1. (Why they agree: for each point, (distance to origin)² = (projected distance)² + (distance to line)², and the left side does not change as the line rotates. The widget below shows this.)
  • PC1 is a blend of the genes. Slide: slope 0.25 means PC1 is "4 parts Gene 1 and 1 part Gene 2": a linear combination of the original variables (the "cocktail recipe"). Scaled to unit length, those parts are the loadings.
  • PC2 is the line through the origin perpendicular to PC1 (90°); in 2-D no further optimisation is needed. With three genes PC3 is perpendicular to both.
  • To draw the PCA plot, take the projected positions of each sample along PC1 and PC2 as its new coordinates.

The three main ideas (slides)

  1. Variation means information. If everyone has the same age, "age" tells you nothing. PCA looks for the directions in which the points are spread as far as possible (maximum variance).
  2. Combine, don't just delete. Rather than dropping features such as "Height" or "Leg length", PCA blends them into new directions called principal components.
  3. Zero redundancy. PC2 is at a strict 90° (orthogonal) to PC1, so it captures only information PC1 missed.

How much does each PC explain? The scree plot

The variation of a PC is SS(distances)/(n − 1), which equals the eigenvalue belonging to that PC (slide: "eigenvalues measure the variations"). Example (slide): variation of PC1 = 15 and PC2 = 3, so the total variation around the PCs is 15 + 3 = 18 and PC1 accounts for 15/18 = 83%. A scree plot is the bar chart of these percentages; with 3 genes the slide shows PC1 79%, PC2 15%, PC3 6%.

3. Background you need

  • Mean x̄ = (1/n)Σxi. Variance (spread of one variable): s² = Σ(xi − x̄)²/(n − 1). Dividing by n − 1 instead of n is Bessel's correction (the ML variance divides by n and is biased, see the parameter-estimation page).
  • Covariance of two variables: cov(x,y) = Σ(xi − x̄)(yi − ȳ)/(n − 1). Positive: both increase together. Negative: one increases as the other decreases. Zero: uncorrelated (no linear relationship). cov(x,x) = var(x).
  • Covariance matrix S (d × d): entry Sij = cov(variable i, variable j). The diagonal holds the variances; S is symmetric. For centred data X (d × n, one column per observation): S = (1/(n − 1)) X Xᵀ.
  • Eigenvector and eigenvalue: for a square matrix A, a non-zero vector v is an eigenvector if Av = λv (A only stretches v by the scalar λ, the eigenvalue; the direction does not change). Eigenvectors of a symmetric matrix with different eigenvalues are orthogonal.

How to find them

(A − λI)v = 0 has a non-zero solution only if (A − λI) is not invertible (otherwise multiplying by the inverse would force v = 0, but v must be non-zero, here unit length). A matrix is non-invertible exactly when its determinant is 0, so solve the characteristic equation det(A − λI) = 0 for λ, then solve (A − λI)v = 0 for each λ and normalise.

Mini example: A = [[2,1],[1,2]]: det = (2 − λ)² − 1 = λ² − 4λ + 3 = 0 gives λ = 3 and 1. For λ = 3: (A − 3I)v = 0 gives −v₁ + v₂ = 0, so v = (1,1)/√2. For λ = 1: v = (1,−1)/√2. They are orthogonal.

4. The derivation (why eigenvectors of S)

Goal: find the direction u₁ along which the projected data have maximum variance. Let X be the centred d × n data matrix. The projection onto u is the row vector y = uᵀX (1 × n).

Variance of the projection. X is centred, so y has mean zero and:

var(y) = (1/(n−1)) Σ y_i² = (1/(n−1)) y yᵀ = (1/(n−1)) uᵀX Xᵀu = uᵀ S u (a 1×1 scalar)

Problem: uᵀSu can be made arbitrarily large by scaling u. Only the direction matters, so fix the length:

maximise uᵀS u subject to uᵀu = 1

Lagrange multiplier. The method (slide example: maximise f(x,y) = x − y subject to x² + y² = 1: set up L = x − y − λ(x² + y² − 1), differentiate and solve; the maximum is √2 at (1/√2, −1/√2)). For PCA:

L(u, λ) = uᵀSu − λ(uᵀu − 1) ∂L/∂u = 2Su − 2λu = 0 ⇒ S u = λ u (u is an eigenvector of S, λ its eigenvalue) ∂L/∂λ = −(uᵀu − 1) = 0 ⇒ uᵀu = 1 (the constraint comes back) variance: uᵀSu = uᵀ(λu) = λ uᵀu = λ

So the variance along an eigenvector equals its eigenvalue. To maximise it, pick the eigenvector with the largest eigenvalue: that is PC1. The next components are the next largest eigenvalues; they are mutually orthogonal because S is symmetric. A d × d covariance matrix has d eigenvalue/eigenvector pairs (u₁,λ₁), …, (ud,λd) with λ₁ ≥ λ₂ ≥ … ≥ λd; the PCs form an orthonormal basis (at most d of them).

Exam wording: "The role of eigenvalues and eigenvectors in PCA: eigenvectors of the covariance matrix are the principal directions; each eigenvalue is the variance of the data along its eigenvector; keep the eigenvectors with the largest eigenvalues."

5. The algorithm

  1. Get the data (n observations of d variables).
  2. Center: subtract the mean of each variable.
  3. Covariance matrix S = (1/(n − 1)) X Xᵀ.
  4. Solve det(S − λI) = 0 for the eigenvalues; for each, solve (S − λiI)ui = 0 and normalise to uiᵀui = 1.
  5. Rank and choose: sort the eigenvalues in descending order; keep the top p to form the feature vector (projection matrix) Wp = [u₁ … up] (dimensions fall from d to p).
  6. Derive the new data: Z = Wpᵀ X (slides: FinalData = RowFeatureVector × RowDataAdjust).

The whole process when you also have a classifier (slides)

Phase 1: training 1. split the data into X_train and X_test 2. compute the mean μ_train from X_train ONLY; center the training data 3. fit PCA: covariance of the centred training data, eigen-decomposition, keep top p → W_p (d × p) 4. project: Z_train = W_pᵀ (x − μ_train); train the classifier (SVM, logistic regression, …) on Z_train 5. save μ_train, W_p and the trained classifier Phase 2: testing / inference, for a new sample x_test A. center with the STORED training mean: x − μ_train B. project with the stored matrix: z = W_pᵀ (x − μ_train) C. pass z to the classifier → predicted label
Never fit PCA on the test data (or on train + test together): the mean and Wp must come from the training data only and then be re-used unchanged. Otherwise information leaks from the test set, the same mistake discussed on the model-evaluation page.

6. Worked example: the lecture's 10 points

Data (x, y): (2.5, 2.4), (0.5, 0.7), (2.2, 2.9), (1.9, 2.2), (3.1, 3.0), (2.3, 2.7), (2.0, 1.6), (1.0, 1.1), (1.5, 1.6), (1.1, 0.9).

  1. Means: x̄ = 1.81, ȳ = 1.91. Centred data: (0.69, 0.49), (−1.31, −1.21), (0.39, 0.99), (0.09, 0.29), (1.29, 1.09), (0.49, 0.79), (0.19, −0.31), (−0.81, −0.81), (−0.31, −0.31), (−0.71, −1.01).
  2. Covariance (n − 1 = 9): var(x) = 5.549/9 = 0.6166, var(y) = 6.449/9 = 0.7166, cov(x,y) = 5.539/9 = 0.6154. S = [[0.6166, 0.6154], [0.6154, 0.7166]]. Positive covariance: x and y increase together.
  3. Eigenvalues: det(S − λI) = (0.6166 − λ)(0.7166 − λ) − 0.6154² = λ² − 1.3332λ + 0.0630 = 0, giving λ₁ = 1.2840, λ₂ = 0.0491. (Their sum 1.3331 is the trace of S, the total variance.)
  4. Eigenvector for λ₁: (S − λ₁I)u = 0: −0.6674u₁₁ + 0.6154u₁₂ = 0, so u₁₂ = 1.0845u₁₁. Take u₁₁ = 1, length √(1 + 1.0845²) = 1.4752, normalise: u₁ = (0.6779, 0.7352). The same procedure gives u₂ = (−0.7352, 0.6779). They are orthogonal: 0.6779·(−0.7352) + 0.7352·0.6779 = 0. (Software may return either sign; −u is equally valid.)
  5. Variance explained: PC1: 1.2840/1.3331 = 96.3%; PC2: 3.7%. Almost all the variation lies along u₁ (angle atan(0.7352/0.6779) = 47.3° from the x-axis), a line with slope ≈ 1.08.
  6. Project onto PC1 (p = 1): z = u₁ᵀ(x − mean). Observation 1: 0.6779·0.69 + 0.7352·0.49 = 0.828. All ten values: 0.828, −1.778, 0.992, 0.274, 1.676, 0.913, −0.099, −1.145, −0.438, −1.224. Each point is now a single number.
  7. Using both components (p = d = 2) the projected data are just a rotation of the centred data: nothing is lost.

Check: the variance of the ten PC1 values is 1.2840 = λ₁, as the derivation says.

Widget: rotate the line, watch variance and error

Find PC1 yourself. The ten centred points from the example. Rotate the line through the origin: the segments are the distances to the line (the reconstruction error). The strip shows the 1-D projections.

At every angle variance along the line + average squared distance to the line = 1.3331 (the trace, i.e. total variance). So maximising the first term is the same as minimising the second: the two definitions of "best fit" agree. The maximum, 1.2840, occurs at θ = 47.3° (PC1); the minimum, 0.0491, at 137.3° (PC2).

7. Choosing how many components p

Keep as many as are needed to maintain a chosen percentage of the original variance (slide: "choose p based on what percentage of the variance of the original data we would like to maintain"):

proportion of variance explained by PC i = λ_i / (λ₁ + λ₂ + … + λ_d) cumulative proportion for p components = (λ₁ + … + λ_p) / (λ₁ + … + λ_d)
  • Plot the eigenvalues (the scree plot) and the cumulative proportion (slide: Optdigits data, eigenvalues falling quickly then flattening, cumulative proportion rising towards 1). Common choices: enough PCs to reach 90–95% of the variance, or the "elbow" where the eigenvalues level off.
  • Example: eigenvalues 6, 3, 1 give 60%, 30%, 10%; two components keep 90%.
  • If the classifier is the goal, choose p by cross-validated accuracy (it is a hyperparameter).

8. Getting the original data back

With the top p components, the approximation of an observation is x̂ = μ + Σi≤p (uiᵀ(x − μ)) ui = μ + WpWpᵀ(x − μ). The exact original data are recovered only if all d eigenvectors are used; otherwise information is lost (slide). The loss is exactly the variance you dropped:

mean squared reconstruction error = Σ_{i>p} λ_i (total squared error over n points = (n − 1) Σ_{i>p} λ_i)

Check on the example: with p = 1 the dropped variance is λ₂ = 0.0491, so the total squared error is 9 × 0.0491 = 0.442 (computed directly: 0.442). This is also the "minimum-error formulation" of PCA in Bishop §12.1.2: the subspace with maximum variance is the subspace with minimum reconstruction error.

9. Practical issues and limits

  • Scale matters. PCA on the covariance matrix is dominated by the variable with the largest numbers. On the past-paper data (price, weight), if weight were recorded in grams instead of kg the first PC would be essentially (0, 1): all weight. When variables have different units, standardise them (zero mean, unit variance, i.e. PCA on the correlation matrix) first. For the price/weight data PCA on the correlation matrix gives PC1 = (0.707, 0.707) instead of (0.243, 0.970). (Standard practice; the slides do not cover it.)
  • Unsupervised. PCA never looks at class labels: the highest-variance direction need not separate classes (see the LDA page for an example where PCA mixes two classes completely and LDA separates them).
  • Linear only. It finds linear subspaces; curved structure needs non-linear methods (kernel PCA, etc.).
  • Outliers can swing the direction of maximum variance.
  • Components are blends, so they are harder to interpret than original features.
  • Sign ambiguity: u and −u are the same direction; both are correct.
  • Few samples: with n samples the centred data have rank at most n − 1, so at most n − 1 eigenvalues are non-zero (30 samples of 100-D data have at most 29). Software usually uses the SVD of the centred data matrix instead of forming S: the right singular vectors are the eigenvectors and s²/(n − 1) the eigenvalues (checked on the example: 1.2840 and 0.0491). 10. Exam kit

Past papers: the price/weight PCA (F23, S23i, F22: "show the step-by-step calculation to derive the feature vector"); role of eigenvectors and eigenvalues, and how the covariance matrix helps find the principal components (F24, S23); PCA vs LDA as projection methods (S24).

Solved past-paper example: products (price, weight) = (4,7), (5,6), (3,1)

  1. Mean: (4, 4.667). Centred: (0, 2.333), (1, 1.333), (−1, −3.667).
  2. Covariance (divide by n − 1 = 2): var(price) = (0 + 1 + 1)/2 = 1; var(weight) = (5.444 + 1.778 + 13.444)/2 = 10.333; cov = (0 + 1.333 + 3.667)/2 = 2.5. S = [[1, 2.5], [2.5, 10.333]].
  3. Eigenvalues: det(S − λI) = (1 − λ)(10.333 − λ) − 6.25 = λ² − 11.333λ + 4.083 = 0, so λ₁ = 10.961, λ₂ = 0.373 (sum 11.333 = trace).
  4. Eigenvectors: for λ₁: (1 − 10.961)u₁ + 2.5u₂ = 0, so u₂ = 3.984u₁, normalise: u₁ = (0.243, 0.970). For λ₂: u₂ = (−0.970, 0.243).
  5. Feature vector (keep the largest eigenvalue): W = (0.243, 0.970)ᵀ. PC1 explains 10.961/11.333 = 96.7% of the variance, dominated by weight.
  6. New data: z = Wᵀ(x − mean): 2.26, 1.54, −3.80.

Template for any numerical PCA question

  1. Mean of each variable; centred data.
  2. Covariance matrix (state n − 1 or n; the lectures use n − 1).
  3. Characteristic equation (for 2 × 2: λ² − trace·λ + det = 0); both eigenvalues.
  4. Eigenvector for each λ by solving (S − λI)u = 0; normalise to length 1.
  5. Sort by eigenvalue; choose p; write the feature vector W.
  6. Project: Z = Wᵀ(centred data); say how much variance is kept.

Common mistakes

  • Forgetting to subtract the mean before computing S or before projecting.
  • Dividing by n in one place and n − 1 in another.
  • Not normalising the eigenvector (it must have unit length); or mixing up the order of the two eigenvectors.
  • Using the eigenvector of the smaller eigenvalue as PC1.
  • Claiming PCA uses class labels, or that the principal components are some of the original features.
  • Fitting PCA on train and test together.

Self-test

1. x = (1,2,3), y = (2,4,6). Covariance matrix and eigenvalues? What does it tell you?
var(x) = 1, var(y) = 4, cov = 2: S = [[1,2],[2,4]], trace 5, det 0, so λ = 5 and 0. PC1 explains 100%: y is exactly 2x, so the data are one-dimensional.
2. Eigenvalues of S are 8, 1.5, 0.5. Proportion explained by PC1 and by the first two PCs?
Total 10. PC1 = 80%; first two = 95%.
3. Why must the data be centred, and why must u be a unit vector?
Centring makes the projected mean zero so that var(uᵀX) = uᵀSu. Without ‖u‖ = 1 the variance grows without bound as u is scaled, so there would be no maximum.
4. u₁ = (0.6, 0.8) and a centred point (5, 5). Its PC1 coordinate? Reconstruction from PC1 alone?
z = 0.6·5 + 0.8·5 = 7. Reconstruction = z·u₁ = (4.2, 5.6) (plus the mean); the error vector is (0.8, −0.6), length 1.
5. 50 samples of 1 000-dimensional data. How many non-zero eigenvalues can S have?
At most n − 1 = 49.
6. Why does PCA on raw data in kg and on the same data in grams give different PCs, and what fixes it?
The covariance matrix is not scale-invariant: the variable with the largest numbers dominates. Standardise the variables (use the correlation matrix) before PCA.
