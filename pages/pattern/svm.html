Support vector machines: deep dive

Why maximum margin, how the optimisation problem is built, the full Lagrangian and dual derivation, soft margins, and kernels, with numbers you can check by hand.

Read: Bishop, PRML: Ch. 7 "Sparse Kernel Machines", §7.1 "Maximum Margin Classifiers" and §7.1.1 "Overlapping class distributions" (soft margin); Appendix E "Lagrange Multipliers"; Ch. 6 §6.1 "Dual Representations" and §6.2 "Constructing Kernels". Duda, Hart & Stork: Ch. 5 "Linear Discriminant Functions", §5.11 "Support Vector Machines". Han & Kamber, Data Mining: "Support Vector Machines" (source of the slide's 8-tuple illustration). Classic tutorial: Burges (1998), "A Tutorial on Support Vector Machines for Pattern Recognition".

1. The idea: not just any separating line

A linear classifier (least squares, perceptron) needs a hyperplane y(x) = wᵀx + b: class +1 if y(x) ≥ 0, else −1. If the data are separable, infinitely many hyperplanes work (the slide's B1, B2, …). The perceptron stops at the first one it finds, which may sit very close to some points, so a little noise misclassifies new data.

SVM answer: choose the hyperplane with the largest margin, the widest empty "street" between the classes. It is the safest against noise and generalises best. The points that touch the street are the support vectors; they alone determine the solution.

Orange outlines/edges: support vectors. w is perpendicular to the lines and points towards the +1 class.

History (slides): invented by Vapnik and Chervonenkis in the 1960s at the Institute of Control Sciences, Moscow ("method of generalized portrait"); became famous in the 1990s at AT&T Bell Labs with kernels. Also called the maximal margin classifier.

2. Margin and the primal problem

Geometry you need

  • The boundary is y(x) = 0. The vector w is normal to it (for two points a, b on the plane, wᵀ(a−b) = 0). The bias b shifts the plane.
  • Signed distance of x from the plane: write x = p + r·w/‖w‖ with p on the plane (y(p) = 0). Then y(x) = wᵀp + b + r‖w‖ = r‖w‖, so r = y(x)/‖w‖. Origin to plane: |b|/‖w‖.

Canonical scaling

(w,b) and (cw,cb) describe the same plane, so we are free to rescale until the closest points satisfy |wᵀx+b| = 1. For every training point (labels yi = ±1) this gives one compact condition:

y_i (wᵀx_i + b) ≥ 1 for all i (equality exactly for the support vectors)

Margin = 2/‖w‖

Take a support vector x₊ on wᵀx+b = +1 and x₋ on wᵀx+b = −1. The margin width is the projection of (x₊ − x₋) onto the unit normal w/‖w‖:

width = (x₊ − x₋)·w/‖w‖ = [(wᵀx₊ + b) − (wᵀx₋ + b)] / ‖w‖ = (1 − (−1)) / ‖w‖ = 2/‖w‖

The optimisation problem

maximise 2/‖w‖ ⇔ minimise ½‖w‖² subject to y_i(wᵀx_i + b) ≥ 1, i = 1…N
Why ½‖w‖² and not "maximise 2/‖w‖"? (asked in exams) (1) Maximising 1/‖w‖ is the same as minimising ‖w‖, and minimising ‖w‖ is the same as minimising ‖w‖² because squaring is monotonic for ‖w‖ ≥ 0. (2) ‖w‖² is smooth and convex, with no square root, so the problem is a convex quadratic programme with a unique global minimum. (3) The ½ cancels the 2 on differentiation: ∂(½‖w‖²)/∂w = w. (4) 1/‖w‖ blows up at w = 0, which is awkward.

This is a constrained optimisation problem. Next we turn it into an unconstrained one with Lagrange multipliers.

3. Lagrange multipliers, duality and KKT

Intuition (slides: level curves)

To optimise f(x) subject to g(x) = k, you cannot move freely; you slide along the constraint curve. At the best point the level curve of f just touches the constraint curve, so the two gradients are parallel: ∇f = λ∇g. The scalar λ is the Lagrange multiplier. Equivalent: stationary points of L = f − λg.

Small example (also an exam question): minimise f = x²+y² subject to x+1 = 0, y+1 = 0. L = x²+y² + λ₁(x+1) + λ₂(y+1); ∂x: 2x+λ₁ = 0, ∂y: 2y+λ₂ = 0, so x = y = −1, λ₁ = λ₂ = 2 and f = 2.

Inequality constraints: the generalised Lagrangian

For constraints g(x) ≥ 0 (here gi = yi(wᵀxi+b) − 1) use L(x,λ) = f(x) − Σλigi(x) with λi ≥ 0. Consider the inner maximisation over λ ≥ 0:

  • Case 1, constraint broken (g < 0): −λg is positive and grows without limit as λ → ∞, so maxλ L = +∞. This candidate is rejected.
  • Case 2, constraint satisfied (g ≥ 0): −λg ≤ 0, so the best λ makes the penalty zero (λ = 0 or g = 0) and maxλ L = f(x).

So minx maxλ≥0 L(x,λ) equals the original constrained problem (choose x to minimise f, while λ punishes violations). This is the primal.

Primal → dual

Primal: min_x max_{λ≥0} L(x,λ) Dual: max_{λ≥0} min_x L(x,λ)

In general swapping min and max is not allowed (the dual value is ≤ the primal value: weak duality). For the SVM, the objective is convex and the constraints are linear, so strong duality holds and both give the same optimum. That is why we may solve the dual.

KKT conditions

For the problem min f s.t. g ≥ 0, a global optimum satisfies:

1. ∇f(x) − λ∇g(x) = 0 (stationarity) 2. g(x) ≥ 0 (primal feasibility) 3. λ ≥ 0 (dual feasibility) 4. λ g(x) = 0 (complementary slackness)

For SVMs the KKT conditions hold (and are sufficient), so solving the dual loses nothing.

4. Deriving the dual, step by step

L_P(w,b,λ) = ½‖w‖² − Σ_i λ_i [ y_i(w·x_i + b) − 1 ], λ_i ≥ 0

Step 1: set derivatives to zero (minimise over w and b):

∂L_P/∂w = w − Σ λ_i y_i x_i = 0 ⇒ w = Σ λ_i y_i x_i ∂L_P/∂b = −Σ λ_i y_i = 0 ⇒ Σ λ_i y_i = 0

Step 2: substitute back. Expand LP = ½w·w − Σλiyi(w·xi) − bΣλiyi + Σλi:

  • Σλiyi(w·xi) = w·Σλiyixi = w·w.
  • bΣλiyi = b·0 = 0.
  • So L = ½w·w − w·w + Σλi = Σλi − ½w·w.
  • With w·w = (Σλiyixi)·(Σλjyjxj) = Σi,j λiλjyiyj(xi·xj).
maximise L_D(λ) = Σ_i λ_i − ½ Σ_i Σ_j λ_i λ_j y_i y_j (x_i · x_j) subject to λ_i ≥ 0, Σ_i λ_i y_i = 0

This is a standard quadratic programme (QP) in λ only; w and b have disappeared. Solvers: SMO (sequential minimal optimisation), LIBSVM, LIBLINEAR.

5. Using the solution

  1. Solve the dual for λ.
  2. Recover w: w = Σ λi yi xi (only support vectors contribute).
  3. Recover b: from any support vector s, ys(w·xs + b) = 1, so b = ys − w·xs (average over all SVs for numerical stability).
  4. Classify a new z: f(z) = sgn(w·z + b) = sgn(Σ λi yi (xi·z) + b).

What KKT says about the λ's

Complementary slackness: λi[yi(w·xi+b) − 1] = 0. For each point, either λi = 0 or the bracket is 0:

  • λi = 0: the point is strictly outside the street; it has no influence on w. Deleting it changes nothing.
  • λi > 0: then yi(w·xi+b) = 1: the point lies exactly on a margin line, i.e. it is a support vector. (Exam: "why are λi of support vectors greater than zero?" Because only points on the margin can have a nonzero multiplier.)

Also Σλiyi = 0 means the total multiplier weight of the positive SVs equals that of the negative SVs.

Worked example A: two points

x₁ = (2,2) with y = +1, x₂ = (0,0) with y = −1. Σλy = 0 forces λ₁ = λ₂ = λ.

x₁·x₁ = 8, x₂·x₂ = 0, x₁·x₂ = 0 L_D = λ₁ + λ₂ − ½ Σᵢⱼ λᵢλⱼ yᵢyⱼ (xᵢ·xⱼ) = 2λ − ½(8λ²) = 2λ − 4λ² (only the (1,1) term is nonzero) dL_D/dλ = 2 − 8λ = 0 ⇒ λ = 1/4 w = ¼(2,2) − ¼(0,0) = (½, ½) b = y₁ − w·x₁ = 1 − 2 = −1 check x₂: y₂(w·x₂ + b) = −(0 − 1) = 1 ✓ margin = 2/‖w‖ = 2/0.707 = 2.83 = distance between the points

Of course: with two points the best street is perpendicular to the segment joining them, and both are support vectors.

Worked example B: eight points

Positives (3,1), (3,−1), (6,1), (6,−1); negatives (1,0), (0,1), (0,−1), (−1,0). A QP solver (checked in code) gives support vectors (1,0) [λ = ½, y = −1], (3,1) and (3,−1) [λ = ¼ each, y = +1]; all other λ = 0.

Σ λ y = ¼ + ¼ − ½ = 0 ✓ w = ¼(3,1) + ¼(3,−1) − ½(1,0) = (1.5 − 0.5, 0) = (1, 0) b = y − w·x for SV (3,1): 1 − 3 = −2 boundary x₁ = 2, margin 2/‖w‖ = 2

Only 3 of 8 points matter: delete the other five and w, b are unchanged.

Worked example C: the slide's 8-tuple illustration (Han & Kamber)

QP gave λ = 65.52 for two tuples (0.38,0.47) with y = +1 and (0.49,0.61) with y = −1, and 0 for all others. Then w₁ = 65.52·0.38 − 65.52·0.49 = −6.64; w₂ = 65.52·0.47 − 65.52·0.61 = −9.32. b from each SV: b = 1 − w·x₁ = 7.93 (same from the other SV, average 7.93). Boundary: −6.64x₁ − 9.32x₂ + 7.93 = 0. For X = (0.5,0.5): −3.32 − 4.66 + 7.93 = −0.05 < 0, so X is assigned to the negative class.

6. Soft margin: when data are not cleanly separable

Scenario A (sensitive outlier): one noisy point near the other class shrinks the whole margin: a poor boundary. Scenario B: a positive point deep inside negative territory makes the hard-margin problem infeasible (no solution). Fix: let points violate the margin, at a price. Add a slack variable ξi ≥ 0:

hard: y_i(w·x_i + b) ≥ 1 soft: y_i(w·x_i + b) ≥ 1 − ξ_i ξ_i = 0 safely on the correct side of its margin line 0 < ξ_i ≤ 1 inside the street, but still on the correct side of the boundary ξ_i > 1 across the boundary: misclassified
minimise ½‖w‖² + C Σ_i ξ_i (maximise margin + minimise violations)
  • Large C: mistakes are expensive, so the model behaves like a hard-margin SVM (narrow margin, risk of overfitting).
  • Small C: mistakes are tolerated for a wider, more stable margin (risk of underfitting).

Soft-margin dual

The dual is the same as before except the box constraint 0 ≤ λi ≤ C (hard: λi ≥ 0). Meaning of λ:

  1. λ = 0: point safely beyond its margin line (ξ = 0), no influence.
  2. 0 < λ < C: point exactly on the margin line: a classic support vector.
  3. λ = C: point has violated the margin (ξ > 0): inside the street or misclassified.

Numerical illustration (computed in code)

Take example B's data and add one positive outlier at (1.5, 0), just beside the negative (1,0).

7. Non-linear SVM and the kernel trick

If the classes are not linearly separable in x-space, map to a feature space: x → φ(x), and find a linear boundary there. Dual: replace xi·xj by φ(xi)·φ(xj). Problem: if φ takes 1000 features to 10 000 (or infinitely many), computing the dot products is very costly.

Kernel trick: a kernel function K(x,z) = φ(x)·φ(z) returns the high-dimensional dot product by computing something cheap in the original space. We never build φ(x).

Example (slides): degree-2 polynomial in 2-D

Let φ(x) = (x₁², √2·x₁x₂, x₂²) (3-D). Then

φ(x)·φ(z) = x₁²z₁² + 2x₁x₂z₁z₂ + x₂²z₂² = (x₁z₁ + x₂z₂)² = (x·z)² = K(x,z)

The "expensive 3-D dot product" becomes the 2-D dot product, squared. For K(x,z) = (1 + x·z)² the mapping is φ(x) = (1, √2x₁, √2x₂, x₁², √2x₁x₂, x₂²) (6-D), so it includes all terms up to degree 2.

Common kernels

KernelFormulaUse when
Linearx·zdata already linearly separable, or very many features (text)
Polynomial(γ x·z + c)dyou know feature interactions matter; γ scale, c constant, d degree
RBF (Gaussian)exp(−γ‖x − z‖²)no prior knowledge of the geometry, not linearly separable, moderate number of features

RBF: "where is the dot product?" Expand ‖x−z‖² = x·x − 2x·z + z·z; the exponential of a dot product expands into an infinite series, so φ is infinite-dimensional and only the kernel makes it computable. γ controls reach: large γ = tall, narrow bumps (small variance), the boundary wraps tightly around points: overfitting. Small γ = wide, flat bumps, a very smooth boundary: underfitting. Tune γ and C together by cross-validation.

Worked example: XOR becomes separable

Points (1,1), (−1,−1) in class +1 and (1,−1), (−1,1) in class −1. No line separates them (a linear SVM gets only 50%). Use K(x,z) = (1+x·z)². The feature √2·x₁x₂ equals +√2 for the positives and −√2 for the negatives, so in feature space the hyperplane "√2x₁x₂ = 0" separates them with margin 2√2. Code check: the dual has all four λ = 0.125 (all points are support vectors), bias 0, and all four points are classified correctly.

Why the dual, and why w is not computed

  • In the primal, φ(x) appears inside w·φ(x), so you need φ explicitly. In the dual, the objective and constraints depend on the data only through inner products, so K can replace them. "The dual representation is the only way to unlock the kernel trick."
  • The dual has N variables (one per sample) rather than one per feature, so it suits problems with very many features.
  • In kernel SVMs, w = Σλiyiφ(xi) lives in feature space and may be infinite-dimensional, so it is not computed. Classify with f(z) = sgn(Σ λi yi K(xi,z) + b), with b found from a support vector.
  • A valid kernel must correspond to some inner product (Mercer condition: symmetric, positive semi-definite kernel matrix); Bishop §6.2 gives rules for building kernels.

Strengths: convex (no local minima), good generalisation, sparse solution (only SVs matter), works in high dimensions. Weaknesses: training cost grows quickly with N, kernel and C need tuning, no direct probabilities, two-class by nature (multi-class by one-vs-rest or one-vs-one).

9. Exam kit

SVM appears in every past paper. Typical wording and where to look:
  • Explain the Lagrange multiplier in SVM; why solve the dual rather than the primal (F24, S24, F23, every paper) → §3 and §7 ("Why the dual").
  • Show M = 2/‖w‖; show the objective reduces to minimise ½‖w‖² s.t. y(wᵀx+b) ≥ 1; why minimise ½‖w‖² (S24, S23i, F22) → §2.
  • Express the boundary with the multipliers and show it satisfies KKT (F23) → §4–5.
  • Why λi > 0 for support vectors (S24) → §5.
  • Kernel trick with (1 + xᵀz)² (F24); why w is not computed in a kernel SVM (S24) → §7.
  • Soft margin dual vs hard margin (S24) → §6.
  • Given α's, b and support vectors: find w, hyperplane, classify a point (F23) → §5; use w = Σαkvk and check w·v + b = ±1.
  • Which of Naive Bayes, single-layer perceptron, SVM can classify a ring-shaped scatter plot (F22)? SVM: yes, with a non-linear kernel (RBF or polynomial), because the boundary in feature space is linear but a closed curve in x-space. Single-layer perceptron: no, its boundary is a straight line. Naive Bayes: not reliably; Gaussian Naive Bayes has at most a quadratic boundary and the independence and Gaussian assumptions fit a ring poorly. State your reasoning against the actual plot on the paper.

Common mistakes

  • Forgetting the label yi in w = Σλiyixi, or the constraint Σλiyi = 0.
  • Margin is 2/‖w‖, not 1/‖w‖ (1/‖w‖ is the distance from the boundary to one side).
  • Computing b from a point that is not a support vector (λ = 0).
  • Mixing up the roles: C is a soft-margin penalty; γ is the RBF width; λ are the Lagrange multipliers.
  • Saying large γ gives a smooth boundary (it is the opposite: large γ overfits).

Self-test

1. For a hard-margin SVM, ‖w‖ = 4. What is the margin, and the distance from the boundary to a support vector?
Margin = 2/4 = 0.5; each support vector is 1/4 = 0.25 from the boundary.
2. Four support vectors with y·λ values −0.5, +0.5, −0.5, +0.5 at (−1,1), (2,0), (1,−1), (0,2), b = −1. Find w and classify (1,1).
w = −0.5(−1,1) + 0.5(2,0) − 0.5(1,−1) + 0.5(0,2) = (1,1). w·(1,1) + b = 2 − 1 = +1, so class +1. Check: w·v + b = ±1 for all four.
3. In a soft-margin SVM a point has λ = C. What can you say about it?
It violated its margin: ξ > 0, so it lies inside the street or on the wrong side (possibly misclassified).
4. You raise γ in an RBF SVM. Effect on bias and variance?
Narrower bumps, a more flexible boundary: lower bias, higher variance (overfitting). Lower γ or C to regularise.
5. Why can the perceptron's answer differ between runs but the SVM's not?
The perceptron stops at the first separating plane it finds (order and initial w matter). The SVM minimises a strictly convex objective, so its maximum-margin solution is unique.
6. Show that K(x,z) = (x·z)² corresponds to a feature map for 2-D inputs.
φ(x) = (x₁², √2x₁x₂, x₂²): φ(x)·φ(z) = x₁²z₁² + 2x₁x₂z₁z₂ + x₂²z₂² = (x₁z₁ + x₂z₂)².
