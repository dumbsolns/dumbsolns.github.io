Bayesian decision theory: deep dive

The theory of the best possible classifier: posteriors, minimum error, risk and loss, discriminant functions for Gaussian classes (all three cases derived), error bounds, ROC, and the extensions to discrete, missing and compound decisions.

Read: Duda, Hart & Stork, Ch. 2 "Bayesian Decision Theory": §2.1 Introduction, §2.2 "Bayesian Decision Theory: Continuous Features" (§2.2.1 two-category), §2.3 "Minimum-Error-Rate Classification", §2.4 "Classifiers, Discriminant Functions, and Decision Surfaces", §2.5 "The Normal Density", §2.6 "Discriminant Functions for the Normal Density" (cases 1–3), §2.7 "Error Probabilities and Integrals", §2.8 "Error Bounds for Normal Densities" (Chernoff, Bhattacharyya, §2.8.3 ROC), §2.9 "Discrete Features", §2.10 "Missing and Noisy Features", §2.12 "Compound Bayesian Decision Theory and Context". Bishop, PRML, §1.5 "Decision Theory" (§1.5.1 misclassification rate, §1.5.2 expected loss, §1.5.3 reject option) and §2.3 "The Gaussian Distribution".

1. The setting and the vocabulary

Bayesian decision theory designs classifiers that make decisions by minimising an expected risk. The simplest risk is the classification error; when some mistakes are worse than others, the risk includes their costs.

TermSymbolMeaning (fish example)
State of nature (class)ω₁, ω₂sea bass, salmon
PriorP(ωj)how likely each fish is before looking at it
Evidencep(x)density of the measurement (lightness) over all fish
Likelihoodp(x|ωj)how often we measure lightness x when the fish is class j
PosteriorP(ωj|x)probability the fish is class j given the measured x
Bayes' rule: P(ω_j | x) = p(x | ω_j) P(ω_j) / p(x), p(x) = Σ_j p(x | ω_j) P(ω_j) posterior = likelihood × prior / evidence

The evidence is the same for all classes, so for comparing classes it only scales the posteriors (they must sum to 1: P(ω₁|x) + P(ω₂|x) = 1).

2. Minimum-error classification

Priors only

With no measurement: decide ω₁ if P(ω₁) > P(ω₂), else ω₂. It favours the likelier class and makes the same decision every time; it is optimal when nothing else is known.

With the measurement x

decide ω₁ if P(ω₁|x) > P(ω₂|x), else ω₂ ⇔ p(x|ω₁)P(ω₁) > p(x|ω₂)P(ω₂) (evidence cancels) ⇔ p(x|ω₁)/p(x|ω₂) > P(ω₂)/P(ω₁) (likelihood ratio vs threshold θ_a)

Slide illustration: with P(ω₁) = 2/3 and P(ω₂) = 1/3 the posterior curves are the likelihoods re-weighted and re-normalised; where the weighted curves cross the decision changes.

Why this rule minimises the error

Choosing ω₁ at x makes an error only if the true class is ω₂ (probability P(ω₂|x)), and vice versa:

P(error | x) = P(ω₁|x) if we decide ω₂, P(ω₂|x) if we decide ω₁ the Bayes rule picks the larger posterior, so P(error | x) = min[ P(ω₁|x), P(ω₂|x) ] P(error) = ∫ P(error|x) p(x) dx (average error)

At every x the rule makes P(error|x) as small as it can possibly be; any other rule picks the smaller posterior at some x and increases the error there. Since p(x) ≥ 0, the integral is also minimised. In terms of regions: P(error) = P(ω₂)∫R₁p(x|ω₂)dx + P(ω₁)∫R₂p(x|ω₁)dx. (Exam: "explain why the Bayes rule minimises the average probability of error".)

Priors matter: take p(x|ω₁) = 0.8 and p(x|ω₂) = 0.2 at some x. With equal priors P(ω₁|x) = 0.8. With P(ω₁) = 0.3 and P(ω₂) = 0.7: P(ω₁|x) = 0.24/(0.24 + 0.14) = 0.63. The likelihood is the same; a smaller prior lowers the posterior.

3. Where do the probabilities come from?

  • Objective approach: probabilities come only from experiments (frequencies).
  • Subjective approach: probabilities express degree of belief, based on opinion (used when data are scarce, e.g. assume a Gaussian).
  • Mixed: choose a subjective model (e.g. Gaussian) and use an objective dataset to fit its parameters (μ, Σ), the subject of the parameter-estimation chapter.

Slide example (objective): luxury or standard car from its height

C₁ = price > $50K (luxury), C₂ = price ≤ $50K; feature x = car height. Collect data: 1 209 cars, 221 luxury and 988 standard.

  1. Priors: P(C₁) = 221/1209 = 0.183, P(C₂) = 988/1209 = 0.817.
  2. Likelihoods: separate the data by class, discretise the height into bins, count cars per bin, normalise the histogram (e.g. if 46 luxury cars fall in a bin, that bin's value is 46 divided by the total times the bin width).
  3. Posterior in a bin: if p(x = 1.0|C₁) = 0.2081 and p(x = 1.0|C₂) = 0.0597:
P(C₁|x = 1.0) = 0.2081·0.183 / (0.2081·0.183 + 0.0597·0.817) = 0.0381 / 0.0869 = 0.438

So a car of this height is more likely standard (0.562) even though luxury cars are fairly common at that height: the small luxury prior (0.183) pulls the posterior down.

4. The general theory: actions, loss and risk

Generalise in four ways: use many features (x ∈ Rd), allow c categories, allow actions other than classifying (such as rejecting), and use a general loss function.

  • Categories ω₁…ωc; actions α₁…αl.
  • Loss λ(αi|ωj): the cost of taking action αi when the true class is ωj.
conditional risk (expected loss of action α_i given x): R(α_i | x) = Σ_{j=1..c} λ(α_i | ω_j) P(ω_j | x) overall risk: R = ∫ R(α(x) | x) p(x) dx α(x) = decision rule Bayes rule: (i) compute R(α_i | x) for every action; (ii) choose the action with minimum R(α_i | x) minimum overall risk R* = Bayes risk = the best performance achievable

Two categories

Let α₁ = decide ω₁, α₂ = decide ω₂, λij = λ(αi|ωj).

R(α₁|x) = λ₁₁P(ω₁|x) + λ₁₂P(ω₂|x) R(α₂|x) = λ₂₁P(ω₁|x) + λ₂₂P(ω₂|x) decide ω₁ if R(α₁|x) < R(α₂|x) ⇔ (λ₂₁ − λ₁₁) P(ω₁|x) > (λ₁₂ − λ₂₂) P(ω₂|x) ⇔ (λ₂₁ − λ₁₁) p(x|ω₁)P(ω₁) > (λ₁₂ − λ₂₂) p(x|ω₂)P(ω₂) ⇔ p(x|ω₁)/p(x|ω₂) > [(λ₁₂ − λ₂₂)/(λ₂₁ − λ₁₁)] · P(ω₂)/P(ω₁) = θ_b (assuming λ₂₁ > λ₁₁)

A wrong decision costs more than a right one (λ₂₁ > λ₁₁, λ₁₂ > λ₂₂), so the sign flip when dividing is safe. The likelihood-ratio plot in the slides shows the threshold θa (zero-one loss) and θb (general loss) cutting the ratio curve into decision regions R₁, R₂, R₁, R₂.

Zero-one loss recovers minimum error

λ(α_i|ω_j) = 0 if i = j, 1 if i ≠ j R(α_i|x) = Σ_{j≠i} P(ω_j|x) = 1 − P(ω_i|x) minimise R ⇔ maximise P(ω_i|x): decide ω_i if P(ω_i|x) > P(ω_j|x) for all j ≠ i two classes: θ_a = P(ω₂)/P(ω₁)

The overall risk is then the average probability of error: zero-one loss is just the "all errors are equally bad" special case.

Slide example: the cost of a missed disease

A blood test gives P(ω₁|x) = 0.15 (severe disease) and P(ω₂|x) = 0.85 (healthy). Actions: α₁ = give treatment, α₂ = send home. Losses: λ(α₁|ω₂) = 1 (treating a healthy person: mild sickness), λ(α₂|ω₁) = 100 (sending a sick person home: death), correct actions cost 0.

R(α₁|x) = 0·0.15 + 1·0.85 = 0.85 R(α₂|x) = 100·0.15 + 0·0.85 = 15.00 → minimum risk: α₁, TREAT
The posterior alone says "85% healthy, do nothing", but the expected loss says treat. When errors have unequal costs, the most probable class is not necessarily the best decision.

Reject option

Add a third action αr ("too uncertain, ask a human") with loss λr in every state. Decide the class with the largest posterior unless the minimum risk exceeds λr. With zero-one loss, reject when maxi P(ωi|x) < 1 − λr. Example: λr = 0.3 and posteriors (0.55, 0.45): risk of the best class is 1 − 0.55 = 0.45 > 0.3, so reject. (Bishop §1.5.3.)

5. Discriminant functions

A classifier can be written as c functions gi(x): assign x to ωi if gi(x) > gj(x) for all j ≠ i. For the Bayes classifier:

  • General loss: gi(x) = −R(αi|x) (risk is minimised, a discriminant is maximised, so the minus sign).
  • Zero-one loss: gi(x) = P(ωi|x) = p(x|ωi)P(ωi)/p(x).

The choice is not unique: replacing gi by f(gi) for any monotonically increasing f, multiplying all gi by the same positive constant, or adding the same constant to all, leaves the decisions unchanged. So drop p(x) and take logs:

g_i(x) = p(x|ω_i)P(ω_i) or, more usefully, g_i(x) = ln p(x|ω_i) + ln P(ω_i)

The log form is used throughout the Gaussian cases. The feature space splits into decision regions R₁…Rc separated by decision boundaries where gi(x) = gj(x).

Two categories: a dichotomizer. One function g(x) = g₁(x) − g₂(x): decide ω₁ if g(x) > 0. It gives a simpler rule and a clear geometry (boundary g = 0). With logs:

g(x) = ln [ p(x|ω₁)/p(x|ω₂) ] + ln [ P(ω₁)/P(ω₂) ] (log-likelihood ratio + log prior ratio)

6. Gaussian class densities N(μi, Σi)

g_i(x) = −½ (x − μ_i)ᵀ Σ_i⁻¹ (x − μ_i) − (d/2) ln 2π − ½ ln|Σ_i| + ln P(ω_i)

The term −(d/2) ln 2π is the same for every class and is dropped. Everything else depends on how much structure we assume for Σi:

CaseΣiGeometry of the classesBoundary
Iσ²I (uncorrelated, equal variance, same for all classes)identical sphereshyperplane ⟂ to the line joining the means
IIΣ (shared, any shape)identical ellipsoids (same size, shape and tilt)hyperplane, not ⟂ to the means line
IIIarbitrary Σidifferent ellipses cutting through each otherhyperquadric (non-linear)

Case I: Σi = σ²I, step by step (as in the slides)

|Σi| = σ2d and Σi⁻¹ = I/σ², so

g_i(x) = −‖x − μ_i‖²/(2σ²) − (d/2)ln 2π − d ln σ + ln P(ω_i) drop the class-independent terms; expand ‖x − μ_i‖² = xᵀx − 2μ_iᵀx + μ_iᵀμ_i; xᵀx is also common to all classes, so drop it: g_i(x) = w_iᵀx + w_i0, w_i = μ_i/σ², w_i0 = −μ_iᵀμ_i/(2σ²) + ln P(ω_i) (a linear discriminant)

Boundary g₁(x) = g₂(x):

(μ₁ − μ₂)ᵀx/σ² − (‖μ₁‖² − ‖μ₂‖²)/(2σ²) + ln P(ω₁) − ln P(ω₂) = 0 multiply by σ², use ‖μ₁‖² − ‖μ₂‖² = (μ₁ − μ₂)ᵀ(μ₁ + μ₂): (μ₁ − μ₂)ᵀ[ x − ½(μ₁ + μ₂) ] + σ² ln[P(ω₁)/P(ω₂)] = 0 write the last term as (μ₁ − μ₂)ᵀ{ σ² ln[P(ω₁)/P(ω₂)] (μ₁ − μ₂)/‖μ₁ − μ₂‖² } and factor out: wᵀ(x − x₀) = 0 w = μ₁ − μ₂, x₀ = ½(μ₁ + μ₂) − [σ² / ‖μ₁ − μ₂‖²] · ln[P(ω₁)/P(ω₂)] · (μ₁ − μ₂)
  • The boundary is a hyperplane through x₀, orthogonal to the line joining the means (its normal is μ₁ − μ₂).
  • Equal priors: the log term vanishes and x₀ is the midpoint ½(μ₁ + μ₂). Unequal priors: x₀ moves away from the more likely class (towards the less likely mean), enlarging the more likely class's region.
  • If σ is very small relative to ‖μ₁ − μ₂‖, the shift σ²/‖μ₁ − μ₂‖² ln(…) is tiny: the boundary is insensitive to the priors.
  • Minimum-distance classifier: with equal priors gi(x) = −‖x − μi‖²: assign x to the nearest mean in Euclidean distance (assumptions: independent features, same variance).

Numbers: μ₁ = (0,0), μ₂ = (4,0), σ² = 1. Equal priors: x₀ = (2,0). With P(ω₁) = 0.8, P(ω₂) = 0.2: x₀ = (2,0) − (1/16)·ln 4·(−4,0) = (2.35, 0), shifted towards ω₂ because ω₁ is likelier.

Case II: Σi = Σ

Now −½ ln|Σ| is also common. Expand −½(x − μi)ᵀΣ⁻¹(x − μi); xᵀΣ⁻¹x is common, and μiᵀΣ⁻¹x = xᵀΣ⁻¹μi because Σ is symmetric:

g_i(x) = w_iᵀx + w_i0, w_i = Σ⁻¹μ_i, w_i0 = −½ μ_iᵀΣ⁻¹μ_i + ln P(ω_i) (linear discriminant) boundary: wᵀ(x − x₀) = 0, w = Σ⁻¹(μ₁ − μ₂) x₀ = ½(μ₁ + μ₂) − { ln[P(ω₁)/P(ω₂)] / [(μ₁ − μ₂)ᵀΣ⁻¹(μ₁ − μ₂)] } · (μ₁ − μ₂)
  • A hyperplane through x₀, but not orthogonal to the line joining the means (the normal is Σ⁻¹(μ₁ − μ₂), tilted by the covariance). With unequal priors x₀ again moves away from the likelier class.
  • Mahalanobis-distance classifier: with equal priors gi(x) = −½(x − μi)ᵀΣ⁻¹(x − μi): assign to the class with the smallest Mahalanobis distance r² = (x − μi)ᵀΣ⁻¹(x − μi). It generalises Euclidean distance (equal when Σ = σ²I) by rescaling and rotating the axes according to the covariance.

Numbers: Σ = [[2, 0.5], [0.5, 1]], μ₁ = (1,1), μ₂ = (3,−1), equal priors: x₀ = (2,0), w = Σ⁻¹(−2, 2) = (−1.71, 2.86). The angle between w and the means line is about 14° (cosine 0.97): clearly not orthogonal. For x = (2.5, 0.5): r₁² = 2.00, r₂² = 3.14, so choose ω₁.

Case III: Σi arbitrary

Only the class-independent −(d/2) ln 2π is dropped; the quadratic terms no longer cancel:

g_i(x) = xᵀW_i x + w_iᵀx + w_i0 W_i = −½Σ_i⁻¹, w_i = Σ_i⁻¹μ_i, w_i0 = −½μ_iᵀΣ_i⁻¹μ_i − ½ ln|Σ_i| + ln P(ω_i)

The boundaries are hyperquadrics: hyperplanes, pairs of hyperplanes, hyperspheres, hyperellipsoids, hyperparaboloids and hyperhyperboloids. They are non-linear, and need not pass through the midpoint of the means.

Slide example: μ₁ = (3,6), Σ₁ = diag(½, 2); μ₂ = (3,−2), Σ₂ = diag(2, 2); equal priors. The boundary is the parabola x₂ = 3.514 − 1.125x₁ + 0.1875x₁² (I checked it by solving g₁ = g₂ numerically: e.g. x₁ = 0 → x₂ = 3.514, x₁ = 3 → 1.83). Its lowest point, 1.83 at x₁ = 3, is near the midpoint x₂ = 2, but it curves up to 3.5 at x₁ = 0 and x₁ = 6, far from the straight midpoint line: it bends round ω₁, the class with the smaller spread in x₁, and ω₂ (wider in x₁) owns the region below the parabola.

Try: equal σ and equal priors: the boundary sits at the midpoint of the means (Case I/II in 1-D). Raise P(ω₁): the boundary moves towards ω₂ (away from the likelier class). Make σ₁ ≠ σ₂: you can get two boundaries, because the log densities are quadratic (Case III), and the region of the narrower class becomes an interval.

7. Error bounds

Exact error probabilities require integrating the overlapping densities, which is hard in many dimensions; bounds are easier. Start from min[a, b] ≤ aβb1−β (for 0 ≤ β ≤ 1):

P(error) ≤ P(ω₁)^β P(ω₂)^(1−β) ∫ p(x|ω₁)^β p(x|ω₂)^(1−β) dx = P(ω₁)^β P(ω₂)^(1−β) e^(−k(β)) for Gaussians: k(β) = [β(1−β)/2] (μ₂ − μ₁)ᵀ[βΣ₁ + (1−β)Σ₂]⁻¹(μ₂ − μ₁) + ½ ln( |βΣ₁ + (1−β)Σ₂| / (|Σ₁|^β |Σ₂|^(1−β)) )
  • Chernoff bound: minimise the bound over β, i.e. maximise k(β): a one-dimensional problem regardless of the dimension of x.
  • Bhattacharyya bound: simply set β = 0.5: easier to compute, but looser.
  • Both are good only for Gaussian densities.

Check on the Case III example (equal priors): with β = 0.5, Σ̄ = diag(1.25, 2), μ₂ − μ₁ = (0, −8): first term 0.125 · 64/2 = 4.0; log term ½ ln(2.5/2) = 0.11; k(0.5) = 4.11 and P(error) ≤ 0.5 · e−4.11 = 0.0082. The Chernoff optimum is β ≈ 0.503, essentially the same (0.0082). A simulation of 2 million samples gives a true error of about 0.002: the bound is valid but about four times too high. (The slide's own example quotes k(0.5) = 4.06 and P(error) ≤ 0.0087.) Equal-variance 1-D case N(0,1) vs N(2,1): k(0.5) = Δμ²/8 = 0.5, bound 0.30; true error Φ(−1) = 0.159.

8. Thresholds and ROC curves

Every classifier uses some threshold. For the likelihood ratio: a = P(ω₂)/P(ω₁) (zero-one loss) or b = P(ω₂)(λ₁₂ − λ₂₂) / [P(ω₁)(λ₂₁ − λ₁₁)] (general loss). Changing the threshold changes the error rates, and the ROC curve plots the trade-off to compare classifiers.

Slide example: person authentication (biometrics). Two classes: Authentic (A) and Impostor (I). Four outcomes:

  • correct acceptance (true positive): the person is A and we decide A;
  • incorrect acceptance (false positive, FAR = false accept rate): the person is I and we decide A;
  • correct rejection (true negative): I, decide I;
  • incorrect rejection (false negative, FRR = false reject rate): A, but we decide I.

Moving the threshold x* trades FAR against FRR. Numbers: impostor scores ~ N(0,1), authentic ~ N(2,1); accept if score > x*.

x*FAR = P(score > x* | I)FRR = P(score < x* | A)

1.00.1590.159
1.50.0670.309

Strict thresholds (high x*) reject impostors but also lock out genuine users; x* = 1 gives the equal error rate 0.159. The best operating point depends on the costs: a bank vault wants low FAR, a phone unlock wants low FRR. See the chapter notes (model evaluation) for TPR/FPR and AUC.

9. Extensions: discrete, missing and compound

Discrete features

If x takes only discrete values, replace the integral ∫ p(x|ωj) dx by a sum Σx P(x|ωj); the rule is unchanged: decide the class maximising P(x|ωj)P(ωj) (Naive Bayes exercises use this).

Missing features

Suppose x = [xg, xb] with the "bad" part xb missing. Filling it in with a mean value can mislead. The Bayes-correct way is to marginalise over the missing features:

P(ω_i | x_g) = ∫ P(ω_i | x_g, x_b) p(x_g, x_b) dx_b / p(x_g) = ∫ g_i(x) p(x) dx_b / ∫ p(x) dx_b

Example: equal priors; x₁ ∈ {0,1} missing, x₂ = 1 observed; if the features are independent given the class, then p(x₁, x₂ = 1|ωi) = p(x₁|ωi)p(x₂ = 1|ωi) and the sum over x₁ equals 1, so the missing feature simply drops out. With p(x₂ = 1|ω₁) = 0.3 and p(x₂ = 1|ω₂) = 0.6 the posterior of ω₂ is 0.6/0.9 = 0.67: decide ω₂.

Compound decisions

Sequential: decide each pattern (each fish) as it arrives. Compound: wait for n patterns X = (x₁…xn) and decide all states Ω = (ω(1)…ω(n)) jointly, where each ω(i) takes one of c values. This can improve performance when consecutive states of nature are not statistically independent (e.g. letters in a word, weather on consecutive days), because the prior P(Ω) then carries information that one-at-a-time decisions throw away. Assuming independence given the states, p(X|Ω) = Π p(xi|ω(i)). (Duda §2.12.)

Common mistakes

  • Forgetting the evidence p(x) cancels, or comparing likelihoods instead of likelihood × prior.
  • Choosing the most probable class when the loss function is unequal (see the 0.85 vs 15 example).
  • Putting the log prior ratio with the wrong sign: x₀ moves away from the likelier class.
  • Using Euclidean distance when the covariance is not σ²I (use Mahalanobis).
  • Saying Case III boundaries are lines, or that Case II is orthogonal to the means.
  • Applying Chernoff/Bhattacharyya to non-Gaussian densities.

Self-test

1. P(ω₁) = 0.3, P(ω₂) = 0.7, p(x|ω₁) = 0.8, p(x|ω₂) = 0.2. Posterior of ω₁?
0.3·0.8 = 0.24; 0.7·0.2 = 0.14; P(ω₁|x) = 0.24/0.38 = 0.632.
2. λ₁₁ = 0, λ₁₂ = 4, λ₂₁ = 1, λ₂₂ = 0 and P(ω₁|x) = 0.7. Which action minimises risk?
R(α₁) = 4·0.3 = 1.2; R(α₂) = 1·0.7 = 0.7. Choose α₂ (decide ω₂) even though ω₁ is more probable, because wrongly deciding ω₁ costs 4.
3. Case I, μ₁ = (0,0), μ₂ = (6,0), σ² = 3, P(ω₁) = 2P(ω₂). Where is x₀?
x₀ = (3,0) − [3/36]·ln 2·(−6, 0) = (3 + 0.347, 0) = (3.35, 0): shifted towards ω₂ (the less likely class).
4. 1-D, N(0,1) vs N(2,1), equal priors. Boundary and Bayes error?
Boundary x = 1 (the midpoint). Error = Φ(−1) = 0.159.
5. Why does minimising risk with zero-one loss reduce to maximising the posterior?
R(αi|x) = Σj≠i P(ωj|x) = 1 − P(ωi|x); the smallest risk is the largest posterior.
6. Why can two Gaussian classes with different variances give two decision boundaries in 1-D?
g₁ − g₂ contains the terms (x − μi)²/(2σi²) with different coefficients, so it is a quadratic in x and can have two roots (Case III): the narrower class owns an interval, the wider class both tails.
