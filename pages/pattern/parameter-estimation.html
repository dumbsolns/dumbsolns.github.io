Parameter estimation: MLE, Bayesian estimation and MAP

How to turn training samples into the parameters of a class-conditional density: the maximum-likelihood principle, its Gaussian derivations, why the variance estimate is biased, then the Bayesian and MAP views with a live posterior widget.

Read: Duda, Hart & Stork, Ch. 3 "Maximum-Likelihood and Bayesian Parameter Estimation": §3.1 Introduction, §3.2 "Maximum-Likelihood Estimation" (§3.2.1 The general principle, §3.2.2 The Gaussian case: unknown μ, §3.2.3 unknown μ and Σ, §3.2.4 Bias), §3.3 "Bayesian Estimation" (§3.3.1 The class-conditional densities, §3.3.2 The parameter distribution), §3.4 "Bayesian Parameter Estimation: Gaussian Case". Bishop, PRML: §2.3.4 "Maximum likelihood for the Gaussian", §2.3.6 "Bayesian inference for the Gaussian", §1.2.5 "Curve fitting re-visited" (MAP), §2.1 "Binary variables". Slide sources: Veksler (CS434), Picone (ECE 8527), Stanley Chan (ECE 595).

1. The problem

The Bayes classifier needs the priors P(ωi) and the class-conditional densities p(x|ωi). In practice we only have training samples. Priors are easy (count the class frequencies). Densities are hard, especially when the feature dimension d is large.

Parametric trick: if general knowledge lets us assume a form, e.g. p(x|ωi) = N(μi, Σi), the unknown function becomes a few unknown numbers θ = (μ, Σ). Then use the training samples to estimate θ, and plug the estimates into the Bayes decision rule as if they were true (the pipeline in the slides: training data D → estimate θ̂ → density p(x|θ̂) → Bayes decision boundary).

Parameters to estimate for a d-dimensional Gaussian: d (mean) + d(d+1)/2 (symmetric covariance): 5 for d = 2, 65 for d = 10, 5 150 for d = 100. Many parameters need many samples, which is one face of the curse of dimensionality.

2. Maximum-likelihood estimation

Assumptions

  • Samples are split by class into c sets D₁…Dc; the samples in Dj are drawn i.i.d. (independent, identically distributed) from p(x|ωj).
  • p(x|ωj) has a known parametric form, fixed by a parameter vector θj; write p(x|θ) (the notation shows dependence on θ; it is not a conditional density in the probabilistic sense).
  • Di says nothing about θj for i ≠ j (functionally independent parameters), so we solve c separate problems, one per class.

Likelihood and its maximiser

p(D|θ) = Π_{k=1..n} p(x_k|θ) = F(θ) likelihood of θ for the sample set D θ̂ = argmax_θ p(D|θ) maximum-likelihood estimate

As a function of θ, p(D|θ) is not a density (it need not integrate to 1 over θ). Intuition (Duda Fig. 3.1): for a Gaussian with unknown mean, the likelihood peaks at the value that sits at the centre of the observed points.

Log trick and recipe

The log is monotonic, so maximising p(D|θ) and maximising l(θ) = ln p(D|θ) give the same θ̂, and the product becomes a sum, which is easier to differentiate:

l(θ) = Σ_k ln p(x_k|θ) θ̂ = argmax l(θ) necessary condition: ∇_θ l = Σ_k ∇_θ ln p(x_k|θ) = 0 (p equations for p parameters)
  1. Write the likelihood.
  2. Take logs.
  3. Differentiate and set to 0.
  4. Solve for θ̂.
  5. Check it is a maximum (second derivative negative), not a minimum or saddle, and check the boundary of the parameter range.

Example from the slides: which coin?

Straight coin: P(H) = ½. Bent coin: P(H) = 4/5. Observed D = HTHHHTHHTHTH (8 heads, 4 tails). The likelihood of each model:

p(D|Bent) = (4/5)⁸(1/5)⁴ = 0.000268 p(D|Straight) = (1/2)¹² = 0.000244 argmax over {Bent, Straight} → Bent

MLE picks the model under which the data were most probable: the bent coin (just barely). No prior knowledge was used; remember this for §6.

3. MLE derivations you must know

(a) Gaussian, unknown mean, known covariance

ln p(x_k|μ) = −½ ln[(2π)^d |Σ|] − ½ (x_k − μ)ᵀΣ⁻¹(x_k − μ) ∇_μ ln p(x_k|μ) = Σ⁻¹(x_k − μ) Σ_k Σ⁻¹(x_k − μ̂) = 0 ⇒ Σ⁻¹(Σ_k x_k − n μ̂) = 0 ⇒ Σ_k x_k = n μ̂ μ̂ = (1/n) Σ_k x_k

The ML estimate of the mean is the sample average, "very intuitive". (Σ⁻¹ is invertible so it can be cancelled; this is why Σ known or not does not change μ̂.)

(b) Gaussian, unknown mean and variance (univariate)

Let v = σ². l(μ, v) = −(n/2)ln 2π − (n/2)ln v − (1/2v) Σ(x_k − μ)².

∂l/∂μ = (1/v) Σ(x_k − μ) = 0 ⇒ μ̂ = (1/n) Σ x_k ∂l/∂v = −n/(2v) + (1/2v²) Σ(x_k − μ̂)² = 0 ⇒ multiply by 2v²: −nv + Σ(x_k − μ̂)² = 0 σ̂² = (1/n) Σ (x_k − μ̂)²

Multivariate: μ̂ = (1/n)Σx_k, Σ̂ = (1/n)Σ(x_k − μ̂)(x_k − μ̂)ᵀ.

Numeric check: data {2, 4, 6, 8}: μ̂ = 5, σ̂² = (9+1+1+9)/4 = 5. In 2-D: samples (1,2), (3,3), (5,7) give μ̂ = (3,4) and Σ̂ = [[2.67, 3.33], [3.33, 4.67]].

(c) Multivariate Bernoulli (past exam question)

x is a d-dimensional binary vector with P(x|θ) = Πi θixi(1 − θi)1−xi.

l(θ) = Σ_k Σ_i [ x_ki ln θ_i + (1 − x_ki) ln(1 − θ_i) ] ∂l/∂θ_i = Σ_k [ x_ki/θ_i − (1 − x_ki)/(1 − θ_i) ] = 0 ⇒ Σ_k x_ki (1 − θ_i) = θ_i Σ_k (1 − x_ki) ⇒ Σ_k x_ki = n θ_i θ̂_i = (1/n) Σ_k x_ki i.e. θ̂ = (1/n) Σ_k x_k

Each θ̂i is the fraction of samples in which bit i equals 1. Numeric: 8 flips 1,0,1,1,0,1,1,1 give θ̂ = 6/8 = 0.75.

(d) Exponential density (slide: "MLE Math")

p(x|θ) = θe−θx for x ≥ 0. Then l(θ) = n ln θ − θ Σxk; dl/dθ = n/θ − Σxk = 0 gives θ̂ = n/Σxk = 1/x̄; d²l/dθ² = −n/θ² < 0, so it is a maximum. For samples 0.5, 1, 2.5: x̄ = 4/3, θ̂ = 0.75.

4. How good is an estimate? Bias, variance, consistency

  • Bias: how close the average estimate is to the truth. θ̂ is unbiased if E[θ̂] = θ.
  • Variance: how much the estimate changes from one data set to another.
  • Trade-off: usually you can reduce one only at the expense of the other.
  • Consistent / converges: the estimate approaches the truth as n → ∞.

The ML mean is unbiased with variance σ²/n

E[μ̂] = (1/n) Σ E[x_i] = (1/n)(nμ) = μ → unbiased Var[μ̂] = (1/n²) Σ Var[x_i] = nσ²/n² = σ²/n (independence) → 0 as n → ∞ (slide route: E[x_i x_j] = μ² for i≠j and μ²+σ² for i=j; E[μ̂²] = μ² + σ²/n)

The ML variance is biased

Use E[x²] = μ² + σ² (since Var(x) = E[x²] − μ²) and E[μ̂²] = μ² + σ²/n. Expand σ̂² = (1/n)Σ(xi − μ̂)² = (1/n)Σxi² − μ̂²:

E[σ̂²] = (μ² + σ²) − (μ² + σ²/n) = σ² (1 − 1/n) = ((n − 1)/n) σ² Unbiased estimator: s² = (1/(n−1)) Σ (x_i − μ̂)² covariance: C = (1/(n−1)) Σ (x_i − μ̂)(x_i − μ̂)ᵀ

Intuition: the deviations are measured from μ̂, which is the point closest to these samples, so they are smaller than deviations from the true μ. Averaged over many data sets the ML variance lands at (n−1)/n of the truth: systematically too small. It still converges (the factor → 1).

5. Limits of MLE

  • Zero probabilities: a bag-of-words model trained on one 10-word sentence gives each seen word probability 0.1 and every unseen word probability 0. A test sentence with one new word then has probability 0, however good the rest. Out-of-vocabulary words are common even with huge corpora.
  • Overfits small samples: with 3 heads in 3 flips, MLE says P(H) = 1.
  • No place for prior knowledge: you may know that a bent coin is rare, but MLE ignores it.

The remedy is to put a prior on unseen events, "a practical application of Bayesian learning": this leads to §6–7.

6. Bayesian estimation

Treat θ as a random variable. Before data, our knowledge is the prior p(θ). Seeing D converts it into the posterior (hopefully peaked near the true θ):

p(θ|D) = p(D|θ) p(θ) / p(D) = p(D|θ) p(θ) / ∫ p(D|θ) p(θ) dθ p(D|θ) = Π_k p(x_k|θ)

Using it for classification: P(ωi|x, D) uses p(x|ωi, D) (the training data inform the density). Because x is independent of D once θ is known:

p(x|D) = ∫ p(x|θ) p(θ|D) dθ (average the model over all plausible θ, weighted by the posterior)

Univariate Gaussian, unknown mean (σ² known)

Model p(x|μ) = N(μ, σ²) and prior p(μ) = N(μ₀, σ₀²). Then

p(μ|D) ∝ Π_k p(x_k|μ) · p(μ) ∝ exp{ −½ [ Σ_k (x_k − μ)²/σ² + (μ − μ₀)²/σ₀² ] } = exp{ −½ [ (n/σ² + 1/σ₀²) μ² − 2 (Σ_k x_k/σ² + μ₀/σ₀²) μ + const ] }

This is the exponential of a quadratic in μ, so p(μ|D) is Gaussian, N(μn, σn²), for every n: a reproducing density, and p(μ) is a conjugate prior. Match coefficients ("equating coefficients") with exp{−½[μ²/σn² − 2μnμ/σn² + …]}:

1/σ_n² = n/σ² + 1/σ₀² μ_n/σ_n² = n x̄_n/σ² + μ₀/σ₀² (x̄_n = sample mean) Solve: σ_n² = σ₀² σ² / (n σ₀² + σ²) μ_n = [ n σ₀² / (n σ₀² + σ²) ] x̄_n + [ σ² / (n σ₀² + σ²) ] μ₀
  • μn is our best guess after n samples: a weighted average of the data mean x̄n and the prior mean μ₀ (weights sum to 1).
  • σn² is our remaining uncertainty; it approaches σ²/n for large n, and the posterior becomes more sharply peaked: Bayesian learning.
  • Predictive density: p(x|D) = N(μn, σ² + σn²): the noise σ² plus our remaining uncertainty about μ.

7. MAP estimation

MAP picks the mode of the posterior instead of keeping the whole distribution. Since p(D) does not depend on θ:

θ̂_MAP = argmax_θ p(θ|D) = argmax_θ Π_k p(x_k|θ) · p(θ) = argmin_θ − Σ_k { ln p(x_k|θ) + ln p(θ) } (log-likelihood + log-prior)

Compared with MLE the extra term ln p(θ) pulls the estimate towards what the prior considers plausible. With a flat prior MAP = MLE.

1-D Gaussian example (slides), one sample x: likelihood N(x; θ, σ²), prior N(θ; θ₀, σ₀²).

minimise (x − θ)²/(2σ²) + (θ − θ₀)²/(2σ₀²) derivative: (θ − x)/σ² + (θ − θ₀)/σ₀² = 0 ⇒ θ(σ₀² + σ²) = σ₀² x + σ² θ₀ θ̂_MAP = (σ₀² x + σ² θ₀) / (σ₀² + σ²)

For n samples, the same steps give θ̂MAP = (nσ₀²x̄ + σ²θ₀)/(nσ₀² + σ²) = μn: the Bayesian posterior mean, because a Gaussian posterior's mode and mean coincide. Numerically, x = 2, σ² = 4, θ₀ = 0, σ₀² = 1 gives θ̂ = 2/5 = 0.4 (MLE would say 2).

Interpreting the result

  • σ₀ = 0: θ̂ = θ₀. Absolutely sure of the prior, no uncertainty (p(θ) = δ(θ − θ₀)); the data are ignored.
  • σ₀ → ∞: θ̂ = x. "I don't trust my prior at all, use the data": uniform prior, MAP = MLE.
  • In between, MAP is a trade-off between data and prior. More data (n ↑) shifts the weight to the data; with large n, MAP ≈ MLE (the exam asks you to show this: divide μn's numerator and denominator by nσ₀²; the weight of μ₀ is (σ²/nσ₀²)/(1 + σ²/nσ₀²) → 0).

Back to the coin

Give the bent coin a prior probability of 0.2 (bent coins are rare) and the straight coin 0.8. Posterior ∝ likelihood × prior: bent 0.000268 × 0.2 = 5.4×10⁻⁵; straight 0.000244 × 0.8 = 1.95×10⁻⁴. Posterior probabilities: bent 0.22, straight 0.78. MAP chooses the straight coin while MLE chose the bent coin: the prior overrode weak evidence. (They agree only if the prior of "bent" is above 0.476.)

Answer template: "Differences between MLE and Bayesian estimation"

  1. MLE: θ fixed unknown; maximise p(D|θ); point estimate; no prior.
  2. Bayesian: θ random with prior p(θ); posterior p(θ|D) ∝ p(D|θ)p(θ); uses all information.
  3. Bayesian estimate for a Gaussian mean is the weighted average μn of the sample mean and the prior mean; as n → ∞ it tends to the MLE x̄ and σn² → 0.
  4. MAP is the point estimate at the mode of the posterior; MAP = MLE for a flat prior or large n.

Common mistakes

  • Forgetting the log or to check the second derivative; differentiating the product instead of the sum.
  • Using the unbiased 1/(n−1) when the question says "MLE" (MLE uses 1/n); or the reverse for an "unbiased estimate".
  • Mixing the roles: σ² is the known data noise; σ₀² is the prior's width, so σ₀² → ∞ means "no prior".
  • Writing the weights of μn the wrong way round (weight on x̄ is nσ₀²/(nσ₀²+σ²), on μ₀ it is σ²/(nσ₀²+σ²)).
  • Saying MLE is "biased" in general: the ML mean is unbiased, the ML variance is biased.

Self-test

1. Samples 3, 5, 10 from N(μ, σ²). ML estimates of μ and σ²? Unbiased variance?
μ̂ = 6; σ̂² = (9 + 1 + 16)/3 = 8.67; unbiased s² = 26/2 = 13.
2. Prior N(0, 1), σ² = 4, one sample x = 5. MAP estimate and posterior variance?
μ₁ = (1·1·5 + 4·0)/(1·1 + 4) = 1.0; σ₁² = 1·4/(1 + 4) = 0.8.
3. Why does MAP approach MLE when n is large?
The data weight nσ₀²/(nσ₀²+σ²) → 1 and the prior weight → 0; equivalently the likelihood term (a sum over n samples) grows while the prior term is a single fixed term.
4. Exponential density θe−θx, samples 1, 2, 3. ML estimate of θ?
θ̂ = n/Σx = 3/6 = 0.5.
5. Why can the ML variance estimator not be unbiased, and how do we fix it?
It measures spread around μ̂, which is fitted to the same samples, so E[σ̂²] = ((n−1)/n)σ². Divide by n − 1 instead of n.
6. 10 flips, 7 heads. MLE of P(H)? MAP with a Beta(2,2) prior (add one head and one tail)?
MLE = 7/10 = 0.70; MAP = (7 + 1)/(10 + 2) = 0.667, pulled slightly towards 0.5.
