1.2 Bias–variance decomposition of the squared errorE[(y − f̂)²] = bias² + variance + σ²
E[(y − f̂)²] = bias² + variance + σ²

Setup: y = f(x) + ε, E[ε] = 0, Var ε = σ², ε independent of the fitted f̂. Expectation is over training sets and noise.

E[(y − f̂)²] = E[(f − f̂ + ε)²] = E[(f − f̂)²] + 2E[(f − f̂)ε] + E[ε²]

The cross term is 0 (ε independent with zero mean), so E[(y − f̂)²] = E[(f − f̂)²] + σ². Now add and subtract f̄ = E[f̂]:

E[(f − f̂)²] = (f − f̄)² + E[(f̂ − f̄)²] + 2(f − f̄) E[f̄ − f̂] E[f̄ − f̂] = 0 → the cross term vanishes E[(y − f̂)²] = (f − f̄)² + E[(f̂ − f̄)²] + σ² bias² variance irreducible noise

Too simple a model: large bias, small variance. Too flexible: small bias, large variance.

2.5 Perceptron convergence theoremIf the data are linearly separable, at most R²/γ² updates occur.
If the data are linearly separable, at most R²/γ² updates occur.

Flip class −1 samples (φ ← tφ) so a solution means ŵᵀφ_n > 0. Let ‖ŵ‖ = 1, γ = min ŵᵀφ_n > 0, R = max ‖φ_n‖, w_0 = 0.

Each update adds a mistake: w_{k+1} = w_k + φ with w_kᵀφ ≤ 0.

ŵᵀw_{k+1} = ŵᵀw_k + ŵᵀφ ≥ ŵᵀw_k + γ ⇒ ŵᵀw_k ≥ kγ ⇒ ‖w_k‖ ≥ kγ (Cauchy–Schwarz) ‖w_{k+1}‖² = ‖w_k‖² + 2w_kᵀφ + ‖φ‖² ≤ ‖w_k‖² + R² ⇒ ‖w_k‖² ≤ kR² k²γ² ≤ ‖w_k‖² ≤ kR² ⇒ k ≤ R²/γ²

The number of updates is finite, so the algorithm halts at a separating vector.

2.7 XOR and d-bit parity are not linearly separableNo weights w1, w2, w0 satisfy all four XOR conditions.
No weights w1, w2, w0 satisfy all four XOR conditions.

Classes: (0,0),(1,1) → ω2 (need g < 0); (1,0),(0,1) → ω1 (need g > 0); g = w1x1 + w2x2 + w0.

g(0,0) < 0 ⇒ w0 < 0 g(1,0) > 0 ⇒ w1 + w0 > 0 g(0,1) > 0 ⇒ w2 + w0 > 0 g(1,1) < 0 ⇒ w1 + w2 + w0 < 0

3.1 Margin = 2/‖w‖Margin width 2/‖w‖ when the closest points satisfy y(wᵀx + b) = 1.
Margin width 2/‖w‖ when the closest points satisfy y(wᵀx + b) = 1.

3.3 Inequality constraints: the min–max Lagrangianmin_x max_{λ≥0} L(x,λ) equals the original constrained problem.
min_x max_{λ≥0} L(x,λ) equals the original constrained problem.
L(x, λ) = f(x) − Σ λ_i g_i(x), constraints g_i(x) ≥ 0, λ_i ≥ 0

Inner maximisation over λ ≥ 0, constraint by constraint:

g_i < 0 (violated): −λ_i g_i > 0 and grows with λ_i ⇒ max_λ L = +∞ (candidate rejected) g_i ≥ 0 (satisfied): −λ_i g_i ≤ 0 ⇒ best λ_i = 0 (or g_i = 0) ⇒ max_λ L = f(x)

So min_x max_λ L = min f(x) over the feasible points. Weak duality: max min ≤ min max. For the SVM (convex objective, linear constraints) strong duality holds, so the two are equal.

4.1 Bayes' rule and the evidenceP(ω_j|x) = p(x|ω_j)P(ω_j)/p(x), p(x) = Σ p(x|ω_j)P(ω_j)
P(ω_j|x) = p(x|ω_j)P(ω_j)/p(x), p(x) = Σ p(x|ω_j)P(ω_j)

Definition of conditional probability, both ways, for the joint density:

p(ω_j, x) = P(ω_j|x) p(x) = p(x|ω_j) P(ω_j) P(ω_j|x) = p(x|ω_j) P(ω_j) / p(x)

The evidence by total probability (the ω_j are exhaustive and exclusive):

p(x) = Σ_j p(x, ω_j) = Σ_j p(x|ω_j) P(ω_j) ⇒ Σ_j P(ω_j|x) = 1

p(x) is the same for all classes, so it drops out when comparing posteriors.

4.2 The Bayes rule minimises the error probabilityP(error|x) = min[P(ω1|x), P(ω2|x)], so the average error is minimal.
P(error|x) = min[P(ω1|x), P(ω2|x)], so the average error is minimal.
P(error|x) = P(ω1|x) if we decide ω2, P(ω2|x) if we decide ω1 deciding the class with the larger posterior gives P(error|x) = min[P(ω1|x), P(ω2|x)] P(error) = ∫ P(error|x) p(x) dx

Any other rule picks the smaller posterior at some x and so raises P(error|x) there. Because p(x) ≥ 0, minimising pointwise minimises the integral.

In terms of regions R1, R2:

P(error) = P(ω2) ∫_{R1} p(x|ω2) dx + P(ω1) ∫_{R2} p(x|ω1) dx decide ω1 ⇔ P(ω1|x) > P(ω2|x) ⇔ p(x|ω1)P(ω1) > p(x|ω2)P(ω2) ⇔ p(x|ω1)/p(x|ω2) > P(ω2)/P(ω1)

4.3 Minimum-risk rule for two categoriesDecide ω1 if p(x|ω1)/p(x|ω2) > [(λ12 − λ22)/(λ21 − λ11)] · P(ω2)/P(ω1).
Decide ω1 if p(x|ω1)/p(x|ω2) > [(λ12 − λ22)/(λ21 − λ11)] · P(ω2)/P(ω1).
R(α1|x) = λ11 P(ω1|x) + λ12 P(ω2|x) R(α2|x) = λ21 P(ω1|x) + λ22 P(ω2|x) decide ω1 ⇔ R(α1|x) < R(α2|x) ⇔ (λ21 − λ11) P(ω1|x) > (λ12 − λ22) P(ω2|x) ⇔ (λ21 − λ11) p(x|ω1)P(ω1) > (λ12 − λ22) p(x|ω2)P(ω2) (p(x) cancels) ⇔ p(x|ω1)/p(x|ω2) > [(λ12 − λ22)/(λ21 − λ11)] · P(ω2)/P(ω1) (dividing by λ21 − λ11 > 0)

9.4 TD and Q-learning updatesQ ← Q + α[r + γ max Q(s′,a′) − Q] = (1 − α)Q + α[r + γ max Q(s′,a′)].

The two forms of the update are the same algebra:

Q + α(t − Q) = Q − αQ + αt = (1 − α)Q + α t with target t = r + γ max_{a′} Q(s′,a′)

Why the target is right: at a fixed point Q = Q*, the expected target equals the Bellman optimality right-hand side,

E[ r + γ max_{a′} Q*(s′,a′) | s, a ] = Q*(s,a)

so the TD error t − Q has expected value 0 and Q stops moving on average.
