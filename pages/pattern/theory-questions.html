1. Foundations and design

Curse of dimensionalityAsked in: S25
Short answer. As the number of features grows, the volume of the feature space grows exponentially, so a fixed data set becomes sparse; the data needed, the cost, and the risk of overfitting all explode, and distances stop being informative.

Definition. The curse of dimensionality (Bellman) is the set of problems that appear when the number of features d is large compared with the number of samples n.

Why it happens

  • Exponential volume. Cutting each feature into 10 intervals gives 10d cells. To have about 10 samples per cell you need 10d+1 samples: 100 for d = 1, 10 000 for d = 3, 1011 for d = 10.
  • Sparsity. With fixed n, most cells (and most of the space) are empty; estimates of densities or boundaries in empty regions are guesses.
  • Everything is near the boundary. In a unit hypercube, the fraction of volume within 0.1 of a face is 1 − 0.8d: 36% for d = 2, 89% for d = 10, over 99.99% for d = 100. Samples sit at the edges, not in the middle.
  • Distance concentration. In high dimensions the distances from a point to its nearest and farthest neighbours become almost equal, so nearest-neighbour and clustering methods lose meaning.
  • Parameter growth. A d-dimensional Gaussian has d + d(d+1)/2 parameters (5 for d = 2, 65 for d = 10, 5 150 for d = 100). Estimating them needs far more samples; with n < d the covariance matrix is singular.

Consequences

Overfitting (the model fits noise), poor generalisation, high computation and storage cost, and classifiers that get worse as useless features are added (the Hughes phenomenon).

Remedies

  • Reduce dimension: feature selection, PCA (unsupervised), LDA (supervised, at most C − 1 dimensions).
  • Collect more data, or use models with strong assumptions (Naive Bayes needs only d one-dimensional densities).
  • Regularisation, ensembles, and domain knowledge to build a few good features.

Possible follow-up questions

Does adding features always improve a classifier?
No. Unreliable, noisy or correlated (redundant) features add no information but add dimensions; with limited data the classifier gets worse. Add a feature only if it brings discriminative information and you can afford the data to estimate it.
Why do nearest-neighbour methods suffer especially?
They rely on distances. When all points are about equally far apart, "nearest" is no longer meaningful, and a ball containing a few neighbours covers a large fraction of the space.
How does PCA help against the curse?
It projects onto the few directions with the most variance, so the classifier works in p ≪ d dimensions while keeping most of the variation.

Supervised, unsupervised and reinforcement learningAsked in: S25 (unsupervised), S23, F22
Short answer. Supervised learning learns from labelled examples, unsupervised learning finds structure in unlabelled data, and reinforcement learning learns from rewards received after taking actions.

Unsupervised learning (the "define" answer): the training data contain only inputs x, with no labels or teacher. The system forms clusters or natural groupings, or finds a compact representation, by itself. Typical tasks: clustering (k-means, hierarchical), dimensionality reduction (PCA), density estimation. Categories are discovered; people may name them afterwards (a satellite image clusters into four groups that an analyst then calls water, soil, vegetation, forest).

Possible follow-up questions

How do you judge a clustering when there are no labels?
With internal criteria (SSE, how compact and separated the clusters are), by stability, or by checking whether the groups are useful for a later task. There is no single correct answer, which is why the number of clusters is a modelling choice.
What is semi-supervised learning?
A mix: a few labelled and many unlabelled examples, using the unlabelled data to learn structure and the labelled ones to name it.

Overfitting, underfitting, bias and variance (effect of model complexity)Asked in: S23, S23i
Short answer. As model complexity grows, bias falls and variance rises. Training error keeps decreasing, but test error is U-shaped: choose the complexity at the minimum of the validation error.

Definitions

  • Underfitting (high bias): the model is too simple to capture the pattern (a line through curved data); error is high on training and test data.
  • Overfitting (high variance): the model is so flexible that it fits the noise; training error is tiny but test error is large; it changes a lot from one training set to another.
  • Bias is the error of the average prediction against the truth; variance is how much predictions fluctuate across training sets. Expected squared error = bias² + variance + irreducible noise σ².

Effect of complexity

Example (polynomial fits, 10 noisy points, noise level 0.30, average of 300 data sets): training error 0.71 (M = 0), 0.24 (M = 3), 0.00 (M = 9); test error 0.77, 0.35, 0.74. The best model has intermediate complexity.

What makes overfitting likelier

  • too few training examples
  • too many features
  • an over-complex hypothesis class

Remedies

  • more data (with 100 points the degree-9 test error drops from 0.74 to 0.31)
  • simpler model, fewer features, feature selection or PCA
  • regularisation (penalise large weights)
  • ensembles (bagging reduces variance, boosting reduces bias)
  • choose hyperparameters by validation or cross-validation

Possible follow-up questions

How can you tell from the errors whether you are over- or underfitting?
Both train and test error high and close: underfitting. Train error low, test error much higher: overfitting.
How does boosting relate to bias and variance?
Boosting combines many weak (high-bias) learners sequentially, each focusing on earlier mistakes, so the ensemble has much lower bias. Bagging averages high-variance learners to lower variance.
Which of train or test error is a fair estimate of future performance?
Only error on data not used for training or tuning (a held-out test set or cross-validation).

Regularisation in logistic regressionAsked in: S24
Short answer. Regularisation adds a penalty on the size of the weights to the loss, e.g. J(w) = −log-likelihood + (λ/2)‖w‖²; it shrinks the weights, smooths the boundary and reduces overfitting.

Model. Logistic regression predicts P(y = 1|x) = σ(wᵀx + b) with σ(a) = 1/(1 + e−a) and is trained by minimising the negative log-likelihood (cross-entropy):

J(w) = − Σ [ y_n ln p_n + (1 − y_n) ln(1 − p_n) ] + (λ/2) ‖w‖² (L2 regularisation) gradient: ∇J = Σ (p_n − y_n) x_n + λ w update: w ← w − η(∇loss + λw)

Why it is needed

  • With many features or few samples, the model can fit the training labels perfectly with large, wildly varying weights (the polynomial example: weights near 250 000 at degree 9).
  • If the classes are linearly separable, the unregularised optimum has ‖w‖ → ∞ (the sigmoid keeps sharpening); the penalty keeps the solution finite.

How it works

  • The penalty λ‖w‖² makes large weights expensive, so the optimiser trades training fit against weight size ("keep all features but reduce the magnitude of the parameters θj").
  • λ controls complexity: λ = 0 gives the plain model (may overfit); very large λ pushes all weights to 0 (underfits). Choose λ by validation or cross-validation.
  • Bayesian view: an L2 penalty is MAP estimation with a Gaussian prior w ~ N(0, 1/λ·I); an L1 penalty λ‖w‖₁ corresponds to a Laplace prior and produces sparse weights (feature selection).
  • Do not penalise the bias b; standardise features first so the penalty treats them equally.

Possible follow-up questions

L1 versus L2?
L2 shrinks all weights smoothly and keeps them non-zero; L1 drives many weights exactly to zero (sparse, interpretable models).
What is the link to the SVM parameter C?
C multiplies the error term in the SVM objective, so C plays the role of 1/λ: small C = strong regularisation (wide margin), large C = weak.

Why mean versus median: minimising Σ(y_i − c)² gives c = ȳ (derivative −2Σ(y_i − c) = 0), whereas Σ|y_i − c| is minimised at the median. For data {1, 2, 3, 100}: mean = 26.5, median = 2.5. For errors (1, 1, 1, 10): MSE = 25.75 but MAE = 3.25; the single outlier supplies 97% of the MSE.

How to decide

  • Errors roughly Gaussian, and big misses really are much worse: MSE.
  • Data contain outliers or measurement glitches, or the cost of an error grows linearly: MAE (or a compromise such as the Huber loss: quadratic for small errors, linear for large ones).
  • You need a closed-form solution or smooth optimisation: MSE.
  • Check the residual plot: heavy tails suggest MAE or Huber.

Possible follow-up questions

What does RMSE add?
It is the square root of MSE, so it is in the units of y and easier to interpret, but it keeps the outlier sensitivity of MSE.
Why is the gradient of MSE for a linear model simple?
∂/∂w of (1/n)Σ(y − wx − b)² = −(2/n)Σ x(y − ŷ): proportional to the errors, so steps shrink as the fit improves.

Mutually exclusive and non-exclusive eventsAsked in: S25
Short answer. Mutually exclusive events cannot occur together (P(A∩B) = 0, so P(A∪B) = P(A) + P(B)); non-exclusive events can (P(A∪B) = P(A) + P(B) − P(A∩B)).

Mutually exclusive (disjoint): the occurrence of one rules out the other. Example: toss one coin: head and tail; roll one die: "even" {2, 4, 6} and "odd" {1, 3, 5}. P(even ∩ odd) = 0, P(even ∪ odd) = 1/2 + 1/2 = 1.

Non-exclusive: they can happen on the same trial. Example: draw one card: "heart" and "king" (the king of hearts); roll a die: "even" {2, 4, 6} and "greater than 3" {4, 5, 6} share {4, 6}:

P(even ∪ >3) = 3/6 + 3/6 − 2/6 = 4/6 (subtract the overlap once, else it is counted twice)

Common confusions

  • Exclusive is not independent. If P(A), P(B) > 0 and A, B are exclusive, then P(A|B) = 0 ≠ P(A): they are strongly dependent (knowing one occurred tells you the other did not). Independent events satisfy P(A∩B) = P(A)P(B).
  • Exhaustive means at least one of them happens; classes in classification are mutually exclusive and exhaustive, so the posteriors P(ωj|x) add to 1.
  • Multi-label tasks (a photo can contain both a dog and a car) have non-exclusive labels; multi-class single-label tasks have exclusive ones.

Possible follow-up questions

Can two events be both mutually exclusive and independent?
Only if at least one has probability 0, because exclusive means P(A∩B) = 0 and independent means P(A∩B) = P(A)P(B).
Where does this matter in the course?
In Bayes' rule the total-probability sum Σ_j p(x|ω_j)P(ω_j) is valid because the classes are exclusive and exhaustive.

Why the Bayes rule minimises the average probability of errorAsked in: S25
Short answer. At every x the rule picks the class with the larger posterior, so P(error|x) = min[P(ω1|x), P(ω2|x)] is as small as possible at each x; averaging over p(x) ≥ 0 therefore gives the smallest possible total error.

Setting

Two classes with priors P(ωj) and likelihoods p(x|ωj). By Bayes' rule P(ωj|x) = p(x|ωj)P(ωj)/p(x). The rule: decide ω₁ if P(ω₁|x) > P(ω₂|x).

Proof

  1. If we decide ω₂ at x, the decision is wrong exactly when the true class is ω₁, which has probability P(ω₁|x); deciding ω₁ errs with probability P(ω₂|x). So P(error|x) is the posterior of the class we did not choose.
  2. Choosing the class with the larger posterior leaves the smaller posterior as the error: P(error|x) = min[P(ω₁|x), P(ω₂|x)]. No decision at that x can give a smaller conditional error.
  3. The total error is the average of the conditional error: P(error) = ∫ P(error|x) p(x) dx. Because p(x) ≥ 0, making the integrand smallest at every x makes the integral smallest. Any other rule chooses the smaller posterior at some set of points and adds error there.
  4. Equivalent region form: P(error) = P(ω₂)∫R₁p(x|ω₂)dx + P(ω₁)∫R₂p(x|ω₁)dx. Moving the boundary away from the point where the two weighted densities cross enlarges one integral by more than it shrinks the other.

The minimum value of P(error) is the Bayes error; it is not zero when the class densities overlap, and no classifier can beat it.

Possible follow-up questions

Is the Bayes error zero?
Only if the class densities do not overlap. Otherwise it is the area under the smaller of the two weighted densities, the irreducible error.
What if the two kinds of mistake have different costs?
Then minimise the expected loss (risk) instead: the boundary moves, see the minimum-risk rule.
Why is the evidence p(x) not needed to decide?
It is the same for both classes, so comparing p(x|ω₁)P(ω₁) with p(x|ω₂)P(ω₂) is equivalent.

Decision rule for the zero-one loss functionAsked in: S25
Short answer. With zero-one loss, the conditional risk is R(α_i|x) = 1 − P(ω_i|x), so minimum risk means "decide the class with the largest posterior": the minimum-error-rate (MAP) classifier.

Zero-one loss: λ(αi|ωj) = 0 if i = j, 1 if i ≠ j: a correct decision costs nothing and every error costs 1.

R(α_i|x) = Σ_j λ(α_i|ω_j) P(ω_j|x) = Σ_{j≠i} P(ω_j|x) = 1 − P(ω_i|x) minimise R ⇔ maximise P(ω_i|x) decide ω_i if P(ω_i|x) > P(ω_j|x) for all j ≠ i two classes: decide ω₁ if p(x|ω₁)/p(x|ω₂) > P(ω₂)/P(ω₁) (threshold θ_a)

The overall risk equals the probability of error, so this is the minimum-error-rate classifier. In discriminant form, gi(x) = P(ωi|x), or equivalently ln p(x|ωi) + ln P(ωi).

Possible follow-up questions

When is zero-one loss inappropriate?
When errors have different costs (disease screening, fraud): use the general loss and the minimum-risk rule.

Role of the loss function; minimum-risk decision ruleAsked in: S24, S25 (derive)
Short answer. The loss function states how costly each (action, true class) pair is; the Bayes decision minimises the expected loss R(α_i|x) = Σ_j λ(α_i|ω_j)P(ω_j|x). For two classes decide ω₁ if (λ₂₁−λ₁₁)p(x|ω₁)P(ω₁) > (λ₁₂−λ₂₂)p(x|ω₂)P(ω₂).

Role of the loss function

  • It turns "how likely" into "how bad": the cheapest action is not always the most probable class. It lets the classifier trade errors, e.g. accept more false alarms to avoid missed diseases.
  • It also allows actions other than classifying, such as reject.

Derivation (two categories)

R(α₁|x) = λ₁₁P(ω₁|x) + λ₁₂P(ω₂|x) R(α₂|x) = λ₂₁P(ω₁|x) + λ₂₂P(ω₂|x) decide ω₁ ⇔ R(α₁|x) < R(α₂|x) ⇔ (λ₂₁ − λ₁₁)P(ω₁|x) > (λ₁₂ − λ₂₂)P(ω₂|x) ⇔ (λ₂₁ − λ₁₁)p(x|ω₁)P(ω₁) > (λ₁₂ − λ₂₂)p(x|ω₂)P(ω₂) ⇔ p(x|ω₁)/p(x|ω₂) > [(λ₁₂ − λ₂₂)/(λ₂₁ − λ₁₁)] · P(ω₂)/P(ω₁)

Example (slides)

Blood test: P(disease|x) = 0.15, P(healthy|x) = 0.85. Treating a healthy patient costs 1; sending a sick patient home costs 100. R(treat) = 0·0.15 + 1·0.85 = 0.85; R(send home) = 100·0.15 + 0·0.85 = 15. Treat, although "healthy" is far more probable.

Reject option: a third action with loss λr; with zero-one loss reject when maxi P(ωi|x) < 1 − λr. Bayes risk is the minimum overall risk, the best performance any classifier can achieve.

Possible follow-up questions

What happens to the decision threshold when false negatives cost more?
The threshold on the likelihood ratio falls (θ_b is smaller), so more samples are assigned to the class that is costly to miss.
What is the Bayes risk?
The expected loss of the Bayes decision rule, ∫ min_i R(α_i|x) p(x) dx; no rule can have lower risk.

Gaussian discriminant analysis (GDA) versus Naive Bayes (NB)

  • GDA: continuous features that are roughly Gaussian per class, with correlations among features captured by the covariance matrix (shared Σ gives a linear boundary, different Σi a quadratic one). Needs enough samples to estimate the covariance (d(d+1)/2 parameters).
  • NB: high-dimensional discrete or sparse features (text, spam), few samples: it needs only d one-dimensional distributions per class.

The strong assumption of Naive Bayes

Features are conditionally independent given the class: P(x|ω) = Πi P(xi|ω). It is rarely exactly true (words are correlated) but is often good enough for classification because only the ranking of the class scores matters.

Why Laplace smoothing is necessary

Estimating P(xi|ω) from counts gives 0 for a value never seen with that class, which makes the whole product 0 whatever the other features say (one unseen word wipes out a spam score). Add 1 to every count and the number of possible values V to the denominator: P(xi=v|ω) = (count + 1)/(nω + V). This is MAP estimation with a uniform (Dirichlet/Beta) prior.

Possible follow-up questions

Which generalises better with small data?
Often the generative model (if its assumptions are reasonable), because it imposes more structure; with large data, discriminative models usually win.
How does Naive Bayes classify?
Compute ln P(ω) + Σ ln P(xi|ω) for each class and choose the largest.

Mahalanobis distance and why it generalises Euclidean distanceAsked in: F24
Short answer. Mahalanobis distance r² = (x−μ)ᵀΣ⁻¹(x−μ) measures distance in units of the data spread, accounting for different variances and correlations; with Σ = σ²I it reduces to Euclidean distance (scaled).
Euclidean: d_E²(x,μ) = (x − μ)ᵀ(x − μ) Mahalanobis: r²(x,μ) = (x − μ)ᵀ Σ⁻¹ (x − μ)
  • Generalisation: if Σ = σ²I, then Σ⁻¹ = I/σ² and r² = d_E²/σ²: Euclidean distance up to a constant factor. So Euclidean distance is the special case of uncorrelated features with equal variance.
  • Why it is better in general: it divides each direction by the spread of the data in that direction (rescaling) and rotates to the principal axes (decorrelating). Points at equal Mahalanobis distance from the mean lie on an ellipse that follows the covariance; a point far along the long axis can be "closer" than one across the short axis.
  • Use in classification: in Gaussian Case II (shared Σ) with equal priors, the Bayes classifier assigns x to the class with the smallest Mahalanobis distance to its mean; with Σ = σ²I it is the minimum-Euclidean-distance classifier.
  • Properties: scale-invariant (changing the units of a feature does not change r) and non-negative; for Gaussian data r² follows a χ² distribution with d degrees of freedom.

Example (past paper): Σ = [[2, 0.5], [0.5, 1]], μ₁ = (1, 1), μ₂ = (3, −1), x = (2.5, 0.5): r₁² = 2.00, r₂² = 3.14, so choose class 1; the Euclidean distances would be 1.58 and 1.58 (a tie), so the covariance matters.

Possible follow-up questions

When does Mahalanobis reduce to Euclidean?
When Σ is a multiple of the identity (features uncorrelated with equal variance).
What breaks if Σ is singular?
Σ⁻¹ does not exist (fewer samples than features, or collinear features); use the pseudo-inverse or add a small multiple of I (regularise).

An uncorrelated 2-D Gaussian factorises into two 1-D GaussiansAsked in: F24, S24, S23
Short answer. Uncorrelated means the covariance matrix is diagonal; then the joint density equals the product of the two marginal densities, so (for Gaussians) uncorrelated implies independent.

Let x = (x₁, x₂) with mean μ = (μ₁, μ₂) and covariance Σ. Uncorrelated: cov(x₁, x₂) = 0, so Σ = diag(σ₁², σ₂²).

|Σ| = σ₁²σ₂², Σ⁻¹ = diag(1/σ₁², 1/σ₂²) (x − μ)ᵀΣ⁻¹(x − μ) = (x₁ − μ₁)²/σ₁² + (x₂ − μ₂)²/σ₂² p(x) = 1/(2π|Σ|^{1/2}) · exp{ −½[(x₁ − μ₁)²/σ₁² + (x₂ − μ₂)²/σ₂²] } = [ 1/(√(2π)σ₁) e^{−(x₁−μ₁)²/(2σ₁²)} ] · [ 1/(√(2π)σ₂) e^{−(x₂−μ₂)²/(2σ₂²)} ] = N(x₁; μ₁, σ₁²) · N(x₂; μ₂, σ₂²)

Because p(x₁, x₂) = p(x₁)p(x₂), the variables are independent. Important: uncorrelated implies independent only for jointly Gaussian variables; in general independent ⇒ uncorrelated, not the reverse (x and x² for symmetric x are uncorrelated but dependent). Geometrically the density contours are axis-aligned ellipses (circles if σ₁ = σ₂), the basis of Case I of the Gaussian classifier.

Possible follow-up questions

Does independence imply uncorrelated?
Yes: independence gives E[x₁x₂] = E[x₁]E[x₂], so the covariance is 0.
Why does this matter for Naive Bayes?
NB assumes independence given the class; for Gaussian features with diagonal covariance this is exact.

Equal-covariance Gaussian classes: boundary and the effect of unequal priorsAsked in: S24, S23, F24
Short answer. With a shared covariance Σ the boundary is a hyperplane wᵀ(x − x₀) = 0 with w = Σ⁻¹(μ₁ − μ₂); unequal priors shift x₀ away from the more probable class.

Bayesian networks: what they are, proving a diagram is one, and computing probabilitiesAsked in: S25, S23i, F22
Short answer. A Bayesian network is a directed acyclic graph with a conditional probability table at each node; the joint distribution is the product of P(node | parents). To use one, factorise, then sum out the unknowns.

Definition and proof checklist

  1. Nodes are random variables.
  2. Edges are directed and the graph has no directed cycle (a DAG).
  3. Each node has a conditional probability table given its parents (roots have priors).

Then the joint factorises: P(x₁…xn) = Πi P(xi|parents(xi)) (chain rule plus "each node is independent of its non-descendant predecessors given its parents"). A diagram that satisfies the three points is a Bayesian network.

Computing a probability (past paper)

Heart disease network: P(E = yes) = 0.7, P(D = healthy) = 0.25, and P(HD = yes | E, D) = 0.25 (yes, healthy), 0.45 (yes, unhealthy), 0.55 (no, healthy), 0.75 (no, unhealthy). Marginalise the parents:

4. Linear discriminants and the perceptron

Geometric interpretation of a linear discriminant functionAsked in: F24, F23
Short answer. g(x) = wᵀx + w₀ defines a hyperplane g(x) = 0; w is its normal (pointing to the positive side), w₀ sets its offset from the origin, and the signed distance of a point x from the plane is g(x)/‖w‖.

Role of each part

  • Weight vector w: perpendicular to the decision hyperplane (for two points a, b on it, wᵀ(a − b) = 0). It points into the region where g > 0 (class ω₁). Changing w rotates/tilts the plane; the unit normal is w/‖w‖.
  • Bias w₀: shifts the plane parallel to itself. The signed distance from the origin to the plane is w₀/‖w‖ (geometric distance |w₀|/‖w‖). If w₀ = 0 the plane passes through the origin.
  • g(x): its sign classifies (positive: ω₁, negative: ω₂); its magnitude is proportional to the distance from the plane.

Distance formula

x = x⊥ + r w/‖w‖ with g(x⊥) = 0 g(x) = wᵀx⊥ + w₀ + r wᵀw/‖w‖ = r‖w‖ ⇒ r = g(x)/‖w‖

The same result by constrained minimisation (F23): minimise ‖x − x_a‖² subject to g(x) = 0; the Lagrangian gives x = x_a − λw/2 with λ = 2g(x_a)/‖w‖², so the shortest distance is |g(x_a)|/‖w‖.

Example: 2x₁ + x₂ = 3: w = (2,1), w₀ = −3, ‖w‖ = √5. The origin is on the negative side at distance 3/√5 = 1.34; the point (2,2) has g = 3 and distance +1.34.

Possible follow-up questions

What does the sign of w₀ tell you?
If w₀ < 0 the origin lies on the negative side of the plane; if w₀ > 0 on the positive side.
Why does multiplying w and w₀ by a constant not change the classifier?
The set g(x) = 0 and the signs of g are unchanged; only the distances g/‖w‖ are scale-free. This freedom is what the SVM uses to normalise the margin.

The perceptron: learning rule, convergence, and its limits (XOR, d-bit parity)Asked in: F22, F23, F24, S24
Short answer. Update w ← w + η t_n φ_n on each mistake. If the data are linearly separable it stops after at most R²/γ² updates; it can never solve problems like XOR or d-bit parity.

Learning rule

Output y = sign(wᵀφ(x)); targets t = ±1. A point is correct if t wᵀφ > 0. The perceptron criterion sums the negative scores of the mistakes, E_P(w) = −Σn∈M wᵀφntn; its gradient gives w ← w + ηφntn (single sample) or w ← w + ηΣMφntn (batch). The error of the corrected point drops by η‖φn‖², although other points may become wrong.

Convergence theorem (proof sketch)

After flipping class −1 samples let ŵ (unit) separate the data with margin γ = min ŵᵀφn and R = max‖φn‖. Each update raises ŵᵀw by at least γ, so ‖wk‖ ≥ kγ; it raises ‖w‖² by at most R² (a mistake has wkᵀφ ≤ 0), so ‖wk‖² ≤ kR². Hence k²γ² ≤ kR² and k ≤ R²/γ²: finitely many updates.

Limits

  • XOR: (0,0),(1,1) in one class and (0,1),(1,0) in the other: no line separates them.
  • d-bit parity (d > 1): class ω₁ if the number of 1s is odd. Fixing all but two bits gives XOR as a sub-problem, so no hyperplane works. Algebra for XOR: g = w₁x₁ + w₂x₂ + w₀ needs w₀ < 0, w₁ + w₀ > 0, w₂ + w₀ > 0, w₁ + w₂ + w₀ < 0; adding the middle two gives w₁ + w₂ + 2w₀ > 0, contradicting the last.
  • Non-separable data: it never converges (weights keep changing).
  • The solution is not unique and has no margin; it depends on initial weights and the order of the data.
  • Fixes: better features φ (add x₁x₂), multilayer networks, or kernels.

Numeric (F24): points (1,2)+, (4,3)+, (3,−1)−, (−2,−2)−, w = 0, η = 1, batch: iteration 1 gives w = (4,8); iteration 2 (only (3,−1) wrong) gives (1,9); then no errors.

Possible follow-up questions

Why does a perceptron started from w = 0 not depend on η?
All updates are multiples of η, so w is just scaled by η and the signs of the scores, hence the mistakes, are unchanged.
Batch or single-sample updates?
Batch: small data, stable tracking. Single-sample (stochastic): large or streaming data.

5. Support vector machines

The SVM objective and the margin M = 2/‖w‖Asked in: S23i, F24
Short answer. The primary objective of an SVM is to find the separating hyperplane with maximum margin. With the closest points normalised to y(wᵀx + b) = 1 the margin is 2/‖w‖, so maximising it means minimising ‖w‖.

Many hyperplanes separate separable data. The SVM selects the one that maximises the distance to the closest training points of both classes (the margin); those closest points are the support vectors.

Derivation of M = 2/‖w‖

  1. (w, b) and (cw, cb) define the same plane, so we may normalise (assumption) so that the closest points satisfy |wᵀx + b| = 1: yi(wᵀxi + b) ≥ 1 for all i, with equality for support vectors.
  2. Take x₊ on wᵀx + b = +1 and x₋ on wᵀx + b = −1.
  3. The margin is the projection of (x₊ − x₋) on the unit normal w/‖w‖: M = (x₊ − x₋)ᵀw/‖w‖ = [(wᵀx₊ + b) − (wᵀx₋ + b)]/‖w‖ = (1 − (−1))/‖w‖ = 2/‖w‖.

Optimisation problem: maximise 2/‖w‖ subject to yi(wᵀxi + b) ≥ 1, which is equivalent to minimising ½‖w‖² under the same constraints. Distance from the boundary to a support vector: 1/‖w‖.

Possible follow-up questions

If ‖w‖ = 4, what is the margin?
2/4 = 0.5; each support vector is 0.25 from the boundary.

Why minimise ½‖w‖² instead of maximising 2/‖w‖ directlyAsked in: F24
Short answer. They are equivalent (monotonic transformations), but ½‖w‖² is a smooth convex quadratic with a unique minimum, has no square root, and its gradient is simply w, so standard quadratic programming applies and the dual can be derived.
  • Equivalence: maximise 2/‖w‖ ⇔ minimise ‖w‖ ⇔ minimise ‖w‖² (squaring is monotonic for ‖w‖ ≥ 0) ⇔ minimise ½‖w‖² (a constant factor).
  • Mathematical rationale: ‖w‖² = wᵀw is differentiable everywhere and strictly convex, so with linear constraints the problem is a convex quadratic programme with a unique global minimum and no local minima. 2/‖w‖ is not defined at w = 0 and its gradient has ‖w‖ in a denominator.
  • The ½: cancels the 2 on differentiation: ∂(½wᵀw)/∂w = w, which keeps the Lagrangian conditions clean (w = Σλiyixi).
  • Computational rationale: QP solvers (SMO, interior point) are reliable and efficient for quadratic objectives with linear constraints; the dual only needs dot products, enabling kernels.
  • Normalisation assumption: the scale freedom of (w, b) is fixed by requiring yi(wᵀxi + b) ≥ 1 with equality at the support vectors; without it the objective could be made arbitrarily large or small by scaling w.

Possible follow-up questions

Is the SVM solution unique?
Yes for separable data: the strictly convex objective gives a unique (w, b).

Lagrange multipliers in the SVM and why solve the dual rather than the primalAsked in: S25, F24
Short answer. Lagrange multipliers turn the constrained problem into an unconstrained one by penalising violated constraints; the resulting dual depends on the data only through dot products x_i·x_j, so it allows kernels, has one variable per sample (good when features are many), and exposes the support vectors.

Role of the Lagrange multiplier

For the constraint gi(w, b) = yi(wᵀxi + b) − 1 ≥ 0, attach a multiplier λi ≥ 0:

L(w, b, λ) = ½‖w‖² − Σ λ_i [ y_i(wᵀx_i + b) − 1 ] min_{w,b} max_{λ≥0} L = the primal problem: if a constraint is violated (g < 0), −λg → +∞ as λ → ∞, so that (w, b) is rejected; if it is satisfied, the best λ makes the penalty 0.

Geometrically λ is the weight with which constraint i pulls on the optimum (at a constrained optimum ∇f = λ∇g).

From primal to dual

∂L/∂w = 0 ⇒ w = Σ λ_i y_i x_i ∂L/∂b = 0 ⇒ Σ λ_i y_i = 0 dual: max Σλ_i − ½ΣΣ λ_iλ_j y_i y_j (x_i·x_j) s.t. λ_i ≥ 0, Σλ_i y_i = 0

Swapping min and max is allowed by strong duality (convex objective, linear constraints).

Why the dual is beneficial (especially when the number of features is very large)

  • Kernel trick: the objective and constraints depend on the data only through inner products xi·xj, so replace them with K(xi, xj) to work implicitly in a huge or infinite-dimensional feature space. The primal needs φ(x) explicitly.
  • Size: the dual has N variables (one per sample) regardless of the number of features; the primal has one variable per (mapped) feature, which can be astronomically large or infinite.
  • Simple constraints (λ ≥ 0, Σλy = 0) and a sparse solution: most λi = 0, only support vectors matter.
  • Same optimum as the primal (strong duality), plus a direct view of which samples define the boundary.

Possible follow-up questions

Does the dual lose information about w and b?
No: w = Σλiyixi, and b = ys − w·xs from any support vector.
When might the primal be preferred?
For linear SVMs with few features and very many samples, solvers working on the primal (e.g. LIBLINEAR) can be faster.

Why λ_i > 0 for support vectors; the decision boundary in terms of the multipliers and the KKT conditionsAsked in: S24, F23
Short answer. Complementary slackness λ_i[y_i(w·x_i + b) − 1] = 0 means a point with λ_i > 0 must lie exactly on a margin line (a support vector); the boundary is f(x) = Σ λ_i y_i (x_i·x) + b, summed over support vectors.

KKT conditions

1. stationarity: w = Σ λ_i y_i x_i, Σ λ_i y_i = 0 2. primal feasibility: y_i(w·x_i + b) − 1 ≥ 0 3. dual feasibility: λ_i ≥ 0 4. complementary slackness: λ_i [ y_i(w·x_i + b) − 1 ] = 0

Why support vectors have λi > 0: by (4) either λi = 0 or the bracket is 0. Points strictly outside the margin have yi(w·xi + b) > 1, so the bracket is non-zero and λi must be 0: they do not influence w. A point with λi > 0 must satisfy yi(w·xi + b) = 1, i.e. it lies on a margin line: that is the definition of a support vector.

Decision boundary in terms of the multipliers

w = Σ_{i∈SV} λ_i y_i x_i b = y_s − Σ_{i∈SV} λ_i y_i (x_i·x_s) (any support vector s) f(x) = sign( Σ_{i∈SV} λ_i y_i (x_i · x) + b ), boundary: Σ λ_i y_i (x_i·x) + b = 0

It satisfies KKT by construction: (1) gives w, (3) holds since λ ≥ 0, and complementary slackness holds because only margin points have λ > 0. Σλiyi = 0 says positive and negative support vectors carry equal total weight.

Past-paper example: v₁ = (−1,1), v₂ = (2,0), v₃ = (1,−1), v₄ = (0,2) with α = (−0.5, 0.5, −0.5, 0.5) (labels included) and b = −1 give w = (1,1) and w·v + b = −1, +1, −1, +1 (all on the margins); h(1,1) = sgn(2 − 1) = +1.

The kernel trick, the polynomial kernel, and why w is not computedAsked in: F24, S24, F23
Short answer. A kernel K(x,z) = φ(x)·φ(z) gives the dot product in a high-dimensional feature space without constructing φ. For (1 + xᵀz)² the implicit map has 6 features in 2-D. In a kernel SVM, w lives in feature space, so we classify with Σλ_i y_i K(x_i, x) + b.

What a kernel function is

For a feature map φ, K(x,z) = φ(x)ᵀφ(z). Any symmetric positive semi-definite K (Mercer's condition) corresponds to some feature map. Replace x·z by K(x,z) in the dual and the SVM becomes non-linear.

Polynomial kernel K(x,z) = (1 + xᵀz)², two dimensions

(1 + x₁z₁ + x₂z₂)² = 1 + 2x₁z₁ + 2x₂z₂ + x₁²z₁² + 2x₁x₂z₁z₂ + x₂²z₂² = φ(x)·φ(z) with φ(x) = (1, √2x₁, √2x₂, x₁², √2x₁x₂, x₂²)

So the kernel returns the dot product in a 6-D space (all terms up to degree 2) from a 2-D computation, with no explicit φ. For (x·z)² alone: φ(x) = (x₁², √2x₁x₂, x₂²).

Common kernels: linear x·z; polynomial (γx·z + c)d; RBF exp(−γ‖x − z‖²), whose feature space is infinite-dimensional (expand e2γx·z as a series). Large γ: narrow bumps, a tight boundary (overfitting); small γ: smooth boundary (underfitting).

Why w is not computed explicitly

  • In feature space w = Σλiyiφ(xi), which can have thousands or infinitely many components (RBF); we cannot store it.
  • We never need it: f(x) = sign(Σi∈SV λiyiK(xi, x) + b), with b from a support vector: b = ys − ΣλiyiK(xi, xs). The cost of a prediction is proportional to the number of support vectors.

Possible follow-up questions

How is the kernel trick different from simply adding features?
Adding features builds φ(x) explicitly (costly or impossible); the kernel trick computes only the needed inner products.
Which kernel for which data?
Linear: already separable or very many features (text). Polynomial: known feature interactions. RBF: no prior knowledge, non-separable data, moderate number of features.

  • SVM: yes with a non-linear kernel (RBF, or a polynomial of degree 2, where x₁² + x₂² is a feature). In the mapped space a hyperplane separates the classes, which appears as a closed circular boundary in the original plane. A linear-kernel SVM fails like the perceptron.

Backpropagation: how the training error is propagated back layer by layerAsked in: F23, S23, S23i
Short answer. Backpropagation applies the chain rule to compute the gradient of the error with respect to every weight: first the output-layer sensitivities δ_k = (t_k − z_k)f′(net_k), then hidden sensitivities δ_j = f′(net_j)Σ_k w_kj δ_k, then weights are updated by Δw = η δ × input.

Network and error

Three layers: inputs xi, hidden units yj = f(netj), netj = Σiwjixi, outputs zk = f(netk), netk = Σjwkjyj. Error J = ½Σk(tk − zk)². Gradient descent: Δw = −η ∂J/∂w.

Derivation

output layer: ∂J/∂w_kj = (∂J/∂net_k)(∂net_k/∂w_kj) = −δ_k y_j, δ_k = (t_k − z_k) f′(net_k) Δw_kj = η δ_k y_j hidden layer: ∂J/∂y_j = −Σ_k (t_k − z_k) f′(net_k) w_kj = −Σ_k δ_k w_kj δ_j = f′(net_j) Σ_k w_kj δ_k Δw_ji = η δ_j x_i sigmoid: f′ = f(1 − f)

Algorithm

  1. Initialise weights randomly (small).
  2. Forward pass: compute net, y, z for a sample.
  3. Compute the output error and δk.
  4. Backward pass: compute δj from the δk and the weights.
  5. Update all weights; repeat over samples/epochs until the error stops falling (use a validation set to stop early).

The "error propagates back" because the hidden-unit sensitivity is the weighted sum of the output sensitivities, using the same weights as the forward pass. With non-linear hidden units a multilayer network can solve XOR and other non-linearly-separable problems. Practical issues: local minima, learning rate, vanishing gradients with saturating sigmoids, overfitting (regularise or stop early).

  • Weak classifier: only slightly better than random guessing (error ε < ½), e.g. a decision stump (one threshold on one feature). High bias.
  • Strong classifier: achieves arbitrarily small error; boosting builds one by combining weak ones.

  1. Start with weights wi = 1/N.
  2. For t = 1…T: train weak ht on the weighted data; compute the weighted error εt = Σ wi[ht(xi) ≠ yi].
  3. Classifier weight αt = ½ ln((1 − εt)/εt) (larger for more accurate classifiers; α > 0 when ε < ½).
  4. Update wi ← wi exp(−αt yi ht(xi)): mistakes are multiplied by eα > 1, correct points by e−α < 1; renormalise (divide by Zt).

Why this weight minimises the combined error: the training error of H is bounded by Π Zt, with Z(α) = (1 − ε)e−α + εeα; setting dZ/dα = 0 gives α = ½ln((1−ε)/ε) and Zmin = 2√(ε(1−ε)) < 1. Each weak learner better than chance therefore shrinks the bound exponentially.

Numeric round: 5 samples, weights 0.2 each, h₁ misclassifies one (ε = 0.2): α = ½ln4 = 0.693. Correct: 0.2·0.5 = 0.1 each; wrong: 0.2·2 = 0.4; Z = 0.8; normalised weights 0.125 (four correct) and 0.5 (the mistake): half the weight now sits on the one hard example.

Boosting and the bias-variance trade-off

A single weak learner underfits (high bias). Each round concentrates on the examples the current ensemble gets wrong, so the ensemble can represent a complex boundary: bias falls round by round, and averaging many learners keeps variance moderate. Bagging instead leaves bias unchanged and cuts variance.

Each sample differs, so the models make partly independent errors; averaging them cancels some of the variance.

7. PCA and LDA

Role of eigenvalues and eigenvectors in PCA; how the covariance matrix finds the principal componentsAsked in: F24, S23, F23, S23i, F22
Short answer. The principal components are the eigenvectors of the covariance matrix S; each eigenvalue is the variance of the data along its eigenvector. Sorting by eigenvalue ranks the directions by information, and the top p eigenvectors give the reduced representation.

Why the covariance matrix

S (d × d, S = XXᵀ/(n−1) for centred data) is symmetric; its diagonal holds the variances of each feature and its off-diagonal entries the covariances (positive: increase together; negative: opposite; zero: uncorrelated). It describes the shape of the data cloud: the direction of the longest axis, the spread along each axis. Redundant (correlated) features show up as large off-diagonal entries.

Eigenvector and eigenvalue

A vector u is an eigenvector of S if Su = λu: S only stretches it by the factor λ (the eigenvalue), without changing its direction. For a symmetric matrix the eigenvectors with different eigenvalues are orthogonal.

Link to PCA

The variance of the projection onto a unit vector u is uᵀSu. Maximising it subject to uᵀu = 1 (Lagrange multiplier) gives Su = λu and variance = λ. So:

  • Eigenvectors = the principal directions (new axes); PC1 = the eigenvector with the largest eigenvalue; they are orthogonal, so the components carry no redundant information.
  • Eigenvalues = the variance (information) along each component; λi/Σλ is the fraction of variance explained; Σλi = trace(S) = total variance.
  • Dimension reduction: keep the p eigenvectors with the largest eigenvalues, Wp = [u₁…up], and project z = Wpᵀ(x − mean). Choose p so that, e.g., 90–95% of the variance is kept (scree plot).

Steps and a worked example (price, weight): (4,7), (5,6), (3,1)

  1. Mean (4, 4.667); centre the data.
  2. Covariance S = [[1, 2.5], [2.5, 10.333]] (divide by n − 1 = 2).
  3. Characteristic equation λ² − 11.333λ + 4.083 = 0 gives λ₁ = 10.961, λ₂ = 0.373.
  4. Eigenvector for λ₁: u₁ = (0.243, 0.970) (normalised); u₂ = (−0.970, 0.243).
  5. Feature vector W = u₁ (96.7% of the variance); projections z = 2.26, 1.54, −3.80.

The exact original data can be recovered only if all eigenvectors are kept; otherwise the mean squared reconstruction error equals the sum of the dropped eigenvalues.

Possible follow-up questions

Why must the data be centred?
The covariance and the variance formula uᵀSu refer to deviations from the mean; without centring, PC1 can simply point at the mean.
Why must u have unit length?
Otherwise the variance can be made arbitrarily large by scaling u; only the direction matters.
What is the maximum number of non-zero eigenvalues?
min(d, n − 1).
What if the features have different units?
Standardise them (use the correlation matrix); otherwise the feature with the largest numbers dominates PC1.

Short answer. For documents represented as sparse term-frequency vectors, use cosine similarity: it depends only on the angle (relative word usage), ignores document length, and does not count words that are absent from both.

Doc 1 = (5, 4, 2, 0, 0, 1, 0) and Doc 2 = (0, 3, 4, 0, 1, 0, 0) for the terms coach, win, penalty, sponsor, fixing, season, soccer.

Why cosine

  • The vectors are sparse (most counts are 0) and counts grow with document length. Euclidean distance would call a long and a short document on the same topic "far apart"; cosine compares the direction, i.e. the proportions of the words.

9. Reinforcement learning

Markov decision process, reinforcement learning, and the additive discounted rewardAsked in: S23i, F22, S23
Short answer. An MDP (S, A, T, R, γ) models sequential decisions with the Markov property; reinforcement learning is learning an optimal policy for it by interacting with the environment. The additive discounted reward G_t = Σγ^k R_{t+k+1} keeps the sum finite and prefers sooner rewards.

Reinforcement learning

An agent takes actions in an environment and receives a reward and the next state; it must learn a policy π (a map from states to actions) that maximises the expected cumulative reward. Feedback is evaluative (a reward, not the correct answer) and delayed.

Markov decision process

  • S: states; A: actions; T(s,a,s′) = P(s′|s,a): transition probabilities; R(s,a,s′): reward; γ ∈ [0,1]: discount factor.
  • Markov property: the next state depends only on the current state and action, P(st+1 | st, at, history) = P(st+1 | st, at).

Additive discounted reward and its justification

G_t = R_{t+1} + γR_{t+2} + γ²R_{t+3} + … = Σ_{k≥0} γ^k R_{t+k+1}, 0 ≤ γ < 1
  • Finite: if |R| ≤ R_max the sum is at most R_max/(1 − γ) (e.g. reward 1 per step with γ = 0.9 sums to 10), so infinite tasks are well defined.
  • Uncertainty about the future: distant rewards are less certain, so they are worth less; a reward k steps away counts γk.
  • Prefers sooner rewards (earlier is better, as with money), and rewards the shortest path to a goal.
  • Recursion: Gt = Rt+1 + γGt+1 gives the Bellman equations used to learn values.
  • γ = 0: only the immediate reward (myopic); γ → 1: far-sighted.

Possible follow-up questions

Why use the expected return (value function) rather than the raw return?
The future is stochastic (random transitions, possibly random policy); the agent cannot compute Gt in advance, so it uses the expectation Vπ(s) = E[Gt|s].
What is the optimal policy?
The policy with the largest value in every state; π*(s) = argmaxa Q*(s,a).

k-fold cross-validation: definition, steps and purposeAsked in: S25, F23
Short answer. k-fold cross-validation splits the data into k folds, trains on k − 1 folds and tests on the remaining one, rotates through all k folds, and averages the results, giving a performance estimate that uses every instance for testing exactly once.

Definition and steps

  1. Shuffle (or stratify) and partition the data into k equal folds s₁…sk.
  2. For i = 1…k: train the model on all folds except si; test it on si and record the score.
  3. Average the k scores (accuracy = total correct / total instances).

Example: 5 folds of 20 instances with 11, 17, 16, 13, 16 correct: accuracy = 73/100 = 73%.

Purpose

  • Estimate generalisation (unbiased test-style estimate) when data are limited; every example is used for both training and testing, but never in the same round.
  • Model selection: compare models or choose hyperparameters (k in k-NN, C and γ in an SVM, number of principal components) without touching the final test set; use internal cross-validation inside each training set.
  • Detect overfitting: a large gap between training score and cross-validated score.

ROC curve and AUC: definition, construction from scores, interpretationAsked in: F23, S23, S23i, F22
Short answer. The ROC curve plots the true positive rate against the false positive rate as the classification threshold varies; AUC is the area under it, equal to the probability that a random positive scores above a random negative.

TPR = TP/P (sensitivity, recall), FPR = FP/N = 1 − specificity. Lowering the threshold classifies more instances as positive, raising both TPR and FPR.

How to draw it from scored instances

  1. Count P positives and N negatives. For each threshold t, predict positive if score ≥ t.
  2. Count TP and FP, compute TPR = TP/P and FPR = FP/N.
  3. Plot (FPR, TPR) for each threshold, add (0,0) and (1,1), join the points, and draw the diagonal.

Why accuracy can mislead; precision, recall, specificity and F1Extra question (useful, not asked directly)
Short answer. Accuracy ignores class imbalance and unequal costs; use the confusion matrix and precision, recall, specificity and F1 to see what kind of errors are made.
accuracy = (TP + TN)/(TP + FP + FN + TN) recall (TPR, sensitivity) = TP/(TP + FN) precision = TP/(TP + FP) specificity = TN/(TN + FP) = 1 − FPR F1 = 2PR/(P + R) = 2TP/(2TP + FP + FN) (harmonic mean)

Example: 1 000 instances, 30 positive. A model that always says "negative" has accuracy 97% but recall 0. A second model with TP = 20, FN = 10, FP = 40, TN = 930 has accuracy 95%, recall 0.667, precision 0.333, F1 0.444. Accuracy ranks them the wrong way for finding positives.

  • Precision answers "of the alarms, how many are real?"; recall answers "of the real cases, how many did we catch?".
  • Precision depends on prevalence π: precision = TPR·π/(TPR·π + FPR(1 − π)); with TPR 0.9 and FPR 0.01 it is 0.989 at π = 0.5 but 0.083 at π = 0.001.
  • Choose the metric by the costs: screening for a serious disease wants high recall; a spam filter that must never lose real mail wants high precision.

Possible follow-up questions

Why is F1 a harmonic and not an arithmetic mean?
The harmonic mean is dominated by the smaller value, so a model cannot get a high F1 by excelling at only one of precision and recall.

Bellman's optimality principle and edit distanceAsked in: F23, S23, S23i, F22
Short answer. Bellman's principle: an optimal solution is made of optimal solutions to its sub-problems, so a hard problem can be solved by dynamic programming. For edit distance, D(i,j) = min{D(i−1,j) + 1, D(i,j−1) + 1, D(i−1,j−1) + [s_i ≠ t_j]}.

Bellman's optimality principle

"An optimal policy has the property that, whatever the initial state and decision, the remaining decisions must be an optimal policy for the state that results." So the optimal value of a problem can be written in terms of the optimal values of smaller problems; solving them once and storing the results (dynamic programming) avoids exponential recomputation. The same idea gives the Bellman equations of reinforcement learning, V*(s) = maxa Σ T[R + γV*(s′)], and shortest-path and Viterbi algorithms.

Edit distance (minimum number of insertions, deletions, substitutions)

The optimal alignment of s[1..i] with t[1..j] ends with one of three operations, and the part before it must itself be optimal:

D(i,0) = i, D(0,j) = j D(i,j) = min{ D(i−1,j) + 1 (delete s_i), D(i,j−1) + 1 (insert t_j), D(i−1,j−1) + (0 if s_i = t_j else 1) (match / substitute) }

The method of Lagrange multipliers (extreme values under constraints)Asked in: F23, S23i, S23 (SVM)
Short answer. To optimise f(x) subject to g(x) = 0, solve ∇f = λ∇g (equivalently ∂L/∂x = 0 for L = f − λg) together with the constraint; at the optimum the level curve of f touches the constraint curve and the gradients are parallel.

Method

  1. Form L(x, λ) = f(x) + Σλigi(x) (sign convention is arbitrary).
  2. Set all partial derivatives to zero, including ∂L/∂λ (which returns the constraints).
  3. Solve for x and λ; evaluate f at the candidates; compare.

Exam example: f(x,y) = x² + y² with g₁ = x + 1 = 0, g₂ = y + 1 = 0

L = x² + y² + λ₁(x + 1) + λ₂(y + 1) ∂L/∂x = 2x + λ₁ = 0, ∂L/∂y = 2y + λ₂ = 0, x = −1, y = −1 ⇒ λ₁ = λ₂ = 2 f(−1,−1) = 2 the constraints leave one feasible point, so min = max = 2

Slide example: maximise x − y subject to x² + y² = 1

∂L/∂x = 1 − 2λx = 0, ∂L/∂y = −1 − 2λy = 0 ⇒ x = 1/(2λ), y = −1/(2λ) x² + y² = 1/(2λ²) = 1 ⇒ λ = ±1/√2 λ = 1/√2: (1/√2, −1/√2), f = √2 (maximum); λ = −1/√2: f = −√2 (minimum)

Why it works: moving along the constraint changes f by ∇f·(tangent); at an optimum that must be zero for every tangent direction, so ∇f is perpendicular to the constraint curve, i.e. parallel to ∇g. Inequality constraints g ≥ 0 need λ ≥ 0 and complementary slackness λg = 0 (KKT): either the constraint is active (g = 0) or it is inactive (λ = 0). In the SVM and PCA the multiplier appears as the eigenvalue/support-vector weight.

Possible follow-up questions

What does λ mean?
The sensitivity of the optimal value to the constraint (the "shadow price"): changing the constraint level c by a small amount changes the optimum by about λ·Δc.
Where is it used in this course?
SVM (margin maximisation), PCA (unit-length constraint gives the eigenproblem), LDA (wᵀS_Ww = 1).

Quick-fire viva questions and one-line answersExtra question (useful, not asked directly)
Short answer. Short answers for the questions an examiner might ask in a viva or as a 2-mark question.

What is a feature vector? The ordered list of measurements x = (x₁…xd)ᵀ that represents a pattern; treated as a random vector.

Classification versus clustering? Classification assigns objects to known classes using labelled training data; clustering discovers groups in unlabelled data.

What is a decision boundary? The set of points where the discriminant functions of two classes are equal, g_i(x) = g_j(x).

Prior, likelihood, evidence, posterior? Prior P(ω): belief before seeing x. Likelihood p(x|ω). Evidence p(x) = Σp(x|ω)P(ω). Posterior P(ω|x) = likelihood × prior / evidence.

What is the Bayes error? The smallest achievable error probability, from the overlap of the class densities; no classifier can beat it.

Parametric versus non-parametric? Parametric: assume a form with a few parameters (e.g. Gaussian) and estimate them; non-parametric: no fixed form (k-NN, histograms).

Why use the log-likelihood? The log is monotonic, so the maximiser is unchanged, and products become sums that are easy to differentiate and numerically stable.

Why divide by n − 1 for the sample variance? Deviations are taken from the sample mean, which makes them too small; n − 1 gives an unbiased estimate (ML divides by n and underestimates by (n−1)/n).

Training, validation and test sets? Train to fit the parameters; validation to tune hyperparameters; test once at the end to estimate generalisation.

What is a support vector? A training point on the margin (λ > 0); only support vectors determine the SVM boundary.

What do C and γ do in an RBF SVM? C: penalty for margin violations (large = narrow margin, overfit risk). γ: inverse width of the RBF (large = tight boundary, overfit risk).

When is the perceptron guaranteed to converge? Only when the classes are linearly separable; then in at most R²/γ² updates.

Why are principal components orthogonal? They are eigenvectors of the symmetric covariance matrix, and eigenvectors of a symmetric matrix with different eigenvalues are orthogonal.

How many dimensions can LDA produce for C classes? At most C − 1.

Does k-means always converge? To the global optimum? It always converges (SSE never increases, finite partitions) but only to a local optimum that depends on the seeds.

Single versus complete link? Single: distance between the closest pair (chains, sensitive to noise). Complete: farthest pair (compact clusters, breaks large ones).

What is ε-greedy? Choose a random action with probability ε, else the best-known action: balances exploration and exploitation.

V versus Q? V(s): value of a state under a policy; Q(s,a): value of taking action a in s and then following the policy; V(s) = Σπ(a|s)Q(s,a).

What does AUC = 0.5 mean? The classifier ranks positives and negatives no better than chance (the diagonal ROC curve).

Precision versus recall? Precision = TP/(TP+FP): purity of the alarms. Recall = TP/(TP+FN): coverage of the real positives.

Why stratified cross-validation? It keeps class proportions in every fold, important for small or imbalanced data.

Name a generative and a discriminative classifier. Generative: Naive Bayes, GDA. Discriminative: logistic regression, SVM.

Why do we need a non-linear activation in a neural network? Otherwise a multilayer network collapses to one linear map and cannot solve XOR.

What does the discount factor γ do? It weights future rewards by γk: γ = 0 is myopic, γ → 1 far-sighted, and γ < 1 keeps infinite sums finite.
