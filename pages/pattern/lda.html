Linear discriminant analysis (Fisher LDA): deep dive

Dimensionality reduction that keeps what separates the classes: the Fisher criterion, its derivation, the eigenvalue solution, the slide's full worked example, an interactive projection explorer, and exactly when LDA fails.

Read: Bishop, PRML: §4.1.4 "Fisher's linear discriminant", §4.1.5 "Relation to least squares", §4.1.6 "Fisher's discriminant for multiple classes". Duda, Hart & Stork, Ch. 3 §3.8 "Component Analysis and Discriminants": §3.8.2 "Fisher Linear Discriminant", §3.8.3 "Multiple Discriminant Analysis". Original: R. A. Fisher (1936), "The use of multiple measurements in taxonomic problems". Slide source: Elhabian & Farag (CVIP Lab), "A Tutorial on Data Reduction: Linear Discriminant Analysis".

1. Objective: reduce dimension, but keep the class information

Recall PCA: centre the data, take the covariance matrix, keep the eigenvectors with the largest eigenvalues. PCA keeps maximum variance and never looks at class labels, so the discrimination power is not considered (it re-expresses the data to remove redundancy and noise).

LDA: the goal is still dimensionality reduction, but we want to preserve as much of the class discriminatory information as possible. Setup: C classes (sea bass, tuna, salmon…), class ωi has Ni samples that are m-dimensional. We seek a transformation Y = WᵀX that projects the samples onto a hyperplane of dimension C − 1. For two classes that is a line: each sample becomes a single number y = wᵀx.

The question is which line. The same two classes can be badly mixed on one line and cleanly split on another (slides: "this line succeeded in separating the two classes"; another line leaves them overlapped). We need a number J(w) that measures how well a direction separates the classes, then maximise it.

2. The Fisher criterion

Step 1: projected class means

Class means in x-space: μi = (1/Ni) Σx∈ωi x. After projecting y = wᵀx the mean of class i is μ̃i = wᵀμi. A first idea is to maximise the distance between projected means, |μ̃₁ − μ̃₂| = |wᵀ(μ₁ − μ₂)|.

Why this is not enough: it ignores the spread inside each class. The axis with the larger distance between means can still have heavily overlapping classes, while another axis with a smaller distance but tight classes separates them better. (It is also unbounded: scaling w scales the distance. Fisher's J is scale-invariant.)

Step 2: scatter within the projected classes

Fisher's idea: maximise the difference between the means normalised by the within-class variability, the scatter, which is the variance-like quantity

s̃_i² = Σ_{y ∈ class i} (y − μ̃_i)² s̃₁² + s̃₂² = within-class scatter of the projected samples J(w) = (μ̃₁ − μ̃₂)² / (s̃₁² + s̃₂²)

We want projections where samples of the same class are very close and the projected means are far apart: J large.

Step 3: write J as an explicit function of w

Define the scatter (covariance) matrices in x-space:

S_i = Σ_{x ∈ ω_i} (x − μ_i)(x − μ_i)ᵀ S_W = S₁ + S₂ (within-class scatter matrix) S_B = (μ₁ − μ₂)(μ₁ − μ₂)ᵀ (between-class scatter matrix)

Then

s̃_i² = Σ (wᵀx − wᵀμ_i)² = Σ wᵀ(x − μ_i)(x − μ_i)ᵀw = wᵀ S_i w s̃₁² + s̃₂² = wᵀ(S₁ + S₂)w = wᵀ S_W w (μ̃₁ − μ̃₂)² = (wᵀμ₁ − wᵀμ₂)² = wᵀ(μ₁ − μ₂)(μ₁ − μ₂)ᵀw = wᵀ S_B w J(w) = wᵀ S_B w / wᵀ S_W w

S_B is an outer product of one vector, so rank(S_B) ≤ 1. J is a "Rayleigh quotient": scaling w by any constant leaves it unchanged, so only the direction of w matters.

3. Maximising J: the eigenvalue problem

Differentiate the quotient and set it to zero:

d/dw [ wᵀS_Bw / wᵀS_Ww ] = 0 ⇒ (wᵀS_Ww)·2S_Bw − (wᵀS_Bw)·2S_Ww = 0 divide by 2 wᵀS_Ww: S_Bw − J(w)·S_Ww = 0 multiply by S_W⁻¹: S_W⁻¹S_B w = J w = λ w

So w is an eigenvector of S_W⁻¹S_B and the eigenvalue is exactly the achieved J: the optimal projection is the eigenvector with the largest eigenvalue (maximum λ = J(w)).

Equivalent constrained form (handwritten slides): maximise wᵀS_Bw subject to wᵀS_Ww = 1 (the constraint removes the scale freedom). Lagrangian L = wᵀS_Bw − λ(wᵀS_Ww − 1); ∂L/∂w = 2S_Bw − 2λS_Ww = 0 gives S_Bw = λS_Ww, then multiplying by S_W⁻¹ gives the same eigenproblem. Think of it as: Goal 1, maximise the distance of the projected means (wᵀS_Bw); Goal 2, minimise the within-class variance (wᵀS_Ww).

Shortcut for two classes

Since S_B = (μ₁ − μ₂)(μ₁ − μ₂)ᵀ, the vector S_Bw = (μ₁ − μ₂)·c, where c = (μ₁ − μ₂)ᵀw is just a number. So S_Bw = λS_Ww means S_Ww = (c/λ)(μ₁ − μ₂), hence

w* ∝ S_W⁻¹ (μ₁ − μ₂) (no eigen-decomposition needed)

Rank(S_B) = 1 also means S_W⁻¹S_B has only one nonzero eigenvalue; the other is 0 (the slide shows 8.9×10⁻¹⁶, numerical zero). Its eigenvector is the worst projection direction (J = 0).

Name note (slides): this is called "Fisher's linear discriminant", although it is not a discriminant by itself but a specific choice of direction onto which to project the data. To classify you still pick a threshold on y.

4. Worked example (the slide's dataset)

ω₁: (4,2), (2,4), (2,3), (3,6), (4,4). ω₂: (9,10), (6,8), (9,5), (8,7), (10,8). The slides use covariance matrices (division by N − 1 = 4).

  1. Means: μ₁ = (3, 3.8), μ₂ = (8.4, 7.6).
  2. Class covariances: S₁ = [[1, −0.25], [−0.25, 2.2]], S₂ = [[2.3, −0.05], [−0.05, 3.3]].
  3. Within-class: S_W = S₁ + S₂ = [[3.3, −0.3], [−0.3, 5.5]].
  4. Between-class: μ₁ − μ₂ = (−5.4, −3.8), S_B = [[29.16, 20.52], [20.52, 14.44]].
  5. Inverse: det S_W = 3.3·5.5 − 0.09 = 18.06; S_W⁻¹ = [[0.3045, 0.0166], [0.0166, 0.1827]].
  6. Matrix: S_W⁻¹S_B = [[9.2213, 6.489], [4.2339, 2.9794]].
  7. Eigenvalues: det(S_W⁻¹S_B − λI) = (9.2213 − λ)(2.9794 − λ) − 6.489·4.2339 = λ² − 12.2007λ = 0 ⇒ λ₁ = 0, λ₂ = 12.2007. (The determinant is 0 because rank is 1; the trace 9.2213 + 2.9794 = 12.2007 is the nonzero eigenvalue.)
  8. Eigenvectors: for λ₁ = 0: w₁ = (−0.5755, 0.8178) (bad: leads to poor separability). For λ₂ = 12.2007: w* = (0.9088, 0.4173) (good separability).

Check with the shortcut: S_W⁻¹(μ₁ − μ₂) = (−1.707, −0.784); its length is 1.878, so the unit vector is (−0.909, −0.417) = −w*, the same direction (sign is arbitrary).

The projection

y = 0.9088 x₁ + 0.4173 x₂ ω₁ → 4.47, 3.49, 3.07, 5.23, 5.30 projected mean 4.31 ω₂ → 12.35, 8.79, 10.27, 10.19, 12.43 projected mean 10.80

The classes are cleanly separated (largest ω₁ value 5.30 < smallest ω₂ value 8.79). Any threshold in between works; for equal priors take the midpoint of the projected means: (4.31 + 10.80)/2 = 7.56. Classify a new point by comparing y with 7.56: (5,5) → y = 6.63 → ω₁; (7,7) → y = 9.28 → ω₂.

Compare with PCA on the same data: PCA's first direction is (0.797, 0.605) (37.2°); LDA's is (0.909, 0.417) (24.7°). J at the PCA direction is 11.41 against LDA's 12.20. With these well-separated classes the loss is small; the next sections show cases where PCA is far worse.

Scatter versus covariance

If you use raw scatter matrices (no division by N − 1), S_W is four times bigger here and the eigenvalue becomes 12.2007/4 = 3.05; w is unchanged. State which convention you use. The largest eigenvalue is only the value of J, so it depends on the convention; the direction does not (for equal class sizes).

5. More than two classes (C classes)

The slide outline lists this part; the lecture slides stop at the C − 1 statement. The standard results are in Duda §3.8.3 and Bishop §4.1.6.

μ = overall mean = (1/N)Σ x μ_i = mean of class i, N_i = its size S_W = Σ_i S_i S_B = Σ_i N_i (μ_i − μ)(μ_i − μ)ᵀ S_T = S_W + S_B projection y = Wᵀx (W has up to C − 1 columns) J(W) = |WᵀS_BW| / |WᵀS_WW| solution: columns of W = leading eigenvectors of S_W⁻¹S_B

Why at most C − 1 projections: S_B is a sum of C rank-one matrices (one per class), but the class mean deviations are linearly dependent, because Σ N_i(μi − μ) = 0. So rank(S_B) ≤ C − 1, and S_W⁻¹S_B has at most C − 1 nonzero eigenvalues. Only those eigenvectors carry class-discriminatory information. Two classes: 1 dimension. Three classes: at most 2. A 100-feature problem with 4 classes reduces to at most 3 dimensions.

An example where PCA is the wrong tool

Two classes spread widely along x₁ but differing only in x₂: ω₁ = (−4, 1.1), (−2, 0.9), (2, 1.1), (4, 0.9); ω₂ = (−4, −0.9), (−2, −1.1), (2, −0.9), (4, −1.1). Computed in code:

  • PCA: PC1 ≈ (1, 0) (variance 11.4 against 1.2). Projections: ω₁ → 4.0, 2.0, −2.0, −4.0 and ω₂ → 4.0, 2.0, −2.0, −4.0: the classes are completely mixed. J = 0.00002.
  • LDA: w ≈ (0.01, 1). Projections: ω₁ → 0.88 to 1.12; ω₂ → −1.12 to −0.88: perfectly separated. J = 166.7.

The direction of greatest variance is not the direction of best separation. That is why PCA before classification can discard exactly the information you need.

7. Limitations of LDA

  • At most C − 1 features. If error estimates show that more features are needed, another method must supply them.
  • Parametric. It assumes unimodal, roughly Gaussian class distributions (with similar covariance). If the distributions are significantly non-Gaussian, the projections cannot preserve complex structure (several clusters per class, curved classes).
  • Fails when the information is in the variance, not the mean. If both classes have the same mean (e.g. one tight cluster and one wide cluster around the same centre), μ₁ − μ₂ = 0, so S_B = 0 and J(w) = 0 for every direction. LDA cannot find anything; a different method (e.g. quadratic discriminants, kernels) is required.
  • Singular S_W. S_W⁻¹ needs S_W invertible. This fails when there are fewer samples than dimensions (the "small sample size" problem) or when all points of each class lie on one line (an exam dataset does this; see §8). Fixes: pseudo-inverse, add εI to S_W, or reduce dimension with PCA first. (Standard remedy, beyond the slides.)
  • Linear only and sensitive to class overlap in the means.
Link to Bayesian decision theory (insight, not in the slides): for two Gaussian classes with the same covariance Σ, the Bayes decision boundary's normal vector is Σ⁻¹(μ₁ − μ₂), the same direction as Fisher's w* when S_W ∝ Σ. With equal priors the Bayes threshold is the midpoint of the projected means. So LDA is optimal exactly in the equal-covariance Gaussian case, and the assumptions above are the price of that.

8. Exam kit

Past papers: numerical LDA 2D → 1D appears in S25, F24, S24, S23; "why are PCA and LDA both linear projections / compare them" in S24. Procedure to write in the exam:
  1. Class means μ₁, μ₂.
  2. Class scatter (or covariance) matrices S₁, S₂ (show one calculation).
  3. S_W = S₁ + S₂.
  4. S_B = (μ₁ − μ₂)(μ₁ − μ₂)ᵀ.
  5. S_W⁻¹ (2×2: swap the diagonal, negate the off-diagonal, divide by the determinant).
  6. w* = S_W⁻¹(μ₁ − μ₂), or the eigenvector with the largest eigenvalue of S_W⁻¹S_B (solve λ² − (trace)λ = 0).
  7. Normalise w and project: y = wᵀx. Show the projected values and comment on separation.

Past dataset: S25 and F24

Class 0: (1,2), (3,1); class 1: (6,5), (8,7).

μ₁ = (2, 1.5), μ₂ = (7, 6) S₁ = [[2,−1],[−1,0.5]], S₂ = [[2,2],[2,2]] S_W = [[4,1],[1,2.5]] (det 9) S_W⁻¹ = (1/9)[[2.5,−1],[−1,4]] w ∝ S_W⁻¹(μ₁ − μ₂) = (1/9)(−8, −13) → unit w = (0.524, 0.852) after flipping sign λ_max = (μ₁ − μ₂)ᵀS_W⁻¹(μ₁ − μ₂) = 10.94 projections: class 0 → 2.23, 2.42; class 1 → 7.40, 10.15

Past dataset: S24 (singular S_W)

Class 0: (2,3), (3,5); class 1: (5,8), (6,10). Each class lies on a line of slope 2, so S_W = [[1,2],[2,4]] has determinant 0 and no inverse. Say so, then choose w perpendicular to the line direction, w = (2, −1)/√5: every class-0 point projects to 0.447 and every class-1 point to 0.894, so within-class scatter is zero and J → ∞ (perfect separation). Same answer as the limit of S_W + εI as ε → 0.

Common mistakes

  • Computing S_B with a sum over samples instead of the single outer product (two-class case), or forgetting its rank is 1.
  • Choosing the eigenvector of the smaller eigenvalue: the largest eigenvalue gives the best projection.
  • Using S_B⁻¹S_W (inverted the wrong matrix) or inverting S_W incorrectly. Check: S_W S_W⁻¹ = I.
  • Mixing scatter and covariance between the two classes. Be consistent.
  • Forgetting to normalise w before projecting (the shape of the projection is the same but numbers differ).
  • Claiming LDA can give more than C − 1 dimensions.

Self-test

1. Two classes, μ₁ = (2,0), μ₂ = (0,0), S_W = I. What is w*, and the J it gives?
w* ∝ S_W⁻¹(μ₁ − μ₂) = (2,0), unit w = (1,0). J = wᵀS_Bw / wᵀS_Ww = 4/1 = 4.
2. With the slide's S_B and S_W, compute J for w = (1,0) and w = (0,1). How do they compare with 12.20?
w = (1,0): 29.16/3.3 = 8.84. w = (0,1): 14.44/5.5 = 2.63. Both are lower than the maximum 12.20 at w* = (0.909, 0.417).
3. How many discriminant directions can LDA give for 5 classes in 50 dimensions?
At most C − 1 = 4.
4. Why does S_W⁻¹S_B have only one nonzero eigenvalue for two classes?
S_B is an outer product, rank 1, so the product has rank at most 1; the nonzero eigenvalue equals trace(S_W⁻¹S_B) = J_max.
5. Two classes share the same mean but differ in variance. What does LDA do?
μ₁ = μ₂ gives S_B = 0 and J = 0 for every w; LDA finds no useful direction.
6. Why is maximising the distance between projected means alone a bad criterion?
It ignores within-class spread: a direction with a bigger distance can have overlapping classes, and scaling w makes the distance arbitrarily large. Fisher normalises by the within-class scatter.
