Automata Conversions: ε-NFA → NFA → DFA → Minimal DFA

Slides 39–284: definitions, extended transition function, subset construction, ε-closure, equivalent states and the table-filling minimization algorithm, followed by the exam questions that use them (Q1 definitions and Q3 conversions/minimization). Textbooks: Hopcroft–Motwani–Ullman (HMU), Introduction to Automata Theory, Languages, and Computation, 3rd ed.; Sipser, Introduction to the Theory of Computation; Dragon Book (Aho et al.).

1. The big picture

Regular expression ⇄ ε-NFA → NFA → DFA → minimal DFA
                      (remove ε)   (subset construction)   (table filling)

All four models accept exactly the regular languages. Conversions never change the language, only the machine. NFAs and ε-NFAs are easier to design; DFAs are easy to run (one move per symbol), which is why the lexer is a DFA.

Extended transition function δ̂ slides 102–125, 143–157

  • DFA: basis δ̂(q, ε) = q; induction on w = xa: δ̂(q, xa) = δ(δ̂(q, x), a). Meaning: the state reached after reading the whole string.
  • NFA: basis δ̂(q, ε) = {q}; δ̂(q, xa) = ∪ { δ(p, a) : p ∈ δ̂(q, x) }. Meaning: the set of states you may be in.
  • Language: DFA L(A) = { w | δ̂(q₀,w) ∈ F }; NFA L(A) = { w | δ̂(q₀,w) ∩ F ≠ ∅ }.
  • Example (NFA for “ends in 01”: q₀ loops on 0,1; q₀–0→q₁; q₁–1→q₂ final): δ̂(q₀,101): after 1 {q₀}; after 0 {q₀,q₁}; after 1 {q₀,q₂}. Contains q₂, so 101 is accepted.
Read: HMU Ch. 2 “Finite Automata” (§2.2 DFA, §2.2.4 extended transition function, §2.3 Nondeterministic FA, §2.3.2 extended δ for NFAs, §2.5 FA with ε-transitions); Sipser Ch. 1 §1.1 Finite Automata, §1.2 Nondeterminism.

2. ε-NFA → NFA (eliminating ε) slides 280–284

ECLOSE(q) = all states reachable from q using ε-moves only; always contains q itself. For a set, take the union.

  1. Compute ECLOSE of every state.
  2. δ′(q, a) = ECLOSE( δ( ECLOSE(q), a ) ): close, then read a, then close again.
  3. Final states: q is final in the new NFA if ECLOSE(q) contains an old final state.
  4. Start state and states unchanged. (Unreachable states may then be dropped.)

Example (Spring 2023 ε-NFA): q₀ loops 0, q₀–ε→q₁, q₁ loops 1, q₁–ε→q₂, q₂ loops 2 and is final. ECLOSE(q₀)={q₀,q₁,q₂}, ECLOSE(q₁)={q₁,q₂}, ECLOSE(q₂)={q₂}.

State012
→ *q₀{q₀,q₁,q₂}{q₁,q₂}{q₂}
* q₁∅{q₁,q₂}{q₂}
* q₂∅∅{q₂}

All three are final (each closure contains q₂). The language is 0*1*2*.

Read: HMU §2.5.3 “Extended transitions and languages for ε-NFAs”, §2.5.5 “Eliminating ε-transitions”; Dragon Book §3.7.1 (ε-closure inside the subset construction).

3. NFA → DFA: subset construction slides 184–207

  • Same alphabet. DFA start = {q₀} (for an ε-NFA: ECLOSE(q₀)).
  • DFA states are subsets of NFA states. In principle Q_D = 2Q_N (n NFA states give up to 2ⁿ), but build only the subsets reachable from the start.
  • δ_D(S, a) = ∪ δ_N(p, a) for p ∈ S (for ε-NFA: close the result).
  • A DFA state is final if the subset contains at least one NFA final state.
  • The empty set ∅ is a legal DFA state: the dead (trap) state. Include it, with self-loops, if it is reachable.

Procedure (work-list)

  1. Write the start subset in the first row.
  2. For each symbol compute the target subset. If it is new, add it as a new row.
  3. Repeat until no new subsets appear. Name the subsets A, B, C… and mark finals with *.

Worked example: NFA for “ends with 01” slides 195–203

NFA: q₀ loops on 0,1; q₀–0→q₁; q₁–1→q₂ (final).

Read: HMU §2.3.5 “Equivalence of Deterministic and Nondeterministic Finite Automata” (the subset construction and its proof); Sipser Theorem 1.39; Dragon Book §3.7.1 “Conversion of an NFA to a DFA”.

4. DFA minimization slides 211–278

  • Equivalent states: p ≡ q iff for every string z: δ̂(p,z) ∈ F ⇔ δ̂(q,z) ∈ F. Equivalent states can be merged. States that are not equivalent are distinguishable (some string takes one to a final state and the other not).
  • First remove unreachable states. The minimal DFA for a language is unique (up to renaming) and has the fewest states.

Table-filling algorithm (slides 231–238)

  1. Draw a triangular table with one cell for every unordered pair of distinct states.
  2. Mark every pair with one final and one non-final state (distinguished by ε).
  3. For each unmarked pair (p,q) and each symbol a: look at the pair (δ(p,a), δ(q,a)). If that pair is marked, mark (p,q) and recursively mark every pair that was waiting on (p,q) (its dependency list). If the pair is unmarked and not trivial, add (p,q) to that pair’s dependency list. Pairs with identical states (r = s) impose nothing.
  4. When nothing changes, unmarked pairs are equivalent. Merge them into classes (equivalence is transitive).
  5. Build the new DFA: one state per class; start = the class of q₀; finals = classes of final states; transitions from any representative.
Fast hand alternative (partition refinement): start with the partition {F, non-F}; split a block whenever its members move to different blocks on some symbol; stop when nothing splits. It gives the same answer as the table and is quicker for 5–6 states (HMU §4.4.3; Dragon Book §3.9.6). Use the table when the question asks for it.

Worked example A: Fall 2024 (finals c, d, e)

Transitions: a: 0→b, 1→d · b: 0→a, 1→c · c, d, e: 0→e, 1→f · f: 0,1→f.

  1. Mark final/non-final: (a,c),(a,d),(a,e),(b,c),(b,d),(b,e),(f,c),(f,d),(f,e).
  2. Remaining: (a,b), (a,f), (b,f), (c,d), (c,e), (d,e).
  3. (a,f): on 1 → (d,f), marked ⇒ mark (a,f). (b,f): on 1 → (c,f), marked ⇒ mark (b,f).
  4. (c,d), (c,e), (d,e): on 0 both go to e (same), on 1 both to f (same) ⇒ unmarked.
  5. (a,b): on 0 → (b,a), the same pair; on 1 → (d,c), unmarked ⇒ no marking possible ⇒ unmarked.

Classes: P = {a,b}, Q = {c,d,e}, R = {f}. Minimal DFA: P –0→ P, P –1→ Q; Q –0→ Q, Q –1→ R; R –0,1→ R. Start P, final Q. 6 states → 3.

6. Mistakes & practice

  • Forgetting the ε-closure after a move (it is close → move → close).
  • Marking a DFA state final only when it equals a final state, instead of contains one.
  • Leaving out the dead state ∅, or building all 2ⁿ subsets instead of reachable ones.
  • Treating “marked” as “equivalent”: in table filling, marked = distinguishable; unmarked = equivalent.
  • Not removing unreachable states before minimizing.

P1. Convert to a DFA: NFA q₀ loops a,b; q₀–a→q₁; q₁–a,b→q₂ (final). (second symbol from the end is a)

AnswerA={q₀}: a→B, b→A. B={q₀,q₁}: a→C, b→D. *C={q₀,q₁,q₂}: a→C, b→D. *D={q₀,q₂}: a→B, b→A. Four reachable subsets.

P2. ε-NFA: p–ε→q, q–a→r, r–ε→p. Give all ECLOSEs and δ′(p,a).

AnswerECLOSE(p)={p,q}, ECLOSE(q)={q}, ECLOSE(r)={r,p,q}. δ′(p,a) = ECLOSE(δ({p,q},a)) = ECLOSE({r}) = {r,p,q}.

P3. A table-filling run leaves (p,q) unmarked. Can p and q be merged?

AnswerYes. Unmarked means no string distinguishes them, so they are equivalent (and equivalence is transitive, so merge their whole class).

P4. An NFA has 4 states. What is the maximum number of states in its subset-construction DFA?

Answer2⁴ = 16 (including ∅); often far fewer are reachable.
